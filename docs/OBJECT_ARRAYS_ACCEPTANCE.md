Поддержан ограниченный `array<UDT>` v5/v6: nominal typing, typed na,
конструкторы, структурные операции и методы, UDF, for…in, shallow array copy,
история, COW, общий GC и квоты. Varip переносит структуру массива и только
помеченные поля объектов. Reference-поля, вложенные массивы и object-dependent
requests остаются исключены; сравнение исполнения с TradingView не заявляется.

Каждый слот удерживает одну ссылку на запись независимо от числа aliases
контейнера. Проверены каскадный GC, очередь на тысяче баров, checkpoint на
100 тысячах одинаковых ссылок без размножения объектов, every-bar/every-event
restore, повреждённые рёбра и nominal ID, отсутствие утечки staging account
и запрет переноса обычной мутации через intrabar checkpoint. Новая intrabar
запись использует constructor baseline для обычных полей: это явная
интерпретация OpenPine, требующая отдельной внешней проверки.

Массив со 100 тысячами ссылок проверен через файловый record codec при прежнем
512 МиБ бюджете задания, в том числе внутри незакрытого бара. Компактные integer
ID слотов устранили лишние tagged-словари; partial heap передаётся отдельными
records и материализуется при restore, без последующего IO из runtime.
Отдельно проверены 3000 записей с varip-полями в обычном массиве: partial heap
содержит только записи, а не переносимую структуру массива.

превышения decode reserve в прежнем представлении. После исправления запущен
отдельный полный CI нового коммита; decode reserve и остальные лимиты сохранены.
