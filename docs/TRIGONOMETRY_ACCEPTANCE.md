# Приёмка тригонометрии и математических констант в R6

[Проверка ветки](https://github.com/s7cret/openpine/actions/runs/43730492024) ·

[Машиночитаемое свидетельство](evidence/trigonometry-20261115.json)

Python 3.14.8, CI 57/57, один wheel.
Windows — 2096 успешных тестов. Linux — 2095 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4920 прежних наблюдений conformance
сохранены. Добавлены 22 расчётных сценария и 19 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. Двухминутный угол относительного изменения цены
дал одно оповещение после подтверждённого пересечения нуля.

В первом кандидате два прежних теста ожидали отказа для `math.sin(1)`.
В итоговом кандидате проверки используют `math.sin(close)` и подтверждают
запрет зависимости вычисляемой цели запроса от свечей.
[Первый кандидат](https://github.com/s7cret/openpine/actions/runs/43728562667) · [Журнал feedback](https://github.com/s7cret/openpine/actions/runs/43728562667/job/132855739207).

Шесть тригонометрических функций проверены в Pine v1–v6, перевод углов
и четыре константы — в v4–v6. Покрыты квалификаторы, именованные
аргументы, na, окрестность полюсов tan и переполнение при переводе угла.
Сравнение с исполнением TradingView остаётся отдельным этапом.
