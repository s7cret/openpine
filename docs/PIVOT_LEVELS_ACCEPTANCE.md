Python 3.14.8, CI 57/57, один wheel.
На Windows прошли 2063 тестов. На Linux прошли 2062 тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4760 прежних наблюдений conformance
сохранены. Добавлены 6 расчётных сценариев и 14 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед сменой дня.
Смена R1 не вызвала оповещение. Пересечение внутри дня вызвало одно.

Обе функции проверены в Pine v5–v6, в v1–v4 проверены отказы.
Численные проверки охватывают шесть формул, режим developing и смену
периода в UTC. Семантика уровней отражена в профиле OpenPine.
Сравнение с исполнением TradingView остаётся отдельным этапом.
