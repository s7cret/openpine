Python 3.14.8, CI 57/57, один wheel.
Windows — 2118 успешных тестов. Linux — 2117 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены 5064
прежних наблюдений. Добавлены 28 исполняемых сценариев и
17 ожидаемых отказов. Они покрывают версии Pine,
дни по умолчанию, ночные окна, перерывы, переходы DST и явные диагностики.

Два сохранённых пресета на одном IR выставили заявки на барах 1 и 2
и на барах 2, 3 и 4 соответственно. Условия учитывали торговые часы
и абсолютные даты. После паузы и обновления пресета worker восстановил
свою строку окна из checkpoint. Журнал совпал с непрерывным расчётом. Сохранённый
IR дал те же настройки и наблюдения через CLI. Проверки прошли на
общем wheel Windows и Linux. В Chrome на установленном wheel
проверены строка расписания, загрузка, редактирование и сброс пресета.

В статической матрице реализованные формы сессионных вызовов и ввода имеют статус PARTIAL.
Сравнение с исполнением TradingView ведётся отдельно.
