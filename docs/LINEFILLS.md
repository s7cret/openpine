# Заливка между линиями Pine v5–v6

Индикатор или стратегия может залить канал между двумя линиями с координатами по
индексу бара. Заливка следует за границами, включая их продление.
В v1–v4 тип и операции получают `LINEFILL_VERSION`.
[Закреплённый профиль](../spec/linefills-profile.json)

```pine
//@version=6
indicator("Price channel", overlay=true)
var line upper = line.new(0, high, 1, high, extend=extend.right)
var line lower = line.new(0, low, 1, low, extend=extend.right)
var linefill channel = linefill.new(upper, lower, #33669980)
if bar_index > 0
    line.set_xy2(linefill.get_line1(channel), bar_index, high)
    line.set_xy2(linefill.get_line2(channel), bar_index, low)
    linefill.set_color(channel, close >= open ? #22884480 : #AA222280)
```

- `linefill.new(line1, line2, color)` создаёт объект. Для пары линий
  допускается одна заливка. Повторный вызов выдаёт новый ID и заменяет
  предыдущую заливку. OpenPine считает прямой и обратный порядок одной
  парой. `linefill.get_line1` и `linefill.get_line2` возвращают линии в
  порядке последнего вызова конструктора.
- `linefill.set_color` меняет цвет. Значение `na` скрывает заливку,
  сохраняя объект. `linefill.delete` удаляет заливку. Удаление или
  вытеснение любой границы удаляет все связанные заливки.
- OpenPine возвращает `na` при создании из отсутствующей линии или
  из одной линии дважды. Чтение через удалённую ссылку возвращает
  `na`, изменения по такой ссылке пропускаются. Лимит на скрипт
  составляет 50 живых заливок и 1024 вызова изменения за бар. При
  заполнении лимита объектов вытесняется самая старая заливка.

Веб строит заливку в общем видимом диапазоне двух линий и разделяет
пересекающийся канал на две части. Вертикальные, совпадающие и
разнесённые по X границы дают нулевую площадь. OpenPine рисует заливку
на панели, общей для двух границ. Границы на разных панелях скрывают
заливку, сохраняя её ID, цвет и ссылки на линии.
[Размещение рисунков](DRAWING_OVERLAY.md)

Checkpoint сохраняет ID заливок, цвет и ссылки вместе с границами.
Итоговый результат и replay возвращают состояние заливок под
ключом `linefills`. Изменения открытого бара попадают в отдельный
предпросмотр. [Внутренние сценарии](../conformance/linefills/cases.json)

Стратегия может сохранить заливку, метки, таблицу и торговый журнал в одном
результате. При вытеснении линии по `max_lines_count` связанная заливка
исчезает вместе с границей. В replay это сначала видно на открытом баре,
а затем в подтверждённом состоянии после его закрытия.
[Пример стратегии Pine v6](../conformance/linefills/v6-strategy-channel.pine)

Точная сверка исполнения с TradingView проводится отдельным этапом.
