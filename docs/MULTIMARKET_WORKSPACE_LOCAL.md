# Многорыночная стратегия в локальном рабочем месте

Исходник `71079c252a4eed2879bcb398685403c04a69775c`, Windows 11, Python 3.14.8. Файлы стратегии и порядок запуска приведены в [описании экономики](ECONOMICS.md). Численные результаты доступны в [локальном отчёте](evidence/multimarket-workspace-local.json).

В Chrome загружены Pine, свечи двух рынков и курсы USD/EUR. В паспорте подготовки проверены источник и пара валют. После отмены и возобновления подготовки первый запуск отобразил график, шесть исполнений и три закрытые сделки. HTTP-запрос двух баров со смещением 10 вернул цены 110 и 111 и позицию 1 на обоих барах. Повтор из сохранённой конфигурации создал отдельное задание с тем же снимком FX. Оба результата совпали по статистике, включая комиссию 8,52 EUR и конечный капитал 995,48 EUR.

Два worker одновременно открывали один снимок Parquet. В тесте каждый останавливался после извлечения первой строки из открытого курсора. Отмена первого задания оставила его без результата. Второе продолжилось и вернуло для проверенного диапазона значения 40 и 85.

В отдельном сценарии сохранены завершённый запуск и checkpoint второго задания перед исполнением стоп-ордера. После истечения временных закреплений входов выполнены сборка мусора и резервное копирование. При восстановлении в тесте запись прерывалась после 32 байт ошибкой ENOSPC. Целевой каталог появился только при успешном повторе. После открытия восстановленного хранилища завершённый результат прочитан, а продолжение второго задания воспроизвело полный журнал эталона.
