# Приёмка исполнения по младшим свечам

- [x] 1. Версионированный контракт v1–v6; `use_bar_magnifier` из Wiki только в v5/v6; явные настройки для ранних версий.
- [x] 2. Кратные минутные интервалы, одинаковый инструмент/провайдер, слоты, порядок, OHLCV и конфликты.
- [x] 3. Два неизменяемых снимка Parquet в RunPlan, общий каталог/провайдер, строгие пропуски либо отмеченный fallback всей основной свечи.
- [x] 4. Общий брокер: лоты, частичные выходы, OCA, stop-limit, trailing, комиссии, риск; provenance младшей свечи и модельной точки.

- [x] 6. Checkpoint внутри первого/последующих баров, миграция SQLite 15, восстановление воркера, CLI/HTTP/UI и исследования/walk-forward.
- [x] 7. Независимые ценовые примеры, все границы восстановления, максимальные команды и счётчики, нагрузка, установленный wheel и полный CI.
