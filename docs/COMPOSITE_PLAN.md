# Составные результаты и индикаторы R6

- [x] 1. Версионные контракты, evidence и форма составного результата в IR.
- [x] 2. Распаковка, `_`, UDF/value-if, однократное вычисление и типы элементов.
- [x] 3. Устойчивые variance/stdev, прогрев, NA, bounded storage и восстановление.
- [x] 4. MACD/BB и согласованное состояние компонентов во всех версиях.
- [x] 5. Числовые tuple-запросы, gaps/lookahead, rollback и совместный checkpoint.
- [x] 6. Два семейства стратегий v1–v6, jobs/chart/ledger и исследования.
- [x] 7. Независимый corpus, аварии/backup, нагрузка, installed wheel, Windows/Linux CI.

Приёмка закрыта 23.10.2026 для исходного коммита `761dda5`
на Python 3.14.8. [Отчёт с идентичностями и хешами](evidence/composite-20261023.json)
и [CI на Windows/Linux](https://github.com/s7cret/openpine/actions/runs/40013117458) фиксируют:

- 484 теста в 57 модулях; обе платформы прошли полную матрицу, 9/9 заданий CI.
- 623 conformance-сценария: 72 новых, все прежние 551 наблюдение и старые bundles сохранены.
- Все 12 стратегий v1–v6 проходят совместное восстановление контекстов, runtime и broker.
  Установленный wheel дополнительно проверен через CLI/HTTP на v1/v6 для обоих семейств,
  с графиками, журналом, experiment, отдельным holdout и walk-forward.
- Реальное завершение воркера на 100000 свечах: повторная попытка продолжает с бара 1000.
  Backup/restore продолжает с бара 5 с активной защитой; итоговые journal/Parquet совпадают
  с непрерывным запуском. Проверены 3 каталога, 9 планов, 4 копии checkpoint и 56 объектов.
- Числовые ядра отдельно: 1000000 свечей, 5000000 выходных значений, Decimal с точностью
  100 знаков. Максимальная ошибка variance/stdev — 4,44×10⁻¹⁶; BB — не более одной ULP.
  В этом прогоне длина окна 127, состояние 381 ячейка, peak RSS 72368128 байт,
  время 79,347 с. Это не миллионный тест полного воркера.
- В браузере проверен готовый CLI/HTTP-результат BB v6: 240 свечей, 5 рядов,
  6 защитных выходов, легенда, масштаб и сброс. Запуск с дополнительным контекстом
  выполняется через CLI/HTTP; историческая веб-форма пока не загружает такие снимки.

Ограничения: плоские результаты 2…16 scalar элементов; lengths simple int
1…100000; явные same/higher контексты; одна full-position защитная группа
на подтверждённой исторической OHLC-модели. BB v1–v3 реконструирован, v1/v2
historical lookahead on явно отмечен. Точная сверка с TradingView — отдельный этап.
