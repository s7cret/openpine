# Составные результаты и индикаторы R6

- [ ] 1. Версионные контракты, evidence и форма составного результата в IR.
- [ ] 2. Распаковка, `_`, UDF/value-if, однократное вычисление и типы элементов.
- [ ] 3. Устойчивые variance/stdev, прогрев, NA, bounded storage и восстановление.
- [ ] 4. MACD/BB и согласованное состояние компонентов во всех версиях.
- [ ] 5. Числовые tuple-запросы, gaps/lookahead, rollback и совместный checkpoint.
- [ ] 6. Два семейства стратегий v1–v6, jobs/chart/ledger и исследования.
- [ ] 7. Независимый corpus, аварии/backup, нагрузка, installed wheel, Windows/Linux CI.

Приёмка открыта до проверки окончательного кода и сохранения доказательств.
Базовый результат предыдущего этапа: 466 тестов, 551 conformance-сценарий;
прежние положительные и отрицательные наблюдения должны сохраниться.

Ограничения: плоские результаты 2…16 scalar элементов; lengths simple int
1…100000; явные same/higher контексты; одна full-position защитная группа
на подтверждённой исторической OHLC-модели. BB v1–v3 реконструирован, v1/v2
historical lookahead on явно отмечен. Точная сверка с TradingView — отдельный этап.
