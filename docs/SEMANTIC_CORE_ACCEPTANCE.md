# Приёмка первой порции семантики

Код [`c78c920`](https://github.com/s7cret/openpine/commit/c78c9204918fa0d2eac64a914766cc515d9a3ca0)
прошёл [полный CI 57/57](https://github.com/s7cret/openpine/actions/runs/40979731505)
на Python **3.14.8**. Реализованы литеральные defaults UDF и обе формы switch
для v5/v6; v1–v4 получают явную диагностику версии. Все версии представлены
целыми программами: в старых версиях эквивалентная логика использует if и
обязательные параметры. [Матрица семантики](SEMANTIC_COVERAGE.md),
[контракт и ограничения](SEMANTIC_CORE.md), [машинное свидетельство](evidence/semantic-core-20261030.json).

| Проверка | Принятый результат |
| --- | --- |
| Unit/integration на каждой ОС | 1413 тестов в 163 модулях; все прежние 1396 ID сохранены, добавлено 17 |
| Conformance на каждой ОС | 2483 случая: 1646 исполнений и 837 ожидаемых отказов |
| Прежние наблюдения | Все 2461 совпали точно с прошлой приёмкой отдельно в Windows и Linux |
| Новый conformance | 22 случая; полные отчёты одинаковы между ОС |
| Целые программы | 64 записи: 58 исполнений и 6 прежних ожидаемых отказов; исходные 56 записей сохранены точно |
| Сравнения корпуса | 414 успешных, 38 различий моделей явно помечены not_equivalent; полное свидетельство корпуса одинаково между ОС |
| Установленный пакет | Один общий wheel, 18 suites на каждой ОС, четыре проверки восстановления |

Новые восемь программ прошли обычные workers, подачу исходника/сохранённого IR,
историю, replay, восстановление и сравнение нативного состояния. Две стратегии
проверяют checkpoint с открытой позицией и независимые equity/комиссии.
У исторического и наблюдаемого брокера разные модели: их не объявляют
эквивалентными. Независимые ожидания не получены запуском самого Pine evaluator.

Проверены однократное вычисление selector, порядок explicit/default аргументов,
ленивые условия, области видимости, tuple-результаты и независимые branch/UDF var.
Внутрисвечный varip проверен с восстановлением на каждом разрезе ленты;
дополнительный контекст использует собственные цены. Поддельный effectful default
отклоняется до эффектов. Чрезмерные normalized AST и развёрнутые value-ветки
получают `FUNCTION_EXPANSION` вместо Python RecursionError.

При отказе допуска до enqueue контроллер корпуса сохраняет исходную причину
`resource_wait`: очистка пропускает запланированный, ещё не созданный job ID.
Отдельный регрессионный тест проверяет точный failure и завершение случая.
Лимиты процессов/RAM/диска не ослаблены. Дополнительный локальный прогон восьми
программ использовал проверенный RECORD и распакованный wheel; обе CI-установки
проверены штатным installer. Локальное временное давление памяти не выдаётся
за ошибку Pine или успешную проверку ресурсов.
