Python 3.14.8, CI 57/57, один wheel.
Windows — 2113 успешных тестов. Linux — 2112 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены 5040
прежних наблюдений. Добавлены 6 исполняемых сценариев и
18 ожидаемых отказов. Они покрывают версии Pine,
свёртку констант, смещения, високосные даты и отклонение неверного ввода.

На одном IR первый диапазон выставил заявки на барах 1 и 2, второй
на барах 2, 3 и 4. Бар на исключительной границе конца не выставил
заявку. После паузы и обновления пресета worker восстановил прежние
даты из checkpoint. Журнал совпал с непрерывным расчётом. Сохранённый
IR дал те же настройки и наблюдения через CLI. Проверки прошли на
общем wheel Windows и Linux. В Chrome на установленном wheel
проверены поле UTC, миллисекунды, загрузка и сброс пресета.

В статической матрице реализованные формы timestamp и ввода даты имеют статус PARTIAL.
Сравнение с исполнением TradingView ведётся отдельно.
