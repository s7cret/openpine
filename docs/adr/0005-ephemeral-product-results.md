# 0005. Смешанные результаты используют существующую кучу и codecs

Статус: accepted. Дата: 2026-11-02.

Функции и блоки уже возвращают scalar tuple; отдельные ссылки уже проходят
через UDF, `if` и `switch`. Запрет ссылок внутри tuple и numeric/bool-only
результаты циклов были границами реализации. Новый профиль расширяет эти границы.

Tuple остаётся временным значением из 2–16 компонентов. В v1–v3 доступны
scalar-компоненты; primitive arrays с v4; enum, UDT и существующие map/matrix
типы с v5. Доступность самих циклов прежняя: for с v2, while/for-in с v5.
Все компоненты получают сильнейший qualifier; любая ссылка делает его series.
Ссылочные типы инвариантны, UDT/enum номинальны; int/float допускают прежнее
числовое продвижение. Bare na и вложенные tuple не разрешают тип автоматически.

Выражения вычисляются один раз слева направо. Перед публикацией новых
переменных распаковки проверяется весь результат. Побочные эффекты вычисления
не откатываются при ошибке; неуспешный бар не публикуется и не checkpoint-ится.
GC работает на успешной границе бара, поэтому более ранняя временная ссылка
жива во время вычисления следующих компонентов. В конце бара остаются прежние
persistent/history roots; `_` не создаёт root. Конструкторы и ссылки используют
прежние общие квоты. Контейнер tuple ограничен существующими arity/IR limits;
отдельная куча, mid-bar GC и независимый бюджет не вводятся.

Цикл возвращает последний полностью вычисленный хвост. Break/continue не
подменяют его; при отсутствии хвоста возвращается typed na, bool v6 — false.
Это включает отсутствующую строку, enum и ссылку. Сохранённый IR новых
TupleIR/результатов циклов получает typed-ir.20. Старые scalar tuples и
request.security_lower_tf с tuple массивов сохраняют прежние схемы. Целый
tuple не сохраняется в переменной/истории/checkpoint. Состояние распакованных
ссылок использует прежний codec по наличию enum/object-array/map/matrix/graph.
Новая версия runtime-state без изменения провода была бы лишней миграцией.

Альтернативы: копировать ссылки при возврате (ломает алиасы); разрешить tuple
как контейнер общего назначения (требует новых типов хранения и codec); менять
старые bundles (ломает их неизменяемость). Все три отклонены.

Источники: [type system](https://www.tradingview.com/pine-script-docs/language/type-system/#tuples),
[loops](https://www.tradingview.com/pine-script-docs/language/loops/),
[v5 type system](https://www.tradingview.com/pine-script-docs/v5/language/type-system/),
построчно закреплённые записи в `spec/product-results-profile.json`.
Современная документация задаёт общую модель; v1/v2 — реконструкция на прежнем
scalar-профиле, а не подтверждение исторической доступности всех форм.
Сравнение с выполнением в TradingView остаётся отдельным этапом.
