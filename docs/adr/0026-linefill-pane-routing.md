# ADR 0026. Панель заливки определяется обеими границами

Дата 2026-11-07

Статус accepted

`line.new` и `polyline.new` в Pine v5–v6 получили `force_overlay`.
`linefill.new` принимает две линии и цвет. Справка Pine описывает
привязку заливки к линиям, но не задаёт правила для разных панелей.
[Обновление Pine v5](https://www.tradingview.com/pine-script-docs/v5/release-notes/#june-2024) · [Справка о заливках](https://www.tradingview.com/pine-script-docs/visuals/fills/#line-fills)

OpenPine хранит и исполняет `linefill` по прежним правилам. После
разделения линий по панелям каждая панель строит заливку, только если
обе её границы доступны на этой панели. В разных панелях у цен Y разные
шкалы. Выбор панели одной из границ заставил бы перенести координаты
второй в чужую шкалу. Скрытие сохраняет идентичность объекта, его цвет,
доступ к границам и каскадное удаление.

Правило применяется к истории, подтверждённому live-состоянию и
предпросмотру. Записи линий и полилиний хранят `force_overlay` только
при `true` по соглашению из ADR 0025. Контур полилинии и его заливка
попадают на одну панель. Поведение заливки между разными панелями
проверено по внутренним сценариям OpenPine. Сверка с TradingView
относится к отдельному этапу.
[ADR 0025](0025-drawing-pane-override.md)
