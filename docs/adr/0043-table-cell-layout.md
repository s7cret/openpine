# ADR 0043. Размеры и типографика ячеек таблиц

Дата 2026-11-10. Статус accepted.

Pine v4 документирует автоматические размеры по содержимому и явные
размеры в процентах. Текущая справка также описывает максимум по колонке
и строке, обрезку текста при явном размере и размеры шрифта в пунктах.
Закреплённые выпуски определяют набор допустимых параметров для каждой
версии. [Таблицы v4](https://www.tradingview.com/pine-script-docs/v4/essential/tables/) ·
[Таблицы Pine](https://www.tradingview.com/pine-script-docs/visuals/tables/#sizing-table-cells) ·
[Закреплённая спецификация](../../spec/lock.json)

OpenPine хранит процент в ячейке и переводит его в размер при отрисовке.
Это сохраняет одну модель для истории, replay и разных размеров окна.
Явная величина дорожки определяется максимумом положительных значений
в её колонке или строке. Автоматическая дорожка подбирается по содержимому.
Проценты относятся к доступной области таблиц в панели графика.
Профиль ограничивает отдельный процент диапазоном 0–100, размер шрифта
диапазоном 0–256 пунктов и подсказку 4096 символами. Подсказку определяем
по координатам указателя на графике, сохраняя события у canvas.
Пиксельная сверка с TradingView проводится отдельно.

Оформленная ячейка расширяет прежнюю запись, когда хотя бы одно свойство
отличается от умолчания. Сброс возвращает прежнюю форму записи. Старые
IR-вызовы, результаты и checkpoint остаются читаемыми. Профиль v4
сохраняет действующий вызов без текста, который уже используется в
сценариях OpenPine. Справка v4 описывает текст как обязательный аргумент.
