# ADR 0046. Хранение массивов ID рисунков

Дата 2026-11-11. Статус accepted.

Одинаковая аннотация Pine `array<line>` применяется к собственному массиву
скрипта и к снимку `line.all`. Если пропустить оба значения через одну
привязку IR, правила записи пришлось бы проверять по происхождению значения
в каждой ветке и при восстановлении. В IR используем `array.drawing.line`
для изменяемого массива и сохраняем `array.line` для снимка.
То же правило действует для меток, боксов и полилиний.
[ADR 0040](0040-drawing-inventory.md)

Изменяемый массив использует обычный heap. Его ячейки хранят ID из
пространства своего вида рисунков. Копирование массива сохраняет эти ID.
При восстановлении каждый ненулевой ID должен быть ниже `next_id`
соответствующего хранилища. Удалённые и вытесненные ID ниже этой границы
допустимы. Время жизни рисунка определяется явным удалением и лимитом
рисунков, время жизни массива — корнями heap и историей. Для проверки
checkpoint нужен один проход по ячейкам массивов рисунков.

Существующие форматы IR, heap и журналов продолжают читать прежние записи.
Для новых массивов доступны обычные привязки, `var` и история скрипта.
Точные результаты TradingView проверяются на отдельном этапе.
