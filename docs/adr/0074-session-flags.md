# ADR-0074. Границы торговой сессии в UTC 24×7

Дата 2026-11-17

Статус accepted

Закреплённый справочник содержит три переменные состояния рынка
с Pine v4 и четыре переменные границ с v5. Руководство уточняет,
что флаг последней свечи может отсутствовать из-за отсутствия сделок
в финальном интервале. [Справочник сессий](https://www.tradingview.com/pine-script-docs/concepts/sessions/#first-and-last-bars).

В OpenPine первая свеча определяется по дню её открытия и времени
предыдущей подтверждённой свечи того же контекста. Это работает при
условном чтении флага, пропуске начала сессии и повторном вычислении
свечи. Replay восстанавливает предыдущую подтверждённую свечу из
существующего курсора checkpoint. Формат checkpoint и IR не меняется.

Последняя свеча определяется по совпадению исключающего закрытия
с UTC-полуночью. Определение последней полученной свечи по следующей
строке потребовало бы будущих данных и превратило бы пропуск в сигнал.
W, M и минуты, пересекающие границу UTC-дня, оставлены за пределами
профиля границ. [Профиль и примеры](../SESSION_FLAGS.md).
