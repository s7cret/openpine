# ADR-0020. Продление рамки ценовой зоны

Дата 2026-11-05

Статус accepted

Расширенная запись бокса хранит исходные углы, режим X, толщину,
стиль и продление. Декодер распознаёт старые записи по их
дискриминантам. Первый сеттер оформления добавляет
недостающие настройки по умолчанию и сохраняет ID. Запись проходит
через существующие форматы журнала и checkpoint.

API выбирает окно по пересечению с исходным боксом или с видимой
продлённой стороной. Canvas отдельно ограничивает заливку
и вертикальные стороны исходными углами. Горизонтальные стороны
в выбранном направлении доходят до края окна. При совпадающих X
вертикальная рамка остаётся единственной видимой стороной.

Толщина 1–64 соответствует политике оформления линий OpenPine.
Внутренние проверки покрывают эту политику и геометрию окон.
Детали визуального совпадения с TradingView проверяются отдельно.
