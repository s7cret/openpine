# ADR-0077. Heikin Ashi в историческом запросе

Дата 2026-11-18

Статус accepted

В Pine тикер Heikin Ashi задаёт синтетические OHLC для запрошенного
контекста. Формула зависит от предыдущей HA-свечи, а расчёт стратегии
требует рыночных цен для исполнения. [Запросы к нестандартным графикам](https://www.tradingview.com/pine-script-docs/concepts/non-standard-charts-data/).

OpenPine закрепляет преобразование в перегрузке Typed IR и разрешает
исходный символ до чтения данных. В хранилище и у провайдера используется
идентичность рыночного снимка. Группа планировщика дополнительно учитывает
вид свечей, поэтому обычный запрос и HA имеют собственные курсоры.
Checkpoint HA-группы хранит предыдущие синтетические open и close вместе
с курсором. Брокер получает рыночную свечу из основного потока исполнения.

Первую HA-свечу инициализируем средним open и close первой свечи запрошенного
снимка. При пропуске интервала рекурсию продолжает следующий имеющийся бар.
Так повторный запуск и восстановление используют одну исходную точку.
Изменение начала снимка может изменить последующие HA-значения.
