# ADR 0041. Доступ к полям и отсутствие графического объекта

Дата 2026-11-10. Статус accepted.

Закреплённые выпуски Pine v4–v6 содержат все 15 операций. В выпусках
v5–v6 указаны типы X, цен и ссылок. Часть параметров линии и метки в v4
обозначена только как `series`. OpenPine допускает целый X и числовой Y
в соответствии с семантикой существующих координатных операций v4 и
уточнёнными сигнатурами v5–v6. [Закреплённая спецификация](../../spec/lock.json)

Setters обновляют одну запись через действующий путь валидации и журнала.
Чтение возвращает хранимое значение, включая Y метки с привязкой к свече.
OpenPine использует `na` для чтения по отсутствующему ID. Для текста это
позволяет отличить отсутствующий объект от живой метки с пустой строкой.
Обычные и `varip`-снимки сохраняют это значение с существующим форматом
скалярного состояния. Сравнение с TradingView для этих граничных случаев
входит в отдельную проверку.
