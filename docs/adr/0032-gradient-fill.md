# ADR 0032. Градиентная заливка и её маска

Дата 2026-11-08

Статус accepted

В закреплённых справочниках v5–v6 перечислена перегрузка вертикального
градиента между двумя `plot`. Анонс TradingView для v5 показывает
также перегрузку между двумя `hline`. В официальном FAQ есть
пример v6 с невидимыми `hline` и прозрачным краем градиента.
OpenPine допускает обе перегрузки с v5. В матрице строка с `plot`
отражает закреплённый справочник, а `hline` указан в разделе
дополнительных сигнатур со своим источником.
[Справочник v5](../../spec/bundles/pine-spec-20261020.1/reference/v5.json) · [Анонс](https://www.tradingview.com/blog/en/pine-script-vertical-gradients-33586/) · [Пример v6](https://www.tradingview.com/pine-script-docs/faq/visuals/)

Обычные заливки и градиенты используют одни и те же ссылки на маски.
Градиент хранит четыре отдельных значения в строке бара, поскольку
каждый из уровней и цветов может меняться. Сегмент использует значения
своего правого бара в координатах графика. Смещения и окна
границ применяются по правилам ADR 0030.
[ADR 0030](0030-visual-output-windows.md)

Для равных уровней OpenPine использует резкую границу. При обратном
порядке каждый цвет остаётся на своей высоте. Один отсутствующий
цвет получает RGB второго цвета с нулевой альфой. Отсутствующий
уровень скрывает сегмент. При пересечении маски рисуем два треугольника.
Шкала берёт значения границ маски. Эти правила описывают модель
OpenPine. Пиксельное совпадение с TradingView проверяется отдельно.
