# ADR-0023. Настройки текста и область наведения метки

Дата 2026-11-06

Статус accepted

Настройки текста добавлены к двум формам записи метки с явными
`xloc` и `yloc`. Сеттер создаёт полную запись настроек и сохраняет
существующие поля и ID. Подсказка на простой метке сохраняет прежний
вид. Для этого простая метка хранит пустое выравнивание до явной
настройки текста. Старые формы распознаются по прежним полям. Журнал и checkpoint
проверяют значения без миграции каталога.

Формат Pine v6 имеет собственный тип `text_format`. В записи хранятся
два флага начертания. Сложение объединяет флаги, включая комбинацию
жирного и курсива. Число как аргумент скрипта имеет тип `int` и
получает диагностику несовместимого типа.

Оба графика используют путь плашки и границы отрисованных строк
для проверки наведения. Область ограничивается панелью, а при
перекрытии выбирается последняя отрисованная метка. Геометрия
пересчитывается вместе с изображением и не хранится в результате.
Точные границы наведения и отображение подсказки определяет OpenPine.
