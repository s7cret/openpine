# ADR-0075. Время исполнения в Pine-программе

Дата 2026-11-17

Статус accepted

Справочники Pine связывают `timenow` с моментом вычисления. Исторические
свечи вычисляются при загрузке скрипта, а текущая свеча — по обновлениям.
[Pine v3](https://www.tradingview.com/pine-script-docs/v3/essential/sessions-and-time-functions/#built-in-variables-for-working-with-time) ·
[Pine v6](https://www.tradingview.com/pine-script-docs/concepts/time/#timenow).

Для исторической работы одна явная метка задаётся на запуск. Это позволяет
одинаково исполнять данные в CLI, в воркере и после восстановления.
Смена метки меняет хеш плана и окружения. При отсутствии поля прежние
планы и окружения сохраняют представление. Форматы снимков, событий и IR
используют существующие схемы.

Для наблюдаемой фазы время каждого расчёта берётся из события, которым
он вызван. Часы процесса и время открытия свечи могли бы дать другое
значение при повторе записи или восстановлении. Метка запрошенного
выражения принадлежит его собственному событию. Исторический префикс
replay использует общую закреплённую метку из окружения основного
контекста. [Профиль](../EXECUTION_TIME.md).
