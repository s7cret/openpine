# ADR 0040. Снимки живых графических объектов

Дата 2026-11-10. Статус accepted.

Закреплённый справочник Pine v5–v6 описывает массивы ID только для чтения.
Нулевой элемент указывает на самый старый живой объект. Пример справочника
сохраняет ссылку на список и удаляет объекты по индексам. В OpenPine каждое
чтение фиксирует состав списка для текущего расчёта. Повторное чтение
отражает изменения, а перебор ранее взятого списка остаётся стабильным.
[Справочник Pine](https://www.tradingview.com/pine-script-reference/v5/#var_line.all)

Снимок хранит тип и последовательность ID. Самими рисунками владеют
существующие хранилища runtime. За каждый прочитанный ID расходуется бюджет
операций текущего бара. Индексация и перебор используют действующие правила
массивов. У снимка нет корней в heap, истории значений или записи в checkpoint.
После восстановления он строится из восстановленного набора объектов.

`copy()` создаёт новую запись через общий путь с теми же лимитами и журналом.
Для отсутствующего ID принято значение `na`. Заливка принадлежит паре линий
и при копировании линии не дублируется. Внешняя сверка этих случаев с
TradingView остаётся отдельной проверкой. [Профиль OpenPine](../DRAWING_OBJECTS.md) · [ADR 0039](0039-drawing-limits.md)
