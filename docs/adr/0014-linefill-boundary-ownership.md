# ADR-0014. Заливка принадлежит паре линий

Дата 2026-11-04

Статус accepted

## Контекст

Заливка движется вместе с двумя линиями. Их удаление и вытеснение
должны убирать зависимые объекты в том же шаге. Повторное создание
для той же пары заменяет прежнюю заливку новым ID.
[Правила Pine](https://www.tradingview.com/pine-script-docs/visuals/fills/#line-fills)

## Решение

Runtime держит заливки в состоянии линий. Запись содержит ID двух
границ и цвет. Уникальность проверяется по паре ID, а порядок
аргументов хранится для getter-вызовов. Линия и её зависимые заливки
удаляются одним действием после проверки лимитов. Геометрию вычисляет
график из текущих границ.

## Последствия

Для профиля используются Typed IR .28 и runtime-state .20. При
восстановлении каждая заливка проверяется на наличие обеих границ.
Отдельная ветка предпросмотра хранит свои линии и заливки. Хранение
ссылок и цвета ограничивает объём checkpoint даже при частых
перемещениях границ. [Профиль OpenPine](../LINEFILLS.md)
