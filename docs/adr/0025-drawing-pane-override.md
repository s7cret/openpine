# ADR 0025. Панель выбирается для каждого объекта

Дата 2026-11-07

Статус accepted

Панель метки и бокса определяется двумя настройками. Флаг объекта
`force_overlay=true` выбирает ценовую панель. Остальные объекты
наследуют `overlay` индикатора. Исторический и live-графики
разделяют объекты по панелям перед расчётом шкал и отрисовкой.

Записи с принудительным наложением добавляют поле `force_overlay`
со значением `true`. Отсутствие поля означает `false`. Это
позволяет читать прежние результаты и checkpoint по их исходной
схеме. Новые объекты используют отдельные варианты типизированных
записей. Журнал и предпросмотр сохраняют выбор панели вместе
с геометрией и оформлением объекта.
[Правило Pine](https://www.tradingview.com/pine-script-docs/visuals/overview/#overlay)
