# ADR 0061. Согласованные пары и окна корреляции

Дата 2026-11-14. Статус accepted.

[Закреплённый bundle](../../spec/lock.json) содержит `correlation` в
v1–v6 и `ta.rci` в v6. Для Pearson динамическая длина появилась в
v4. В v1–v3 допущено постоянное для запуска значение, в v1–v2
вызовы позиционные. [Примечания к Pine v4](https://www.tradingview.com/pine-script-docs/v4/release-notes/#january-2021).

Pearson пропускает пару целиком при `na` в любом из источников.
Так значения обоих рядов остаются привязаны к одному вызову. RCI
сохраняет позиции пропусков, поскольку ранги сравниваются с порядком
отсчётов. При равенстве используются средние ранги. Для окна с одним
значением и нулевой дисперсии выбрано `na`.
[Оконная корреляция в Pine](https://www.tradingview.com/pine-script-docs/v5/concepts/other-timeframes-and-data/) ·
[Формула RCI](https://www.tradingview.com/support/solutions/43000765570-rank-correlation-index-rci/).

Pearson хранит пять точных префиксов в существующих кольцевых буферах.
Разности префиксов дают суммы окна без пересчёта сохранённых пар.
Checkpoint хранит два плоских столбца значений с общими позициями пар,
начальный префикс и контрольные итоги. При восстановлении префиксы
пересчитываются и сверяются до публикации
состояния. RCI хранит исходные значения и рассчитывает ранги при
достижении вызова. Предпросмотр использует слой изменённых ячеек.
Точная сверка пограничных правил с исполнением TradingView остаётся
отдельным этапом.
