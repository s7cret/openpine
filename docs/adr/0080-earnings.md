# ADR-0080. Время публикации EPS

Дата 2026-11-18. Статус accepted.

Закреплённый справочник определяет аргументы функций и поля EPS. Расписание публикаций и ревизий задаёт источник снимка. Объединение всех полей в одну строку квартала могло бы показать факт в момент публикации прогноза.

OpenPine хранит каждое поле отдельно с окончанием отчётного периода и временем доступности в UTC. На баре выбирается последняя доступная публикация запрошенного поля. При одновременной публикации одного поля за разные периоды приоритет имеет более поздний период. Повтор той же записи идемпотентен. Разные значения одного поля для одинаковой пары времён вызывают ошибку импорта. Явный null сбрасывает значение своего поля.

Для v4–v6 действуют границы бара и наблюдения, описанные в [ADR-0079](0079-corporate-actions.md). Набор значений индексируется при загрузке, поиск на баре использует двоичный поиск. Добавление семейства сохраняет канонические байты старых снимков. Оценка соответствия внешнему исполнению TradingView требует отдельной сверки.
