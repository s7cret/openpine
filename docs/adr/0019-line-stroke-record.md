# ADR-0019. Оформление в записи линии

Дата 2026-11-05

Статус accepted

Оформленная линия хранит геометрию, режим X, продление, цвет, стиль
и ширину в одной записи. Сеттер создаёт одно событие `update` с
тем же ID. Preview и checkpoint используют тот же формат, что и
подтверждённый результат. Это позволяет восстановить вид линии
без отдельной синхронизации геометрии и оформления.

Результаты со старыми записями декодируются по прежним
дискриминантам. Для них Canvas применяет синий цвет, сплошной
стиль и ширину 1 пиксель по справке Pine. Такие же значения
использует первый сеттер оформления для недостающих полей.
Опции оформления в конструкторах связываются через новые
перегрузки IR. Схемы хранилища и checkpoint допускают старые
записи и новую форму записи линии. [Справка Pine](https://www.tradingview.com/pine-script-docs/visuals/lines-and-boxes/#creating-lines)

OpenPine ограничивает ширину диапазоном 1–64 по аналогии с
профилем `plot`. Проекция вычисляется для исходной геометрии.
Canvas скрывает прозрачную обводку и рисует стрелки у исходных
видимых концов. У вертикальной линии первый конец соответствует
`arrow_left`, второй соответствует `arrow_right`. Диапазон
ширины и правила отрисовки проверяются как поведение OpenPine.
