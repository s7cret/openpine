# ADR 0052. Исторический прогрев и журнал оповещений в live

Дата 2026-11-12. Статус accepted.

При создании live-сессии с оповещениями время источника закрепляет границу
истории для каждого интервала. Прогрев и ReplayEngine используют один срез.
Эта граница определяет, какие расчёты могут публиковать оповещения. Для скриптов
с оповещениями она нужна и без ссылок на метаданные инструмента в Pine.
Профиль подстановок передаётся в конфигурацию replay при создании, а сессия
и паспорт показывают закреплённое значение.

Веб читает опубликованный `alert_events` существующего replay. Для показа
исполнения берётся строка торгового журнала с совпадающим `fill_id` на баре
события. Обе операции используют неизменяемые блоки опубликованного состояния.
Позиция чтения и выбранная страница принадлежат интерфейсу и не входят в checkpoint.

Смена версии проекции live по действующему контракту требует нового наблюдения.
Сохранённые опубликованные журналы доступны для чтения по ID сессии или replay.
