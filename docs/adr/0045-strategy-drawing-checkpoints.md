# ADR 0045. Checkpoint торгового журнала и журнала рисунков

Дата 2026-11-11. Статус accepted.

Стратегии Pine v4–v6 могут хранить метки вместе с торговым результатом.
У индикаторов журнал рисунков привязан к подтверждённым барам. В наблюдаемой
стратегии торговый журнал может уже включать события открытого бара.
При первом совместном префиксе прежний код записи выбирал версию рисунков,
а чтение после выделения рисунков возвращалось к версии обычных рядов.
Поэтому восстановление теряло дискриминант торгового префикса.

`ResultSink` присваивает совместному префиксу версию `openpine.output-prefix.8`.
Он хранит оба журнала и проверяет состав по настройкам исполнения,
полученным из закреплённой программы. Рисунки восстанавливаются на границе
подтверждённых баров. В наблюдаемом режиме торговый журнал отдельно проверяет
`simulation_completed` и `observations`. Снимок предпросмотра остаётся
в checkpoint replay. Worker проверяет согласованность обоих журналов
с восстановленным состоянием движка.

Версии `.1`–`.7` читаются по прежним правилам. У них остаются те же структуры
для рядов, отдельного торгового префикса и рисунков индикатора. Совместный
дискриминант позволяет отличать новый контракт до чтения журналов и сохраняет
существующие проверку, хранение и публикацию каждой последовательности.
Выбранный срез проверяется возобновлением исторического задания и replay,
в том числе из checkpoint до первого подтверждённого бара.
