# ADR 0033. Видимость ряда и доступность его значений

Дата 2026-11-08

Статус accepted

Архив v4 документирует два режима `display` для шести функций
`plot*`. В закреплённых v5–v6 параметр есть также у `hline`,
`barcolor`, `bgcolor`, двух обычных заливок и градиента между
двумя `plot`. Страница о заливках приводит сокращённые сигнатуры
обычных заливок без `display`, а обзор показывает вызов с этим
аргументом. Для доступности берём закреплённые сигнатуры.
Справочник не выделяет градиент между `hline` отдельной строкой.
Его опоры могут быть скрыты, а собственный параметр `display`
остаётся вне этого профиля до отдельного подтверждения сигнатуры.

Режим задаётся закрытым типом с двумя значениями. При условном
выборе используют булев литерал или прямой булев input. При запуске
режим разрешается из закреплённых входов. Сохранённый IR использует
дополнительную перегрузку только при явной передаче аргумента.
Контракт строки результата сохраняется. Выбранный режим хранится
в метаданных ряда и сверяется при восстановлении. Скрытие через
`na` убрало бы значения из результата и из маски, поэтому график
применяет отдельное правило видимости.

Скрытые ряды исключены из собственной отрисовки, легенды, подсказок
и расчёта шкалы. Видимая заливка использует их как опоры. Если
у панели нет других числовых границ, шкала берётся из сегментов
видимой заливки. Для уже масштабированной панели применяется её
текущий диапазон. Это политика OpenPine для сочетания скрытых опор
и заливки. Внешняя сверка изображения проводится отдельно.
