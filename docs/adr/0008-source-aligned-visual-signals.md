# ADR-0008: Сигнальные слои сохраняют исходный бар

Дата: 2026-11-03. Статус: accepted.

Пользователь одобрил раскраску и метки через существующую цепочку R6.
Offset требует показать метку на другом баре, а checkpoint, сравнение и
Parquet должны сохранять стабильный порядок исходных наблюдений.

Contracts владеет additive signal ABI, compiler проверяет global scope и
qualifiers, runtime выдаёт float series и два независимых RGBA канала,
storage сохраняет их в прежнем value_json. Execution range reader добавляет
ограниченный halo; UI применяет статический offset. Нулевое absolute значение
сохраняется явно, отсутствие метки выражается null. IR .23/state .15 выбираются
по фактическому использованию; прежние схемы не переименовываются.

Перестановка записей Parquet по целевому бару потребовала бы буферизации будущих
результатов и другого commit boundary. Drawing heap добавил бы ненужную здесь
идентичность/мутацию/удаление. Поэтому оставляем декларативные bar outputs.
Чтение halo ограничено offset ±10000, окно chart — прежними 5000 барами.

Документация Wiki подтверждает наличие функций v1–v6, но не все defaults.
[Профиль и ограничения](../VISUAL_SIGNALS.md) отделяют явные pinned claims
от выбранных defaults, ограниченных qualifiers и renderer choices.
Внешняя TradingView-equivalence и динамические offsets остаются отдельной работой.
Пересмотр нужен при введении динамического offset или изменяемых drawing objects.
