# ADR 0039. Ёмкость графических объектов из декларации

Дата 2026-11-09. Статус accepted.

Закреплённый справочник Pine v4 допускает `max_lines_count`,
`max_labels_count` и `max_boxes_count`. С v5 допущен и
`max_polylines_count`. В справке TradingView указано приблизительное
число показываемых объектов и удаление старых объектов при превышении
лимита. OpenPine продолжает использовать точное вытеснение по порядку
создания. Оно даёт одинаковые снимки при непрерывном исполнении и после
возобновления. Бюджеты событий и вершин сохраняются отдельно, поэтому
увеличение числа объектов не увеличивает допустимую сложность контура.
[Справка v4](https://www.tradingview.com/pine-script-docs/v4/essential/drawings/#limits) · [Справка о полилиниях](https://www.tradingview.com/pine-script-docs/visuals/lines-and-boxes/#total-number-of-objects)

Явные параметры добавляются к варианту сигнатуры после параметров формата,
шкалы и порядка. Программа без этих параметров сохраняет исходную сигнатуру
и лимит 50. В checkpoint сохраняются объекты, ID и счётчики. Лимит берётся
из допущенной программы, с которой связан checkpoint. Поэтому имеющиеся
проверки идентичности программы и реализации продолжают действовать,
а формат снимка не требует миграции.

Копия для открытого бара наследует лимит. После подтверждения вытеснение
журналируется перед созданием новой записи. Зависимые заливки удаляются
в той же ветке исполнения. Лимит относится к живым объектам одного вида
на один запуск, включая объекты с координатами `na`.
