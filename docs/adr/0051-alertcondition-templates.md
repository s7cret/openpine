# ADR 0051. Подстановка значений в `alertcondition()` при replay

Дата 2026-11-12. Статус accepted.

Документация Pine описывает подстановки в `alertcondition()` с v4. Условия
уже наблюдаются на закрытии в существующем replay. При возобновлении
совместимого запуска сообщения должны совпадать с непрерывным прогоном
с тем же профилем. Выбор режима при создании фиксирует этот контракт.
[Версии и подстановки Pine](https://www.tradingview.com/support/solutions/43000531021-how-to-use-a-variable-value-in-alert/)

Новый `openpine.alertcondition-templates.1` выбирается при создании replay
индикатора v4–v6 и входит в его идентичность. Проверка отпечатка реализации
для сохранённых IR и replay действует по общим правилам R6. Метаданные содержат
константный шаблон. Для сработавшего условия подстановка выполняется после
всех операторов прохода и до публикации его выходов. Для значений `plot()`
используются подготовленные точки этого прохода. Такой порядок позволяет
читать скрытые графики и графики, объявленные после условия, без повторного
расчёта и дополнительного состояния в checkpoint.

Часы replay берутся из ленты. Неоднозначные или отсутствующие ссылки на
график дают диагностику. Допуск индексов заканчивается при первом графике,
который выходит за профиль обычного `plot()`. Для пропуска выбрано `na`,
для неизвестного токена — буквальный текст. Сверка этих решений и форматирования
с исполнением TradingView проводится отдельно.
