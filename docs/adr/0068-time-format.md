# ADR 0068. Закрепление базы часовых поясов

Дата 2026-11-16. Статус accepted.

`str.format_time()` должен выдавать одинаковую строку после
восстановления на Windows и Linux. Поиск `ZoneInfo(name)` сначала
обращается к данным ОС. Их выпуски и доступность различаются.
[Источники данных zoneinfo](https://docs.python.org/3.14/library/zoneinfo.html#data-sources).

Закрепили `tzdata==2026.6`, соответствующий IANA `2026f`. Имена
проверяются по списку пакета и загружаются через `ZoneInfo.from_file()`
с явным путём к TZif. Версия пакета входит в идентичность сборки и
вычисления. Смена версии требует повторной приёмки. Установленный worker
читает пакет локально. Пакет поставляется и обновляется через
существующий процесс сборки и проверки зависимостей.
[Выпуск IANA](https://www.iana.org/time-zones/releases/2026f) ·
[Выпуск и SHA-256 Python wheel](https://pypi.org/project/tzdata/2026.6/#files).

Пояс применяется на этапе вывода строки из Unix-миллисекунд.
Границы свечей определяет профиль UTC/24×7. Пропущенный пояс в IR
представлен ссылкой на `syminfo.timezone`. Эту ссылку и шаблон
по умолчанию проверяет runtime при загрузке IR.
[Границы календаря](../ENVIRONMENT.md) · [Профиль форматирования](../TIME_FORMAT.md).
