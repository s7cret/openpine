# ADR 0050. Значения переменных в сообщении об исполнении

Дата 2026-11-12. Статус accepted.

Документация Pine связывает вычисление сообщения с исполнением заявки.
OpenPine фиксирует доступность значений по фазам собственного брокера.
[Оповещения об исполнении в Pine](https://www.tradingview.com/pine-script-docs/concepts/alerts/#order-fill-events)

Профиль `openpine.strategy-fill-alerts.3` применяется, если сообщение
читает именованные значения. Компилятор и загрузчик IR проверяют
зависимости по идентификаторам привязок. Скалярные `input` читаются из
закреплённых настроек. Чистые неизменяемые глобальные выражения
разворачиваются с лимитом размера и глубины и вычисляются по OHLC
наблюдения исполнения. Глобальные скаляры `var` читаются из снимка
соответствующей фазы.

Для исполнения на поступившем наблюдении источником служит состояние
последней подтверждённой свечи. При исполнении на закрытии после обычного
прохода используется состояние этого прохода. Обработчик исполнения
сохраняет только значения, от которых зависят сообщения. При первом
исполнении до инициализации `var` используется отсутствующее значение,
для `bool` в v6 — `false`. Доступны `alert_message` в v4–v6 и
сообщения частей `strategy.exit()` в v5–v6.

Восстановление использует штатный checkpoint с подтверждёнными `var`,
закреплённые входы и следующий элемент ленты. Снимок фазы живёт внутри
одного наблюдения. Сверка с TradingView по фазам исполнения ведётся отдельно.
