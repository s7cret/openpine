# ADR 0053. Окна SWMA, стохастика и линейной регрессии

Дата 2026-11-13. Статус accepted.

Граница версий взята из [закреплённого bundle](../../spec/lock.json):
v1/v2 дают архивные позиционные формы, v3 указывает для длины `integer`,
v4 — `series[integer]`, v5/v6 — `series int`. Поэтому длина до v4 ограничена
квалификатором `simple`. У регрессии v4 сохраняет `integer` для смещения,
v5/v6 явно ограничивают его `simple int`. Миграция имён сверена с
[руководством v5](https://www.tradingview.com/pine-script-docs/migration-guides/to-pine-version-5/#renamed-functions-and-parameters).
Формулы сверены со [справочником v4](https://www.tradingview.com/pine-script-reference/v4/).

Для неоднозначных краевых случаев R6 фиксирует свою модель: `stoch`
наследует прогрев и пропуски оконных экстремумов, нулевой диапазон даёт
`na`; регрессия по одному отсчёту — горизонтальная прямая через отсчёт.
Для SWMA и регрессии сохраняются позиции пропусков. Это позволяет расширять
и сокращать длину без пересборки истории. Исторические допуски и граничные
результаты пока подтверждены внутренними примерами, без сравнительного
запуска TradingView.

SWMA хранит кольцо из четырёх значений. Стохастик использует два существующих
дерева экстремумов, регрессия — две точные префиксные суммы WMA и позицию
последнего пропуска. Каждая свеча обновляет ограниченное число ячеек или
путь в дереве. Копирование при preview касается изменённых ячеек.
В checkpoint хранятся отсчёты и проверяемые опоры, а не полные деревья
или массивы префиксов.
