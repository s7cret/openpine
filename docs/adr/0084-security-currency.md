# ADR-0084. Момент пересчёта запросов в другую валюту

Дата 2026-11-20. Статус accepted для профиля OpenPine.

Описания параметра `currency` для обоих запросов в wiki (v5 — `5b17acd3ae8b9ecb`, v6 — `d86e2c10e3b91b3c`) охватывают цены и выражения на их основе, исключают числовые литералы и отсылают к предыдущему дневному курсу. Они не задают порядок вычисления EMA при смене курса и не описывают исправление уже опубликованной котировки. Доступность аргумента по версиям и ручная арифметика собраны в [профиле](../SECURITY_CURRENCY.md).

OpenPine вычисляет выражение и хранит его историю в исходной валюте инструмента. Когда вторичный результат становится видимым, денежные компоненты умножаются на доступный тогда курс. Для подтверждённого закрытия это время закрытия, для ранней видимости при lookahead — момент видимости с ограничением временем исполнения. Перенос уже видимого значения на следующую свечу сохраняет использованный курс. Каждая младшая свеча получает собственную оценку до записи в массив. Для потока исправлений применяется [правило видимости дневных курсов](0081-daily-fx.md).

| Выражение | Решение профиля |
| --- | --- |
| `close`, `hl2` | Денежная цена |
| `close[1]` | Предыдущая исходная цена, курс в момент видимости текущего результата |
| `ta.ema(close, 3)` | Денежная EMA в исходной валюте, затем пересчёт. В примере за понедельник получается 100 EUR |
| `volume` | Сохраняется число единиц объёма |
| `200`, логическое условие | Сохраняются значение и тип |
| `close / open` | Отношение двух цен одного контекста безразмерно |
| `[close, volume, close / open, 200]` | У каждого элемента собственная единица; пересчитывается только первая компонента |
| Выражение с неустановленной единицей | При явной конвертации диагностируется вне профиля до запуска |

Пересчёт входных цен до EMA изменил бы её частное состояние и дал бы в понедельник 83,5 EUR. Выбранный порядок позволяет двум валютам результата использовать один снимок свечей и даёт одинаковый смысл сохранённому IR в истории и replay. Идентичность исполнения включает привязанные валюты и снимок FX. Сигнал стратегии использует вычисленное значение, брокер исполняет сделку по цене торгуемого инструмента.

Профиль сохраняет прежний путь для пропущенного аргумента и принятого маркера native. Явное обращение к валюте графика требует различать валюту графика и запрошенного инструмента. Интерпретация неоднозначных выражений, календарь UTC и офлайн-выбор валютной пары относятся к модели OpenPine. Сопоставление с исполнением TradingView проводится отдельно.
