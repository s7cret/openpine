# ADR 0024. Текст хранится вместе с геометрией бокса

Дата 2026-11-06

Статус accepted

Текст доступен с Pine v5. В v6 к нему добавились целочисленный
размер и начертание. Профиль закрепляет доступность по версиям.
[Появление текста боксов](https://www.tradingview.com/pine-script-docs/release-notes/#textboxes) ·
[Расширения v6](https://www.tradingview.com/pine-script-docs/release-notes/#introducing-pine-script-v6)

Текстовый бокс получает отдельный вариант записи с прежним ID.
Обычные, координатные и оформленные записи по-прежнему читаются
с их исходными полями. Текстовый сеттер дополняет старую запись
при первом изменении. Журнал и восстановление используют тот же
механизм, что и для рамки, поэтому текст и геометрия переходят в
подтверждённое состояние вместе.

График рассчитывает выравнивание и перенос по исходным углам,
затем применяет обрезку окна. Это сохраняет положение подписи
при прокрутке. Профиль выбирает боксы по пересечению
прямоугольника или рамки с окном. В окне, куда попала только
продлённая рамка, видна рамка. В режиме переноса длинное слово
делится по графемам, а лишние строки обрезаются снизу.
Числовой размер ограничен 64 пунктами при отрисовке.
Сверка с TradingView остаётся отдельным этапом.
