# ADR-0018. Смена режима X существующего рисунка

Дата 2026-11-05

Статус accepted

## Контекст

Setter `set_xloc` принимает новый режим вместе со всеми координатами X.
Эти координаты интерпретируются в единицах нового режима. Геттеры
возвращают значения в единицах текущего режима. [Закреплённые сигнатуры](../../spec/drawing-xloc-mutations-profile.json)

## Решение

Публиковать режим и X одной заменой записи в существующем хранилище
рисунков. Проверка записи и лимита событий выполняется перед заменой.
Запись сохраняет ID, поэтому ссылки на рисунок и связи `linefill`
остаются действительными. Для линии старого формата без `extend`
при первом обновлении записывается эквивалентное `extend=none`.

Операции входят в существующие схемы Typed IR `.29` и runtime state
`.21`. Они используют тот же формат записи, журнал и индекс времени.
Для программы с более новой схемой `chart.point` координатные
операции учитываются при включении часов replay. [ADR-0015](0015-drawing-time-projection.md)

## Проверка

Сценарии проверяют, что один update хранит оба новых X линии и бокса,
предпросмотр может временно изменить режим, а закрытие свечи и
восстановление из checkpoint дают согласованные записи. [Сценарии conformance](../../conformance/drawing-xloc-mutations/cases.json)
