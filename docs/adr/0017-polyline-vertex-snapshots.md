# ADR-0017. Снимки вершин ломаных

Дата 2026-11-05

Статус accepted

## Контекст

Pine строит ломаную из упорядоченного массива `chart.point`.
Переменные и массивы могут сохранять ссылки на те же точки.
Отрисовка и долговременное хранение требуют отделить время жизни
рисунка от времени жизни ссылок. [Справка Pine](https://www.tradingview.com/pine-script-docs/visuals/lines-and-boxes/#polylines)

## Решение

Heap и checkpoint массива используют существующие ссылки на точки.
`polyline.new` сохраняет упорядоченные пары X и цены. Координаты
и границы бюджета проверяются до выдачи ID и записи события.
Лимиты действуют на один рисунок, живые вершины и число вершин
новых контуров за бар.

Проекция времени выполняется по общей оси из ADR-0015.
Окно получает контуры, пересекающие его по X. Canvas обрезает
сегменты и заливку отдельно. Обводка состоит из видимых частей
исходных сегментов, заливка доходит до границы окна.

## Последствия

Typed IR .31, runtime-state .23 и output-prefix .7 выделяют профиль
ломаных и журнал. Исходные координаты доступны после паузы, а
отдельный preview применяет ось с открытой свечой.
Правила неполных точек и лимиты относятся к модели OpenPine.
