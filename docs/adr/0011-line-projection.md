# ADR-0011. Видимый диапазон линии и вычисление цены

Дата 2026-11-04

Статус accepted

## Контекст

Вычисление `line.get_price` включает индексы за пределами исходных
точек. Пользователь может при этом показать на графике только отрезок.
Сохраняемые записи линий первоначально содержали только координаты.

## Решение

Видимый диапазон определяется полем `extend`. Сохранённая запись без
этого поля трактуется как конечный отрезок. Обе формы проверяются по
закрытому набору полей в существующем формате снимка и журнала.
Включение именованного `extend` выбирает новую перегрузку, а вызов с
четырьмя координатами сохраняет прежний контракт.

Getter использует исходные точки и точные разности индексов. Он
округляет только итог и возвращает `na`, если цена не определена.
Мутирующие операции пишут в журнал при подтверждении бара.

## Последствия

Чтение цены работает и для старых записей, и для всех режимов продления.
API отбирает линии по видимому диапазону, Canvas обрезает видимую часть
до расчёта масштаба. Правила вертикальной линии и границ чисел
закреплены в [профиле лучей](../LINE_EXTENSIONS.md).
