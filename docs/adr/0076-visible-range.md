# ADR-0076. Закрепление видимого диапазона графика

Дата 2026-11-17

Статус accepted

В Pine изменение видимой области приводит к повторному исполнению всей
истории с новой парой `input int`. Ряд снимка может содержать пропуски,
поэтому само попадание метки в календарный диапазон не доказывает наличие
крайней свечи. [Видимые свечи в Pine](https://www.tradingview.com/pine-script-docs/concepts/time/#visible-bar-times).

OpenPine закрепляет два точных времени открытия из основного снимка в
плане задания и окружении. Для запуска без явного окна берутся крайние
свечи снимка. Узкие запросы подтверждают наличие внутренних границ перед
запуском. История читается целиком, а сдвиг окна становится отдельным
заданием по явному действию пользователя. Это сохраняет воспроизводимость
и позволяет сопоставить результаты двух окон на одном IR.

При отсутствии поля старые планы и окружения сохраняют прежнее wire-
представление. В снимках и IR используются существующие схемы.
[Профиль](../VISIBLE_RANGE.md).
