# ADR-0082. Две даты видимости финансового отчёта

Дата 2026-11-19. Статус accepted.

Справочник TradingView относит финансовые данные к началу следующего фискального периода. Для воспроизведения торговых решений OpenPine дополнительно нуждается во времени фактической публикации. Источник должен явно передать обе даты. Границы финансового календаря могут отличаться от календарных кварталов. [Справочник](https://www.tradingview.com/support/solutions/43000564727-what-financial-data-is-available-in-pine/).

Историческое задание использует последнюю ревизию периода внутри закреплённого снимка с начала следующего периода. Такой бэктест может открыть позицию до публикации. Replay использует более позднюю из границы и момента публикации. Исправление старого периода после появления более свежего отчёта сохраняет текущий период. Валютный курс определяется в момент видимости строки. Это решение профиля OpenPine, внешняя сверка TradingView остаётся отдельным этапом.

Оба индекса строятся один раз при открытии снимка. Идентичность снимка и время наблюдения определяют восстановление. Для EPS по финансовому периоду и событийного earnings источник предоставляет самостоятельные потоки. [Ручной эталон](../FINANCIAL.md).
