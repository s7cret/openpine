# ADR-0016. Ссылки точек и снимки рисунков

Дата 2026-11-05

Статус accepted

## Контекст

`chart.point` в Pine v5–v6 является ссылочным типом. Рисунки берут
координаты из точки при вызове. Документация показывает повторное
изменение `price` при создании нескольких независимых линий.
[Типы Pine](https://www.tradingview.com/pine-script-docs/language/type-system/#reference-types) ·
[Пример Pine v5](https://www.tradingview.com/pine-script-docs/v5/concepts/lines-and-boxes/)

## Решение

Встроенный тип имеет фиксированную раскладку `time`, `index`, `price`.
Heap использует существующие записи, ссылки, квоты и копирование при
записи. Поля точки участвуют в обычном откате открытой свечи.

Конструкторы и сеттеры рисунков выбирают X по `xloc` и передают
скалярные координаты в существующий runtime рисунков. Это сохраняет
геометрию при изменении или освобождении исходной точки. Выбранное
поле со значением `na` передаётся как отсутствующая координата.

## Последствия

Typed IR .30 и runtime-state .22 закрепляют закрытую раскладку точки.
Журнал и API графика используют принятые записи рисунков с `xloc`.
Чтение всех полей и запись `price` входят в [профиль](../CHART_POINTS.md).
Случаи с отсутствующими координатами проверяются по внутренней
модели OpenPine. Сверка с TradingView проводится отдельно.
