# ADR-0010. Общий жизненный цикл меток и линий

Дата 2026-11-03

Статус accepted

## Контекст

У метки одна точка, а отрезок может пересекать окно графика, даже когда обе
его точки находятся снаружи. При этом подтверждение бара, выделение ID,
вытеснение и восстановление одинаковы для обоих видов объектов.

## Решение

Runtime переиспользует общую реализацию жизненного цикла с закрытыми
записями и отдельным счётчиком для каждого вида. При паузе оба снимка
сохраняются вместе с подтверждённым курсором. Журналы используют общий
механизм CAS-частей и отдельные схемы событий.

Программы с линиями используют typed IR .25, runtime-state .17 и
output-prefix .5. Для программ только с метками действуют прежние схемы
и форма событий. Выбор схемы зависит от операций и типов в программе.

## Последствия

API выбирает отрезки по пересечению диапазонов. Renderer обрезает их
перед расчётом шкалы, поэтому невидимые концы не растягивают ось цен.
В [профиле линий](../LINES.md) отделены правила OpenPine и границы
внутренней проверки.
