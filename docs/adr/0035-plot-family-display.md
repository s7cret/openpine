# ADR 0035. Места вывода меток и OHLC

Дата 2026-11-09

Статус accepted

Закреплённые сигнатуры v5–v6 и справочник v5 допускают один тип
`plot_display` для шести функций `plot*`. В том числе справочник
показывает выражение с `display.price_scale`. Руководство по отладке
уточняет, что `plotshape`, `plotchar` и `plotarrow` не выводят данные
на шкалу. Для `plotbar` и `plotcandle` обзор указывает последнее
значение `close` на шкале и четыре значения в числовых панелях.
[Справочник v5](https://www.tradingview.com/pine-script-reference/v5/)
· [Отладка Pine](https://www.tradingview.com/pine-script-docs/writing/debugging/)
· [Обзор](https://www.tradingview.com/pine-script-docs/visuals/overview/#display-in-other-locations)

Принимаем флаг шкалы для всех шести функций в выражении. Метки и
стрелки используют панель, статус и окно данных. OHLC использует
все четыре места. Правило исходной свечи, замороженный выбор и
совместимость старых перегрузок продолжают
[решение для числового plot](0034-plot-destinations.md).

Расширенные перегрузки `plotshape` и `plotchar` сохраняют исходное
значение с типом bool/int/float в существующем скалярном слоте.
Renderer отдельно преобразует его в координату. Это различает
ложное условие, числовой ноль и пропуск в статусе и окне данных,
сохраняя геометрию старых результатов. Для OHLC скалярный слот
сохраняет `null`, а `last_close` строится в представлении графика
из последнего подтверждённого OHLC-образца той же публикации.
Когда образец находится за окном, чтение охватывает один бар.
Миграция данных не требуется. [Профиль](../PLOT_FAMILY_DISPLAY.md)
