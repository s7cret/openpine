# ADR 0028. OHLC как визуальный слой

Дата 2026-11-07

Статус accepted

`plotcandle` и `plotbar` вычисляют четыре цены на исходном баре.
Пользователь управляет слоем целиком через легенду и `force_overlay`.
Один ID связывает цены и цвета при чтении окна, восстановлении и
обновлении открытого бара. Четыре независимых числовых ряда потребовали
бы повторно собирать каждую фигуру в потребителях.

Статические свойства хранятся в дескрипторе, значения и цвета бара
записываются одним объектом в существующей строке Parquet. Скалярный
слот остаётся пустым. В памяти `bars` выровнен по индексам наблюдений.
Потоковый checkpoint хранит метаданные слоя и префикс результата.
Typed IR `.23` уже различает визуальные вызовы по ABI. В нём добавлен
новый тип презентации `openpine.ohlc-layer.1` с отдельной проверкой
строк, дескрипторов и состояния. Рынок поставляет исходные свечи, а
презентация вычисленных свечей принадлежит runtime и результату.

Журнал TradingView датирует появление функций июнем 2015 года. Снимок
v1/v2 содержит имена без полных сигнатур. Для этих версий выбран
реконструированный позиционный срез из четырёх цен, заголовка и цвета.
Цвета тени и рамки подтверждены начиная с v3, `force_overlay` с v5.
Справочник описывает пропуск при `na` и нормализацию экстремумов.
Детали оформления по умолчанию закреплены в профиле OpenPine.
