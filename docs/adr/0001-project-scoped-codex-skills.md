# ADR-0001: Локальные навыки Codex для OpenPine

Дата: 2026-11-01
Статус: accepted

## Контекст

OpenPine уже имеет собственные проверки спецификации, native/installed suites,
source-bound CI, общий wheel и проверки восстановления. Пользователь одобрил
адаптацию трёх выбранных навыков Superpowers/ECC и создание собственного навыка
приёмки только для OpenPine. Полная установка фреймворков добавила бы общие
процессы и настройки вне нужного набора.

## Решение

Хранить четыре независимых навыка `openpine-debugging`,
`openpine-verification`, `openpine-adr`, `openpine-acceptance` в
`.agents/skills/` этого репозитория. Сторонние процедуры адаптировать к R6,
сохранить MIT-уведомления и закрепить исходные коммиты. Собственную приёмку
строить поверх существующих инструментов, не создавая второй gate.

Для текущего запуска из родительского workspace использовать локальные junction
на те же каталоги. Глобальные каталоги навыков и настройки Codex не менять.
Автоматический выбор навыков оставить стандартным; срабатывание ограничить
описаниями конкретных задач.

## Рассмотренные альтернативы

- Полная установка обоих наборов: добавляет невыбранные навыки, bootstrap,
  общие процессы и пересекающиеся инструкции.
- Дословное копирование трёх `SKILL.md`: сохраняет неперенесённые зависимости
  и требования к повторному согласованию/перезапускам проверок.
- Только правила в `AGENTS.md`: просты, но подробные процедуры загружаются
  даже тогда, когда задача их не требует.
- Глобальная установка: затрагивает другие проекты вопреки выбранной области.

## Последствия и проверка

Навыки изменяются вместе с проектом и применяются выборочно. Их команды и
источники нужно поддерживать при изменении инструментов. Обновления upstream
проверяются вручную по закреплённым ревизиям; скрытого auto-update нет.

Application fingerprint и wheel не включают сами файлы навыков. Их структура,
ссылки, команды и поведение проверяются отдельно; старая application-приёмка
не выдаётся за тест новых инструкций.
