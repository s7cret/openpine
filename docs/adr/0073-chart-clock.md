# ADR-0073. Закрепление границы графика

Дата 2026-11-17

Статус accepted

`last_bar_time` и `last_bar_index` должны быть доступны в начале
исторического вычисления. `bar_index` и координаты свечи описывают
текущий курсор. В разреженном ряду разница во времени между
свечами слабо связана с их порядковым номером.
[Историческая граница в Pine](https://www.tradingview.com/pine-script-docs/concepts/time/#last_bar_time).

Историческая граница берётся из манифеста выбранного снимка, а для
входа в памяти из идентичности загруженного ряда. Если программа
использует эти переменные, в окружении фиксируются число свечей
и время открытия последней. Сохранённое состояние проверяет хэш
окружения. Запрошенный контекст закрепляет свой снимок тем же способом.

В replay историческая граница определена входными метаданными.
Индекс задаётся явно и сверяется с парой время/позиция по ходу
чтения событий и при восстановлении. Для новой свечи переменные
используют координаты текущего наблюдаемого кадра. Кадр уже
передаёт порядковый номер в своём контексте, поэтому checkpoint
переиспользует существующий курсор активной и подтверждённой
свечи. Дополнительного буфера событий или свечей не требуется.
Поле индекса в конфигурации добавляется при его наличии.

В UTC 24×7 завершение торгового дня на границе старшего периода
вычисляется из его исключающего закрытия. Для W/M берётся день,
которому принадлежит последняя миллисекунда периода. Это правило
покрывает непрерывный календарь текущего профиля.
[Торговый день в Pine](https://www.tradingview.com/pine-script-docs/concepts/time/#time_tradingday) ·
[Профиль и сценарии](../CHART_CLOCK.md).
