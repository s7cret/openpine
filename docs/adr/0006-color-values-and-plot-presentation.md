# 0006. Цвет — типизированный RGBA token, представление plot идёт рядом с числами

Статус: accepted. Дата: 2026-11-03.

Пользователь одобрил семь пунктов этапа цветов: правила версий, тип и операции,
существующие конструкции языка, plot/API/график, восстановление и приёмка.
Было нужно провести цвет через общий интерпретатор и существующее хранение
рядов без изменения семантики старых числовых программ.

Выбран отдельный `ValueType('color')` с каноническим `#RRGGBBAA` token.
Сохранённый token является строкой JSON, но Binder не допускает преобразование
из Pine string. Runtime и checkpoint проверяют каноничность по объявленному
типу. Это продолжает существующий подход к номинальным scalar tokens для enum.
Отдельный heap и mutable color object не нужны; фиксированное значение проходит
через прежние коллекции, scalar history и varip без новой схемы heap.
Упаковка в число создала бы риск путаницы с числовой арифметикой; новый Python
класс потребовал бы дополнительных тегов во всех потоковых scalar codecs.

Для styled plot создан закрытый `colors.plot` ABI. Обычный двухаргументный
`visual.plot` сохраняется. Выход содержит прежний числовой ряд и независимое
представление: цвет каждого бара, постоянные ширину и стиль. Parquet сохраняет
прежнюю физическую схему с JSON-столбцом; только styled строки содержат пару
`{value,color}`. Числовые читатели снимают это представление, график получает
его явно. Оптимизация и сравнение числовых рядов не начинают считать цвет числом.

Новый IR21 ограждает новые типы и контракты. State13 ограждает параметры и
цветовой префикс выхода; прежние программы выбирают прежние схемы. Ветки
preview получают собственные выходы, а подтверждённые точки публикуются на
прежней успешной границе бара. Квоты и таймауты не увеличиваются.

Имена ранних версий взяты из закреплённого Wiki. Точная ранняя RGB-палитра и
HEX-доступность не установлены; v1–v3 реализованы как явная реконструкция.
Изменение red/teal/yellow в v6 подтверждено
[официальной миграцией](https://www.tradingview.com/pine-script-docs/migration-guides/to-pine-version-6/#color-changes).
Квантование, границы градиента и ограниченный renderer записаны в
[профиле цветов](../COLORS.md). Первые пять позиционных аргументов plot
сохраняют Pine-порядок; поздние параметры не сдвигаются в освободившиеся позиции.

Ручные конечные ожидания, сохранённый IR, heap/history, все разрезы восстановления,
CLI/HTTP/Parquet и browser pixels проверяются раздельно. Они подтверждают модель
OpenPine, не внешнее выполнение TradingView. При появлении внешних наблюдений,
требующих других правил округления, ранней палитры или визуальных объектов,
нужно добавить версию профиля и явную миграцию вместо изменения старого bundle.
