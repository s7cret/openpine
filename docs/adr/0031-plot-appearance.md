# ADR 0031. Архивные сигнатуры plot и опорная линия

Дата 2026-11-08

Статус accepted

Закреплённый справочник v1–v2 даёт две записи `plot`. В одной
`style` стоит перед `linewidth`, в другой порядок обратный.
Поддерживаем обе формы отдельными ABI. Форма со стилем впереди
определяется по типу четвёртого аргумента. В форме с шириной впереди
шестой bool выбирает `trackprice`, а шестой int выбирает прежнюю
короткую форму с `transp`. Вызов длиннее шести аргументов проходит
проверку архивной формы. Архивный `offset` использует тот же предел
±10 000, что и современный профиль.
[Справочник v1](../../spec/bundles/pine-spec-20261020.1/reference/v1.json) · [Справочник v2](../../spec/bundles/pine-spec-20261020.1/reference/v2.json)

Справочник описывает опорную линию на последнем значении индикатора.
OpenPine трактует его как значение последнего бара расчёта и берёт
цвет этого бара. Если последний бар даёт `na`, линия исчезает.
Так история и replay могут использовать тот же терминальный
отсчёт независимо от страницы. Префикс результата хранит цвет
вместе с существующим полем последнего значения. Открытый бар
даёт отдельный временный отсчёт для браузера.
[Справочник v5](https://www.tradingview.com/pine-script-reference/v5/#fun_plot) · [Параметры plot](https://www.tradingview.com/pine-script-docs/visuals/plots/#plot-parameters)

Справочник v5–v6 определяет ступени с ромбами и с разрывами.
OpenPine помещает ромб в координате отсчёта, на котором изменилось
значение. Чтение диапазона захватывает один предшествующий отсчёт
этого стиля. Пиксельное совпадение и поведение в пограничных
случаях проверяются отдельно.
[Справочник v5](https://www.tradingview.com/pine-script-reference/v5/#var_plot.style_stepline_diamond)
