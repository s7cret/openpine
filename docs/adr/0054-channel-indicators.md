# ADR 0054. Сигнатуры и прогрев каналов волатильности

Дата 2026-11-13. Статус accepted.

[Закреплённый bundle](../../spec/lock.json) подтверждает `series int` для
`bb` и `bbw` в v4–v6. Динамический `bb` получает отдельный контракт и
состояние префиксных сумм. Фиксированная длина `bb` сохраняет существующий
контракт, арифметику и формат checkpoint. `bbw` использует те же префиксы,
что и динамический `bb`. Ширина рассчитывается как удвоенное отклонение
от средней, делённое на среднюю. Такая форма сохраняет ширину при
округлении границ и даёт `na` при нулевой средней.

Для `kc` и `kcw` в v4 перечислены обе формы вызова, в v5 есть две
перегрузки, а в v6 есть запись с четырьмя параметрами. У последнего указано
значение `true` при отметке «required». В OpenPine значение по умолчанию
разрешает трёхаргументную форму и использует True Range. Это согласуется
с явно описанной формой v4/v5. Для v1–v3 сохранён прежний допуск `bb`,
реконструированный по архивным материалам.

Расчёт Keltner использует EMA рыночного диапазона, как в примере функции
из [справочника Pine v4](https://pl.tradingview.com/pine-script-reference/v4/#fun_kc).
Выбор источника инициализации EMA следует действующему профилю R6 для
соответствующей версии. Неявные рыночные аргументы закрепляются в IR,
включая ссылку на физическое предыдущее закрытие текущего контекста.
Прогрев, пропуски, значение по умолчанию v6 и нормализация при нулевой
средней проверяются на модели OpenPine. Для сравнения с TradingView
потребуется внешний запуск.
