# ADR 0055. Прогрев и состояние трендовых индикаторов

Дата 2026-11-13. Статус accepted.

[Закреплённый bundle](../../spec/lock.json) содержит SAR для v1–v6 и
DMI и Supertrend для v4–v6. Два результата Supertrend в bundle описаны
как `series float`, поэтому направление хранится как `-1.0` или `1.0`.
[Руководство по миграции](https://www.tradingview.com/pine-script-docs/v5/migration-guides/to-pine-version-5/).

Для DMI используем сглаживание Уайлдера. Сначала отдельно сглаживаем
направленные движения и True Range, затем рассчитываем их отношения.
Ещё одна RMA сглаживает нормированную разность DI. Плоский рынок до
первого ненулевого сглаженного диапазона оставляет DI и ADX в `na`.
Последнее определённое DI сохраняется при пропуске расчёта.
[Описание DMI](https://www.tradingview.com/support/solutions/43000502250-directional-movement-dmi/).

Для Supertrend используем имеющийся ATR и сохраняем обе границы.
При пропуске множителя границы и направление начинают прогрев заново
при следующем определённом множителе, используя накопленный ATR.
[Формула Supertrend](https://www.tradingview.com/support/solutions/43000634738-supertrend/).

SAR использует инициализацию и ограничение двумя предыдущими свечами
из примера справочника. Равные закрытия задают нисходящее направление.
Неявные рыночные аргументы закрепляются в IR и проверяются при чтении.
В checkpoint хранятся только скаляры индикаторов и поля существующих
RMA. Сравнение с исполнением TradingView остаётся отдельной проверкой.
[Справочник Pine v4](https://pl.tradingview.com/pine-script-reference/v4/#fun_sar).
