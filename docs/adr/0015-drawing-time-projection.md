# ADR-0015. Время рисунка и позиция на графике

Дата 2026-11-04

Статус accepted

## Контекст

Pine v4–v6 позволяет задавать координаты рисунков по времени или
индексу. Пагинация и разрывы в данных требуют стабильной проекции
на одну ось графика. [Справка Pine v4](https://www.tradingview.com/pine-script-docs/v4/essential/drawings/)

## Решение

Runtime хранит исходный X и режим координат. API окна вычисляет
глобальную позицию по соседним свечам. Отдельные поля `chart_*`
сохраняют различие между вычисленной позицией и Pine-координатой.
Точная метка времени соответствует свече. Между свечами
используется линейная интерполяция, по краям интервал ближайшей
пары. Это правило OpenPine проверяется отдельными сценариями.

Исторический запрос читает временную колонку нужных блоков
Parquet и учитывает границы снимка. Для replay с режимом
координат каталог SQLite индексирует закрытия первичного
контекста в транзакции приёма событий. Окно читает только
опубликованный префикс. Предпросмотр добавляет текущую открытую
свечу к этой оси. Диагностический replay может получить
временную ось из общего закреплённого журнала.

## Последствия

Typed IR .29 и runtime-state .21 применяются к конструкторам с
явным `xloc`. Формат записи рисунка принимает поле `xloc`, а старые
записи читаются в режиме индекса. Каталог v17 добавляет индекс
без пересчёта прежних replay. Правила проекции и границы описаны
в [профиле OpenPine](../DRAWING_XLOC.md).
