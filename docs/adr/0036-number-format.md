# ADR 0036. Формат графика как метаданные результата

Дата 2026-11-09

Статус accepted

Закреплённые сигнатуры различают архивный `precision` декларации,
`format` в v4 и параметры каждого ряда в v5–v6. В современном
описании параметры ряда наследуются из декларации независимо.
Для `volume` действуют собственные правила представления.
[Закреплённая спецификация](../../spec/lock.json)
· [История Pine](https://www.tradingview.com/pine-script-docs/release-notes/#december-2023)
· [Декларации](https://www.tradingview.com/pine-script-docs/language/declaration-statements/#format-and-precision)

Добавляем перегрузки только для явных параметров. При запуске
собираем декларацию и переопределения рядов по ID в одну запись
`number_format`. В checkpoint источником записи остаются проверенный
IR и замороженные входы. При восстановлении запись собирается из
тех же данных. Метаданные не входят в значения Parquet и не влияют
на брокерскую политику. Для стратегии добавление параметров сохраняет
позиции всех торговых аргументов.

В OpenPine `inherit` без явной точности использует десятичный масштаб
закреплённого шага цены, когда он доступен. Файловый снимок без этих
метаданных сохраняет обычное отображение. Архивный профиль поддерживает
явную точность, включая 4 знака из архивного описания. Декларации без
параметров и старые результаты продолжают использовать прежний формат.
Новые строки отображения используют локаль интерфейса. Сверка точной
строки с TradingView остаётся отдельной проверкой.
