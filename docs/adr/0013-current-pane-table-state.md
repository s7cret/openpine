# ADR-0013. Текущее состояние таблиц в панели

Дата 2026-11-04

Статус accepted

## Контекст

Таблица привязана к позиции в панели. Содержимое зависит от текущего
состояния скрипта, а запрос окна свечей меняет только диапазон графика.
Профиль использует общие правила ссылок и rollback визуальных объектов.
[Документация Pine](https://www.tradingview.com/pine-script-docs/visuals/tables/)

## Решение

Runtime хранит разреженный снимок таблиц и счётчик ID. Ячейки принадлежат
неизменяемой записи таблицы. Предпросмотр открытого бара получает копию
набора записей и заменяет только изменённые таблицы. Новый ID в занятой
позиции вытесняет прежнюю таблицу после проверки лимита.

Checkpoint и итоговый результат содержат текущий снимок. Запрос
графика возвращает его целиком, а replay показывает снимок своего
текущего шага. Это позволяет использовать существующий поток
подтверждения и восстановления без журнала с копиями таблиц на
каждом изменении.

## Последствия

Для скриптов с таблицами предусмотрены Typed IR .27 и runtime-state .19.
Выходной префикс определяется рядами и журналами присутствующих
рисунков. Память ограничена числом выделенных ячеек и длиной текста.
Проверки разделяют подтверждённый снимок и предпросмотр, в том числе
после паузы и продолжения. [Профиль таблиц](../TABLES.md)
