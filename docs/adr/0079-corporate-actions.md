# ADR-0079. Снимок корпоративных событий и момент видимости

Принято 2026-11-18 для исторических заданий и записанного replay.

Свечной провайдер подтверждает OHLCV. У дивидендов и сплитов собственные поля, валюта, границы покрытия и время публикации. Для каждого источника импортируем отдельный JSON-снимок, нормализуем порядок потоков и событий, сохраняем его в существующем хранилище по SHA-256 и закрепляем ссылку в SQLite. Исправленная выплата получает новую идентичность. Исходное задание продолжает ссылаться на прежнюю редакцию.

Внутри потока ключ записи — время действия. Одинаковые повторы сворачиваются, несовместимые записи требуют исправления до импорта. Время первой видимости равно максимуму времени действия и времени доступности. При совпадении видимости нескольких событий выбирается последнее по времени действия. Бинарный поиск по разделяемому индексу разрешает запрос как функцию снимка и часов бара. Для восстановления достаточно закрепить SHA-256 и уже сохраняемый курсор основного бара. Preview дополнительно ограничен временем последнего полученного наблюдения.

Такое определение воспроизводимо для разреженных данных, опоздавшей публикации и повторной доставки. Порядок событий внутри интервала, правила поставщика и точное совпадение с TradingView требуют внешнего сравнения. Примеры и версионные границы приведены в [профиле](../CORPORATE_ACTIONS.md).
