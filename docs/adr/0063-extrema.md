# ADR 0063. Окно размаха и накопительные экстремумы

Дата 2026-11-15. Статус accepted.

В закреплённом справочнике `range` доступен с v4, динамическая длина
указана во всех поддерживаемых версиях. Справочник v4 приводит два типа
результата в одной записи, а v5 и v6 — в двух. В OpenPine числовой тип
результирующего ряда выводится из типа источника. Это сохраняет разность соседних
целых чисел выше точного диапазона binary64. Переполнение даёт диагностику.
[Справочник Pine](https://www.tradingview.com/pine-script-reference/v6/#fun_ta.range).

Размах накапливает только определённые значения и запрашивает текущую
длину после полного прогрева. `highest/lowest` в существующем профиле
работают на окне достигнутых вызовов и используют доступные значения при
прогреве. Размах хранит минимум и максимум в одном узле существующего
дерева, поэтому поиск границ выполняется за один проход по дереву.
Долговременный checkpoint содержит плоские значения листьев. При чтении
дерево строится заново, а предпросмотр пишет только в слой изменённых ячеек.

Накопительные `ta.max/min` работают на всём префиксе контекста и хранят
один экстремум на вызов. Архивные математические `max/min` сохраняют
собственный ABI. Сверка пограничных результатов с исполнением TradingView
остаётся отдельным этапом. [Примечания к выпуску Pine](https://www.tradingview.com/pine-script-docs/release-notes/#august-2022).
