Python 3.14.8, CI 57/57, один wheel.
Windows — 2083 успешных тестов. Linux — 2082 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4841 прежних наблюдений conformance
сохранены. Добавлены 20 расчётных сценариев и 10 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. Новый подтверждённый максимум вызвал одно
оповещение с размахом из двухминутного контекста.

Размах проверен в Pine v4–v6, накопительные экстремумы в v5–v6.
Проверены целочисленная точность, пропуски, динамическая длина и
файловое восстановление окна на 100 000 значений. Первичные формы
`highest/lowest` и математических `max/min` проверены по версиям.
Сравнение с исполнением TradingView остаётся отдельным этапом.
