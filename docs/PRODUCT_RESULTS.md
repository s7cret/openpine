# Смешанные результаты и результаты циклов

Профиль `openpine.product-results.1` расширяет прежние ограничения composite,
objects и loops, сохраняя исходные bundles. Решение и совместимость:
[ADR 0005](adr/0005-ephemeral-product-results.md).

| Форма | v1–v3 | v4 | v5/v6 |
| --- | --- | --- | --- |
| Scalar tuple UDF/if/switch | Прежний профиль, ранние версии реконструированы | Да | Да |
| Tuple с primitive array | — | Да | Да |
| Enum/UDT/map/matrix компоненты | — | — | Да |
| Строковый результат for | С v2 | Да | Да |
| Результат while/for-in | — | — | Строка, enum, ссылка, mixed tuple |

Tuple распаковывается только в новые переменные и `_`; все элементы вычисляются
один раз в порядке записи. Qualifier общий. Типы ссылок должны совпадать точно;
scalar int/float в ветках могут продвигаться в float. Ветки tuple требуют
явного else/default. Пустой цикл возвращает missing каждого компонента,
bool v6 — false. Break/continue сохраняют последний завершённый хвост.

Поддержаны алиасы, shallow copy, история распакованных ссылок, существующие
правила var/varip/rollback и восстановление. Прямые вложенные коллекции,
tuple-параметры, целый tuple в переменной/истории, tuple-тернарный оператор,
новые request-формы и графические типы в этот профиль не входят.

Новые конструкции используют typed-ir.20, состояние — прежние feature codecs.
Проверки: `tests/test_product_results.py`, независимые
`conformance/product-results`, восемь `product-results-*` программ в общем
корпусе. Их ручные ожидания проверяют внутреннюю модель; выполнение TradingView
не подтверждалось.

Checkpoint diagnostics сохраняются в `checkpoint-timings.json` попытки: последние
16 записей, без изменения checkpoint manifest. Отдельно измерены захват состояния
и выходов, canonical object encoding, запись/публикация объектов и обход с
валидацией. Последний показатель включает чтение для проверки codec; это не
чистое CPU-время. `manifest_seconds` — включённый замер публикации manifest,
его encode/write также входят в соответствующие суммарные показатели.
Медленные сохранения (от секунды) записывают фазы в stderr воркера.
Квоты, таймауты, число CI jobs и workload восстановления сохранены.

Installed receipts сохраняют число файлов/замеров и максимумы фаз до удаления
временных каталогов. Суммы относятся только к последним 16 замерам каждой
попытки, а не к полному времени задания; при отказе сводка идёт в stderr.
