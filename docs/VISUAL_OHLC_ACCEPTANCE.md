# Приёмка вычисляемых свечей и баров R6

[Исходник 4a7f34f58d3a](https://github.com/s7cret/openpine/commit/4a7f34f58d3a6722878739ff456569afe4809b67) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42400641183) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42400645636)

CI 57/57, Python 3.14.8, 1 897 тестов в реестре каждой ОС, 4 222 сценария conformance, 180 программ корпуса.

- OpenPine исполняет plotcandle и plotbar для Pine v1–v6. Проверены пропуски,
  нормализация экстремумов, цвета и размещение по панелям.
  Одиннадцать браузерных сценариев прошли в Chrome.
- Сценарии Parquet, сохранённого IR, checkpoint и перезапуска
  replay подтвердили форму OHLC-слоя и порядок наблюдений.
- На Windows прошли 1 897 тестов, на Linux — 1 896.
  Проверка файловых псевдонимов Windows 8.3 на Linux ожидаемо пропущена.
  Обе ОС использовали один wheel. Проверены четыре сценария восстановления.
- Совпали результаты всех 4 188 прежних сценариев. Добавлены 34 сценария в профиле OHLC, из них 14 исполнений
  и 20 ожидаемых отказов. Все отчёты совпали между Windows и Linux.
- Сигнатуры v1/v2 реконструированы. Матрица отмечает обе функции
  как PARTIAL. Сверка с TradingView относится к отдельному этапу.

В первом запуске паспорт программы обращался к прежнему имени
проверки сигнальных вызовов. Имя восстановлено, паспорт различает
сигналы и OHLC-слои. Исправленный кандидат прошёл повторную приёмку.
