# Этап: динамические сигнальные окна

1. Матрица семи функций v1–v6, evidence и сохранение фиксированных ABI.
2. VWMA: пары source/volume, точные префиксы, NA и нулевой объём.
3. MOM/ROC: физические вызовы, изменяемое расстояние и нулевой знаменатель.
4. Тренд и смещения: strict comparisons, latest ties и диапазонное дерево.
5. Compiler/runtime, UDF, циклы, private contexts, checkpoint/restore и preview.
6. Файл, CLI/HTTP, worker, исследования, live/replay и практические примеры.
7. Независимые оракулы, регрессии, миллион событий, установленный wheel,
   Windows/Linux на Python 3.14.8, публикация Git и локальная Wiki.

Приёмка будет закреплена исходным commit и оригинальными квитанциями.
Qualifiers v1–v3 — реконструкция; v4–v6 подтверждены артефактами.
Точная сверка с TradingView остаётся отдельно.
