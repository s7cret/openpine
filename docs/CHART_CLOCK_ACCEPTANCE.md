Python 3.14.8, CI 57/57, один wheel.
Windows — 2139 успешных тестов. Linux — 2138 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены все 5174
прежних наблюдений.
Добавлены 14 исполняемых сценариев и
11 ожидаемых отказов.

На общем wheel CLI прочитал IR, сохранённый HTTP-компилятором.
Исторические воркеры восстановились после второй свечи. Граница
снимка осталась на индексе 4, заявка появилась на индексе 3.
Replay закрепил начальную границу на третьей полученной свече
и возобновился после открытия следующей. Граница выросла
с индекса 2 до 3 и 4. Нативные проверки дополнительно сверили
ревизии открытой свечи, повтор событий и отдельную границу
запрошенного контекста.

В статической матрице переменные имеют статус PARTIAL.
Границы истории и торгового дня UTC 24×7 описаны в [профиле](CHART_CLOCK.md).
Сравнение с исполнением TradingView ведётся отдельно.
