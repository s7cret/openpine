# Идентификаторы рынка и HA-свечи

| Версия | Доступный профиль |
| --- | --- |
| v1 | У функции `tickerid` отсутствует закреплённая сигнатура. Вызов отклоняется с `SIGNATURE_UNAVAILABLE`. |
| v2 | Позиционный `tickerid(prefix, ticker)`. |
| v3–v4 | `tickerid(prefix, ticker)`, в том числе с именованными аргументами. |
| v5–v6 | Фиксированные `ticker.new(prefix, ticker)`, `ticker.standard(symbol)`, `ticker.modify(tickerid)`, `ticker.inherit(from_tickerid, symbol)`. |

У `ticker.new` доступны компоненты основного рынка из `syminfo.prefix` и `syminfo.ticker`.
Результат `ticker.standard` запрашивает обычные OHLC. Вызов `ticker.modify` без опций сохраняет режим исходного тикера. При наследовании режим HA переносится на обычный тикер назначения.
Явные настройки сессии и корректировок требуют метаданных источника. Компилятор выдаёт `TICKER_DATA_CAPABILITY` с именем опции. Для динамических series-целей v6 покрытие остаётся MISSING.

Снимок задаётся базовым рынком и интервалом. Обычные и HA-запросы этого рынка разделяют один источник. На исторических младших интервалах рекурсия начинается с первой выбранной дочерней свечи, включая ограничение `calc_bars_count`, и продолжается через границу родительской свечи. В replay и live предварительное обновление использует последнюю подтверждённую пару HA open/close. Закрытие свечи сохраняет следующую пару. Брокер исполняет сделки по ценам основного рыночного снимка.

[Индикатор](../examples/market-tickers/compare.pine) использует минутный основной снимок и двухминутный дополнительный. [Стратегия](../examples/market-tickers/children.pine) использует четырёхминутный и минутный снимки. Данные, привязки контекстов и ручные ожидания приведены в [корпусе](../conformance/market-tickers/cases.json).

Локальный замер на Python 3.14.8, Windows, один минутный источник и две группы запросов. Свечи уже находились в памяти перед запуском `tracemalloc`. Пик относится к историческому проходу. Полный checkpoint включает результаты обычного драйвера.
