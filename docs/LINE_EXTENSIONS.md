# Лучи и чтение цены линии

В Pine v4–v6 индикатор может задать именованный `extend` в
`line.new(x1, y1, x2, y2, extend=…)` и изменить режим вызовом
`line.set_extend(id, extend)`. Поддержаны `extend.none`, `extend.left`,
`extend.right` и `extend.both`. Без аргумента создаётся конечный отрезок.
Доступность перегрузки, getter и констант сверяется с
[закреплённым профилем](../spec/line-extensions-profile.json).

```pine
//@version=6
indicator("Projected level", overlay=true)
var line guide = line.new(0, 10, 1, 20, extend=extend.right)
if bar_index == 2
    line.set_extend(guide, extend.none)
plot(line.get_price(guide, bar_index))
```

`line.get_price(id, x)` возвращает цену по прямой через исходные точки.
Вычисление включает индексы слева и справа от точек при любом режиме
`extend`. OpenPine округляет только итоговое число. Вертикальная линия,
пропуск координаты, удалённая ссылка или выход цены за пределы конечного
`float` дают `na`. Чтение цены не добавляет событий в журнал.
[Справка TradingView](https://www.tradingview.com/pine-script-docs/visuals/lines-and-boxes/#reading-line-values).

Визуальное продление идёт в сторону меньших или больших индексов,
независимо от порядка точек. Вертикальная линия сохраняет исходную длину.
API выбирает линии по пересечению видимого диапазона, а Canvas вычисляет
ценовую шкалу по обрезанной части. Если проекция концов видимой части
выходит за диапазон конечных чисел Canvas, эта проекция пропускается.

Режим сохраняется при паузе и восстановлении. Replay показывает режим
открытого бара в предпросмотре и публикует только подтверждённые события.
В записях прежнего формата без поля `extend` применяется `extend.none`.
Пределы профиля остались прежними для координат по индексу бара.
Сверка исполнения с TradingView проводится отдельным этапом.
