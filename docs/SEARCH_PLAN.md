# Первый optimizer: план и приёмка

- [x] 1. Закреплённый состав поиска: программа, спецификация, схема inputs,
  снимки, оси, seed/алгоритм/бюджет, критерий, ограничения и реализация оценки.
- [x] 2. Полная сетка и воспроизводимый случайный поиск без дубликатов,
  закрытые типы и явный шаг, до 256 вариантов.
- [x] 3. Десятичные метрики, ограничения, детерминированный порядок,
  определённые состояния ошибок/отсутствующих значений/отсутствия сделок.
- [x] 4. Независимые участки подбора и проверки, прогрев без заявок,
  причинная видимость контекстов и закрепление победителя до проверки.
- [x] 5. Обычные experiments/JobManager, общий бюджет, checkpoint/retry,
  pause/cancel, атомарное сохранение, backup/restore и защита корней от GC.
- [x] 6. CLI/HTTP/веб: пространство, периоды, метрики, таблица, графики,
  продолжение и повтор сохранённого плана.
- [ ] 7. Завершить полную приёмку Python 3.14.8: v1–v6, аварийные точки,
  установленный wheel и единый gate Windows/Linux.

Контракты, ограничения и команды: [SEARCHES.md](SEARCHES.md).
