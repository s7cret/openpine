# OpenPine — локальные перегрузки функций и библиотечных экспортов

**Код не опубликован. Полная приёмка этапа 2 не завершена.** Кумулятивная поставка включает numeric/index, explicit methods и consumer libraries из предыдущих архивов.

## Реальный результат

Исправлена архитектурная причина отсутствия обычных перегрузок: несколько функций с одним именем больше не отклоняются и не схлопываются в последнюю запись параметров/возвращаемого типа. Один FunctionCandidates выбирает конкретную декларацию через прежний SignatureResolver. Эту идентичность используют анализ параметров и результата, контекстные доказательства, binder, linker и обычное исполнение функции.

Поддержаны Pine 5/6: различное количество обязательных параметров, различающиеся типизированные сигнатуры, named/default arguments, скаляры, коллекции, UDT/enum, возвращаемые ссылки и кортежи. В библиотеке отбор public/private и исходного модуля выполняется до выбора перегрузки. Локальная семантика не реализована заново в runtime; старый singleton-путь сохраняется.

Добавлен профиль same_version_function_overloads_v6 (6 — ревизия профиля, не только Pine 6). Новые compiler capabilities нельзя объявить или удалить независимо от AST/восстановленного библиотечного контекста. Полностью перехешированные подмены декларации, квалификатора, default и const facts отклоняются повторным анализом bounded AST без исходного текста.

## Проверяемые сценарии

Для f(int x)=>x+1 и f(float x)=>x+0.5 вызовы с 2 и 2.0 дают 3 и 2.5. Сохраняемые счётчики двух перегрузок идут 1/2/3 и 10/20/30; другой записанный вызов в цикле — 3/6/9. История условного вызова срабатывает через фактические вызовы, не пропущенные бары. Возвращаемые массивы и объекты сохраняют намеренные общие ссылки. Проверены SMA с inputs, tuple/loop values, realtime ordinary/varip поля и JSON restore.

Сквозной host-сценарий сохраняет и заново читает артефакт с диска. Два значения на третьем баре равны 3 и 30; отправляется реальный entry qty=33, цена 102 на закрытии либо 103 на следующем открытии. Direct/imported, Pine 5/6, оба транспорта и fill-recalculation проверены. Транспорт compare_modes исполняется in-process; четыре отдельных новых теста требуют настоящего Bubblewrap.

## Установленные wheels и сохранность

Заново собраны wheel/sdist Pine2AST, Ast2Python и OpenPine из чистых git archive функциональных коммитов. Остальные пять пар сохранены из предыдущего согласованного среза. В новом venv без system-site-packages установлены только настоящие wheels и зависимости из offline-кеша; pip check успешен. В отдельных каталогах без production-исходников с python -I повторно прошли 173/177 новых тестов, те же четыре worker отказали. Сопоставлены 537 Python-файлов четырёх production-пакетов. Повторы не прибавлены к основному итогу.

Архитектурная проверка, Ruff изменённых файлов, compileall и экспорт OpenAPI успешны. Всё production-дерево OpenPine и весь UI в этом проходе не изменены. Сохранены selected_regressions, исходные стадии, callable/evidence locks и прежние численные ожидания.

## Неудачные первые попытки

В evidence сохранены исходный duplicate-function отказ baseline, прерванный предварительный full run и первоначальные новые fixtures с недоступными color/int-conversion bindings. Новые fixtures переведены на литерал цвета и типизированное отсутствующее значение; математические ожидания и старые тесты не менялись. Первая общая collection host не имела pytest-asyncio; установлен настоящий offline wheel и выполнена повторная collection без сокращения списка.

Первый wheel-прогон выявил ошибку упаковки тестового стенда: отсутствовали импортируемые пакеты tests/rc6_tests для вспомогательных функций. Восемь producer-тестов и collection host завершились ошибками. Добавлены только пустые __init__.py в копии тестового стенда; production, wheels, исходные тесты и assertions не изменены. Повторный завершённый прогон дал 65/65 producer, 77/77 compiler и 31/35 host; оставшиеся четыре отказа — Bubblewrap. Оба прогона сохранены.

## Граница приёмки

STATE-02 и IMPORT-03 расширены реализованным локальным профилем обычных перегрузок, но остаются partial. Все 16 рабочих пакетов и четыре исходных критерия сохранены. Не приняты смешанные одноимённые семьи функций/методов, межверсионные библиотеки, вся generic/reference матрица, полный version-exact каталог и независимая builtin-поверхность.

Численный индекс текущих pins не пересчитан; прежние UNVERIFIED v5 str.tonumber ожидания не исправлялись и не скрывались. Python 3.11, GitHub CI, полная host/optimizer, frontend/browser и общий benchmark не запускались. Инженерные ожидания не выдаются за TradingView execution export.
