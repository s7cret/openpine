# Обработка текстовых цен в Pine v4–v6

В v4 `tonumber(x)` возвращает series float даже для литерала. Для недопустимой строки OpenPine принимает значение na по аналогии с v5/v6. Описание v4 этот случай оставляет открытым.

В v5/v6 `str.trim(source)`, `str.repeat(source, repeat, separator)` и `str.tonumber(string)` сохраняют сильнейший квалификатор аргументов, включая input. У `str.replace(source, target, replacement, occurrence)` для входа input результат simple.

| Операция | Поведение исторического профиля |
| --- | --- |
| trim | Удаляет крайние пробельные символы Unicode по правилам Python 3.14.8. Внутренние пробелы сохраняются. Для строки из пробелов и na возвращает пустую строку. |
| replace | Заменяет одно непересекающееся совпадение. По умолчанию индекс равен нулю. Отсутствующий индекс совпадения оставляет исходную строку. Пустая цель сопоставляется с границами кодовых точек. Отрицательный индекс вызывает диагностику. |
| repeat | Вставляет разделитель между повторами. Его значение по умолчанию — пустая строка. Ноль повторов даёт пустую строку, отрицательное число вызывает диагностику, отсутствующий аргумент со значением na даёт na. |
| tonumber | Принимает десятичные цифры ASCII, необязательный знак, точку и десятичную экспоненту. Для пробелов, запятой, некорректной записи и переполнения возвращает na. Пример v5/v6 явно обрезает пробелы и заменяет запятую перед преобразованием. |

Операции используют общий бюджет скалярных вычислений и предел 4096 кодовых точек. Для неизменяемого профиля вычисления символа и интервала рыночного запроса действует прежний список операций. Этим границам соответствует PARTIAL для 31 записи закреплённого справочника. Внешнее сравнение с TradingView относится к отдельному этапу.
