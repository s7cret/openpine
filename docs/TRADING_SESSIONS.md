# Торговые часы стратегии

`time()` возвращает открытие текущего бара внутри заданной сессии,
`time_close()` возвращает её расчётное закрытие. Вне окна обе функции
возвращают `na`. В сессии `0900-1130` на часовом графике бар 11:00
получает закрытие сессии в 11:30. Unix-миллисекунды возвращаются как
`series int`. Переменные `time` и `time_close` читают границы графика.
[Документация сессий Pine](https://www.tradingview.com/pine-script-docs/concepts/sessions/).

| Pine | Вызовы | Параметр сессии |
| --- | --- | --- |
| v1–v2 | Позиционный `time(period, session)` | — |
| v3 | `time(resolution, session)` | `input("0900-1130", type=session)` |
| v4 | `time(resolution, session, timezone)`, `time_close(...)` | `input("0900-1130", type=input.session)` |
| v5–v6 | `time(timeframe, session, timezone)`, `time_close(...)` | `input.session("0900-1130")` |

Первый аргумент задаёт минутный интервал текущего графика. В профиле
принимаются его значение, `period` или `timeframe.period` по версии
и пустая строка. Пропущенная или пустая сессия использует текущий
календарь UTC 24×7. Явная сессия задаётся как `HHmm-HHmm[:дни]`,
содержит до восьми непересекающихся окон через запятую или `24x7`.
День 1 — воскресенье, день 7 — суббота. Для окна через полночь дни
указывают день завершения. `2200-0200:2` начинается в воскресенье в 22:00
и заканчивается в понедельник в 02:00. В режиме OpenPine v1–v4 умолчание
для явного окна — будни. В v5–v6 — вся неделя.
[Архив v3](https://ar.tradingview.com/pine-script-docs/v3/essential/sessions-and-time-functions/) ·
[Архив v4](https://www.tradingview.com/pine-script-docs/v4/essential/sessions-and-time-functions/) ·
[Миграция дефолта v4 → v5](https://www.tradingview.com/pine-script-docs/migration-guides/to-pine-version-5/#changed-the-default-session-days-for-time-and-time_close).

Пояс по умолчанию берётся из окружения графика, где действует UTC.
В v4–v6 можно выбрать фиксированное смещение или пояс из закреплённой
IANA-базы. При равномерном минутном графике открытие активного бара
должно совпадать с сеткой от начала окна. Неоднозначная или
несуществующая локальная граница активного окна даёт диагностику.
[Обоснование профиля](adr/0069-trading-sessions.md).

Значение параметра имеет тип `input string`. В вебе редактируется
строка или выбирается одно из объявленных значений. API, CLI и пресеты
используют тот же контракт проверки и закрепляют строку при запуске.
Ограничение первой реализации — текущий бар, простой строковый
аргумент и текущий минутный интервал. Статус в матрице `PARTIAL`.

[Пример](../examples/trading-sessions/entry-window.pine) объединяет
абсолютные даты и торговые часы. На шести минутных барах пресет
`0000-0003` выставляет заявки на индексах 1 и 2. Пресет `0002-0006`
выставляет заявки на 2, 3 и 4. Приостановленное задание продолжает
использовать свою сохранённую строку после изменения пресета.
