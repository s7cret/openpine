# Поиск подстроки по шаблону в Pine v5 и v6

Вызов `str.match(source, regex)` возвращает первое совпадение, начиная с самой левой подходящей позиции. Если совпадения нет, результат — пустая строка. При отсутствующем значении аргумента профиль возвращает na. Для литералов, input и simple результат имеет тип simple string. Если хотя бы один аргумент меняется по барам, результат имеет тип series string.

В скрипте Pine шаблон "\\d+" передаёт поиску одну обратную косую черту перед d. Такой шаблон извлекает первую последовательность цифр ASCII. Для "bid=12.50 ask=13.75" шаблон "[0-9]+[.][0-9]+" возвращает "12.50".

| Синтаксис | Поведение профиля |
| --- | --- |
| Литерал или экранированный метасимвол | Одна кодовая точка Unicode, сравнение с учётом регистра |
| Точка | Любая кодовая точка кроме перевода строки LF |
| Классы и диапазоны | Набор одиночных символов и диапазонов, в том числе отрицание в начале класса |
| ^ в начале, $ в конце | Строгое начало и конец всей строки |
| ?, *, + | Жадное повторение предыдущего атома. Более короткий вариант выбирается, если он нужен для остатка шаблона |

Шаблон ограничен 256 кодовыми точками, исходная строка — 4096. Поиск вычисляет концы совпадений справа налево двумя рядами индексов. До выделения рядов он резервирует работу из общего бюджета текущего бара с учётом длины строки и сложности шаблона. Результат дополнительно учитывается в бюджете вывода.

Неподдерживаемые конструкции, включая группы, альтернативы, обратные ссылки и опережающие проверки, дают диагностику REGEX_PATTERN в месте вызова. Превышение лимита даёт SCALAR_LIMIT. Все четыре перегрузки исторического профиля имеют статус PARTIAL. Вычисление замороженных параметров рыночного запроса использует прежний список операций.
