# Приёмка ценовых зон Pine v4–v6

[Исходник a1eff4f3a8b2](https://github.com/s7cret/openpine/commit/a1eff4f3a8b2787f2b345925b5f4f823b1f90b0b) · [CI 41753489935](https://github.com/s7cret/openpine/actions/runs/41753489935)

CI 57/57, Python 3.14.8, 1838 test ID на ОС, 3771 conformance-наблюдений, 180 программ. Проверены SHA-256 и происхождение всех 57 архивов.
Обе ОС и четыре сценария восстановления использовали wheel
f280cf7fed06fc19faf56062df45c9865b2d53406d46042e2def499fb33dacbc.

- На Windows прошли 1838 тестов. На Linux прошли
  1837 тестов с одним ожидаемым пропуском проверки Windows 8.3.
- Новый набор содержит 6 исполнений и
  15 ожидаемых отказов. Результаты
  3750 прежних наблюдений
  сохранились с обновлённой идентичностью программы.
- Установочные проверки v4–v6 подтвердили восстановление зоны, линии и
  метки с бара 2 и двенадцать событий журнала зон. Replay v6 показал
  заливку открытого бара отдельно от подтверждённой.
- API вернул зону с обоими краями за окном. Chrome проверил оба варианта
  панели, нормализацию углов, обрезку исходных сторон и live preview.
- Все 180 программ корпуса дали одинаковые переносимые
  свидетельства на обеих ОС.

Границы описаны в [профиле](BOXES.md). Сверка исполнения с TradingView
проводится отдельным этапом. Машиночитаемая запись доступна в
