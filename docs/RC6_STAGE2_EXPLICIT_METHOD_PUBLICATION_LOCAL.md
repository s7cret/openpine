# OpenPine — локальная поставка: явные вызовы методов

**Новая поставка не опубликована. Весь этап 2 не принят.**

## Результат

Реализован общий путь локальных `method(object, ...)`, импортированных `library.method(object, ...)` и прежних `object.method(...)` в существующем same-version профиле Pine 5/6. Единый resolver выбирает точную декларацию, compiler использует прежний runtime вызова, состояния и checkpoint. См. подробности в `docs/RC6_STAGE2_EXPLICIT_METHOD_CALLS.md` исходников OpenPine.

Архив кумулятивный: включает предыдущие численные корпуса, единый индекс остатка и исправление идентичности массивов PineLib. Эти изменения не нужно накладывать ещё раз из прежнего архива. При публикации нужно сверить свежую удалённую историю; автоматического push/merge в поставке нет.

## Измеримый прогресс и ограничения

IMPORT-01 теперь `implemented_local_pending_joint`; IMPORT-03 расширен source/visibility/overload проверками и остаётся partial. Все 16 исходных пакетов и четыре критерии сохранены. Это не процент готовности языка. Межверсионные импорты, defaults receiver вне прежнего AST-профиля и полная смешанная function/method overload-семантика не приняты.

Для named arguments зафиксировано сохранение порядка исходной записи. Результат с изменяемым Counter равен 21/43/65 при receiver, записанном после другого аргумента. Это проверяемая инженерная политика, **не независимо снятый результат TradingView** для всех side effects и defaults.

Прежний численный индекс был красным на 10 из 100 групп из-за UNVERIFIED v5 str.tonumber ожиданий. Новый код не изменяет эти строки/expected, не скрывает конфликт и не присваивает новым source pins результат предыдущего запуска. Полный численный индекс текущего кандидата не пересчитан.

## Неудачные первые прогоны

Сохранены исходное воспроизведение дефекта на baseline wheel, первые targeted отказы при разработке и завершённые итоговые XML. Начальные полные прогоны прерваны/не используются как приёмка, поскольку затем уточнены идентичность callee range и bounded feature admission. Итоговые полные parser/compiler/PineLib прогоны сделаны отдельно на зафиксированных commit heads.

В первых новых тестах также исправлены две ошибки предположений: в verifier нужно передавать объявленный trusted producer commit, а nested simple-вызов требует явно simple вторичного параметра. Численные expected, исходные тесты и sandbox policies не ослаблялись.

## Продолжение

История этой поставки содержит все неопубликованные коммиты с баз удалённого methods merge, включая прежний numeric/index блок. `verify_delivery.py` проверяет hashes, восемь source trees и incremental bundles без сети и без исполнения проектного кода. Для переноса применять Git-историю в чистых рабочих копиях, сверив bases; не перезаписывать более свежую RC6 распаковкой старого дерева. Публикация требует отдельной команды пользователя.
