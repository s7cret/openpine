# Stage 2 rolling-statistics independent expectations

The engineering corpus `verification/builtin-rolling-statistics-v1` contains
66 independently authored cases for seven currently bound float signatures in
Pine 5 and Pine 6: highest, lowest, range, median, mode, variance and stdev.
Each case runs through ABI, generated historical, realtime, abort/retry and
JSON checkpoint continuation paths. No expected value is generated by PineLib.

The tables cover finite windows, NA gaps, all-NA inputs, unit lengths, odd-size
medians, mode frequency ties, population/sample estimates and changing estimate
flags. Literal ordered windows and rational squared-deviation formulas determine
the expected values; Decimal square roots use 60-digit precision independently
of the implementation. Even-size median and integer overload semantics are not
claimed by these float cases.

The versioned reference payloads distinguish calendar-bar extrema windows from
the valid-sample windows used by the other five functions. The current execution
model documents full-window warmup for highest; the corresponding lowest/v5
warmup expectations are explicitly labeled inference. These are manual fixtures,
not a TradingView execution export. See the paired parser documentation for
exact official reference and translation identities.

The first execution on each Python had 271 passes and 60 failures out of 331
tests. Twenty failures exposed stale extrema across missing bars; forty exposed
the missing optional `biased` source parameter. These failures are retained.
The expected files were fixed before execution and remain unchanged throughout
the implementation corrections. Runtime state migration, resource boundaries,
native package tests and a coordinated Linux run must also pass before the
whole block can be accepted. Stage 2 remains in progress.
