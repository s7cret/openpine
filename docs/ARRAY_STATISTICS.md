# Разброс числовых массивов в Pine v4–v6

Для массива float функции range, variance и stdev возвращают series float. Для массива int OpenPine выбирает целочисленную перегрузку и отбрасывает дробную часть результата к нулю. Standardize создаёт отдельный массив того же типа. В закреплённом справочнике v4 у каждой функции одна запись с двумя вариантами результата, а в v5/v6 у каждой по две записи с пересекающимися входами. Выбор для int и правила для вырожденных массивов входят в исторический профиль OpenPine.

| Операция | Правило |
| --- | --- |
| range | Максимум минус минимум среди определённых элементов. Для пустого массива и массива только из na возвращает na. |
| variance, stdev | В v4 используется делитель N. В v5/v6 необязательный biased по умолчанию равен true. При false делитель N−1. N — число определённых значений. Для нулевого делителя результат na. |
| standardize | Из каждого определённого значения вычитается среднее, затем разность делится на стандартное отклонение с делителем N. Длина и позиции na сохраняются. При нулевом разбросе все позиции результата получают na. Для пустого исходника создаётся новый пустой массив. |

Например, float-массив [2, 2, 6, 6] даёт размах 4, дисперсию 4, стандартное отклонение 2 и массив [−1, −1, 1, 1]. Выборочная дисперсия — 16/3. Для int-массива [1, 2, 4] целая часть дисперсии равна 1, стандартизованные значения — [−1, 0, 1].

Runtime накапливает точные суммы двоичных значений и их квадратов. Общий сдвиг больших чисел не уничтожает малые различия из-за округления промежуточных сумм. Итоговый float округляется при преобразовании, а переполнение конечного float или положительного предела int64 даёт ARRAY_NUMERIC. Обход учитывается в бюджете работы, результат standardize расходует обычные квоты массива. Во всех 20 записях указан статус PARTIAL. Внешняя сверка с TradingView остаётся отдельным этапом.

## Медиана, мода и процентили

`array.median` и `array.mode` доступны с v4. Оба процентиля и `array.percentrank` доступны с v5. Для всех пяти функций результат имеет квалификатор series и тип элемента массива. Функции читают исходные позиции и сохраняют их порядок. Пустой массив даёт na, в том числе при запросе ранга. Пропуски исключаются из выборки, а ранг самого пропуска равен na.

| Функция | Правило исторического профиля OpenPine |
| --- | --- |
| median | Среднее двух центральных значений при чётной длине, центральный элемент при нечётной. |
| mode | При равной максимальной частоте выбирается наименьшее из значений с этой частотой. |
| percentile_nearest_rank | Для N определённых элементов и процента p берётся элемент с номером max(1, ceil(N × p / 100)) в возрастающем порядке. |
| percentile_linear_interpolation | Линейная интерполяция между соседями на позиции (N − 1) × p / 100, считая от нуля. |
| percentrank | Доля определённых значений, меньших либо равных значению в исходной позиции index, умноженная на 100. Отрицательный индекс поддерживается с v6. |

При получении дробного результата для int OpenPine отбрасывает дробную часть к нулю. Для непустой числовой выборки процент за пределами [0, 100] даёт ARRAY_PERCENTAGE. Для непустого массива недопустимый индекс даёт ARRAY_INDEX. Процент na даёт na. Изменение порядка для расчёта происходит на временной копии и учитывается в бюджете исполнения.

Закреплённые записи задают доступность версий и типы перегрузок. В локальном справочнике для percentrank прямо описаны сравнение «меньше или равно» и результат пустого массива. Индексация интерполяции, обработка смешанных пропусков, выбор между несколькими модами и округление int закреплены как трактовки OpenPine. Поэтому все 22 записи имеют статус PARTIAL до дальнейшей сверки.

## Ковариация, абсолютные значения и условия

`array.covariance(id1, id2)` в v4 возвращает series float с делителем N. В v5/v6 аргумент biased по умолчанию равен true, значение false выбирает N−1. Каждый массив может иметь тип int или float независимо от другого. Для пар [1, 2, 3] и [6, 4, 2] результаты равны −4/3 и −2 соответственно. OpenPine требует равных длин (иначе ARRAY_SIZE) и исключает пару целиком, если хотя бы одно значение na. Пустая выборка, нулевой делитель и неопределённый biased дают na. Точные двоичные значения сохраняются до итогового округления float.

`array.abs(id)` в v5/v6 создаёт отдельный массив исходного числового типа и длины, сохраняя позиции na. При попытке взять модуль минимального int64 результат выходит за границы типа и OpenPine выдаёт ARRAY_NUMERIC.

`array.every(id)` и `array.some(id)` в v5/v6 возвращают series bool. Таблица параметров wiki указывает bool[], а примечание к обеим функциям явно допускает int[] и float[]. Для чисел ноль считается ложью. В профиле OpenPine пропуск также считается ложью. Для пустого массива every возвращает true, some — false. В v5 новый элемент bool без начального значения равен na, в v6 — false.

Парное исключение пропусков, проверка длин, поведение пустых предикатов и переполнение abs закреплены тестами профиля OpenPine. Все 11 версионных записей отмечены PARTIAL, внешняя сверка исполнения остаётся открытой.
