# Приёмка устойчивого запуска и CI

- [x] Единый контракт занятости, причины и Retry-After.
- [x] Ограниченные безопасные повторы CLI и сохранение диагностик.
- [x] Атомарные ключи создания experiment/search/walk-forward, lookup и backup.
- [x] Лёгкий прогресс, управление и резерв соединений под тяжёлой нагрузкой.
- [x] Ожидание и восстановление отправки в вебе.
- [x] Один wheel, отдельная спецификация, модели шардов каждой ОС и проверка полного покрытия.
- [ ] Полная регрессия, независимая приёмка и публикация.

База — `b4535e8`: 855 тестов в 92 модулях и 2074 conformance-примера.
Новые проверки охватывают ограничения повторов, потерю ответа после commit,
перезапуск сервера/клиента, принудительное завершение процесса, rollback,
backup, удаление с сохранением ключа, коррупцию и конкурентные отправки.

Приёмка выполняется на Python 3.14.8, Windows/Linux. Поведение Pine и все
прежние conformance-наблюдения должны сохраниться. Проверка времени CI
отдельно фиксирует устранённые повторы работы; количество успешных jobs само
по себе не заменяет проверку модулей, test IDs и общего wheel.
