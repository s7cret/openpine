# Приёмка зон и полилиний в стратегиях R6

[Исходник 02c7d0d4d108](https://github.com/s7cret/openpine/commit/02c7d0d4d108127572e061e814373ec92359109a) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/43009579176) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/43009579394)

SHA 02c7d0d4d108. CI 57/57, Python 3.14.8. В реестре каждой ОС 1 981 тестов. Conformance охватывает 4 549 сценариев, корпус — 180 программ.

- В Pine v4–v6 проверена зона лимитной заявки, в v5–v6 также проверена полилиния из `chart.point` с координатами по времени. Для ранних версий подтверждены `BOX_VERSION` и `POLYLINE_VERSION`.
- Сравнение со стратегией без рисунков подтвердило те же заявки, исполнения и капитал. Исторический worker восстановил торговый журнал и журналы меток, линий, зон и полилиний из префикса `.8`. Установленный wheel подтвердил совместное восстановление через HTTP на обеих ОС.
- В replay с `calc_on_every_tick` вытеснение зоны и полилинии появилось в предпросмотре до закрытия бара. После возобновления итоговый график и все пять журналов совпали с непрерывным прогоном. Проверены проекция вершин через разрыв в данных и отрисовка обоих объектов в окне стратегии.
- На Windows прошёл 1 981 тест, на Linux — 1 980. На Linux пропущена проверка псевдонимов Windows 8.3. Аудит подтвердил общий wheel и четыре отчёта восстановления.
- Сохранены все 4 537 предыдущих наблюдений. Добавлено 12 сценариев. Отчёты conformance совпадают между Windows и Linux.

Новый сценарий был расположен перед v6-drawings и менял выбор smoke по умолчанию. Порядок прежних сценариев восстановлен, новые сценарии добавлены в конец корпуса. Итоговая приёмка привязана к исправленному коммиту. [Первый запуск](https://github.com/s7cret/openpine/actions/runs/43005889849)

Сверка с исполнением TradingView проводится отдельно.
