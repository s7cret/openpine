CI 57/57, Python 3.14.8, 1829 test ID на ОС, 3715 conformance-наблюдений, 180 программ. Проверены все 57 архивов и их SHA-256.
Установочные проверки на Windows и Linux и четыре сценария восстановления
использовали один wheel `edf12700d105fd8a4836407389ccb9cefab246abdcc8e0506f32d9c0729e0473`.

- На Windows прошли 1829 тестов. На Linux прошли 1828 тестов
  с одним ожидаемым пропуском проверки Windows 8.3.
- Профиль меток добавил 3 успешных исполнения и 14 ожидаемых отказов.
  Прежние 3698 наблюдений сохранили
  результаты, хеши программ обновились с идентичностью реализации.
- В обеих установках v4–v6 проверены пауза после второго бара,
  продолжение с прежними ID, 12 событий и метка, созданная до окна графика.
  Сохранённый IR v6 дал тот же результат через CLI.
- Локальные replay-тесты проверили rollback и восстановление на открытом
  баре, порядок вытеснения и отказ при подмене ID в checkpoint.
  Chrome проверил обновление и удаление меток на обеих панелях.
- Все 180 сценариев корпуса дали одинаковые переносимые
  результаты на обеих ОС. Сохранены прежние файлы спецификации.

Первая попытка Windows OCA остановилась на 332 из 400 баров по лимиту
120 секунд. Локальное восстановление на том же wheel заняло 35 секунд.
