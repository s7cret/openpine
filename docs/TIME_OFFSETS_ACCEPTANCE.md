# Приёмка смещений времени в R6

Python 3.14.8, CI 57/57, один wheel.
Windows — 2128 успешных тестов. Linux — 2127 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Из 5133
прежних наблюдений 5131 сохранили результаты.
Два прежних отказа переведены в выполнение. См. `v5-bars-back` и
`v6-timeframe-bars-back` в [описании профиля](TIME_OFFSETS.md).
Добавлены 5 исполняемых сценариев и
9 ожидаемых отказов.

На общем wheel CLI прочитал IR, сохранённый HTTP-компилятором.
Воркеры Windows и Linux продолжили выполнение после третьей свечи.
Оба пути дали вертикальные линии 1, 2 и 6 марта 2024 года в полночь UTC.
Нативные проверки также подтвердили отсутствие чтения будущих свечей,
изменение зафиксированного таймфрейма через настройки и
неизменность подтверждённой истории при realtime-просмотре.
Локальный прогон на 10 004 разреженных свечах проверил два смещения
по 5000 и возобновление после заполнения кольцевого буфера.

В статической матрице перегрузки имеют статус PARTIAL.
Сравнение с исполнением TradingView ведётся отдельно.
