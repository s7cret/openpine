проверка коротких путей Windows 8.3.

Все 4591 прежних наблюдений conformance
сохранены; добавлены девять расчётных сценариев и девять ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
прогон через HTTP восстановил состояние окна в середине открытой свечи
и записал следующее оповещение с подставленным значением стохастика.

[Профиль](WINDOW_INDICATORS.md) охватывает Pine v1–v6. В v4–v6
поддерживается изменяющаяся длина. Сравнительный запуск TradingView
в приёмку не входит.
