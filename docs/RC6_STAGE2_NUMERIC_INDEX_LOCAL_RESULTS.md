## Единый индекс — результат, а не зелёная картинка

Сохранены 2374 callable rows, включая 303 direct. Пять путей с ограниченными
независимыми примерами имеются у **284** direct-строк вместо **270**. Две новые
TSI-строки проверяют только явно указанный steady-state continuation, не startup.
19 direct-строк пока без пяти путей. Это не процент завершения Stage 2.

Новый strict replay: **90/100** group/mode/path сочетаний совпадают полностью,
**10** вариантов string corpus не проходят из-за трёх уже известных неатрибутированных
UNVERIFIED ожиданий v5 str.tonumber. То же расхождение есть в исходном CI baseline.
Нельзя выдать 7794 успешных pytest за полный численный gate. Код/expected для этих
строк не изменены без версионного основания. Полная приёмка остаётся заблокирована.

Подробные исходные XML, actual observations, locked assignments, индексы baseline/
current, первый поиск с 160 отказами до root-исправления и начальный provisional
v4 набор сохранены в архиве. Неудачные результаты не переименованы в успешные.
