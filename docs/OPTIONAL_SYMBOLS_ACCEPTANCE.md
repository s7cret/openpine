# Приёмка ignore_invalid_symbol

Python 3.14.8. На Windows прошли 2202 тестов, на Linux 2201. Проверка коротких путей Windows пропущена на Linux. CI завершил 57 заданий. Установка использовала один wheel на обеих платформах.

Отчёты обеих ОС совпали по всем 103 файлам. Сохранены 5462 прежних наблюдений. В новой выборке 3 исполнений и 12 ожидаемых отказов.

CLI и HTTP закрепляют для каждого вызова снимок либо отрицательное свидетельство каталога. Проверены сохранённый IR, восстановление воркера после первого бара, цена исполнения 3 на третьем баре и повторная доставка событий replay. Локальный нагрузочный прогон на 100 тысячах и миллионе баров использовал два снимка с одним разрешением каталога для каждого из трёх сочетаний вызовов.

Артефакты предыдущей сборки для v1–v6 декодированы. После перекомпиляции вызовы без флага имеют прежние узлы IR и результаты. Для запуска IR из другой сборки действует штатная проверка идентичности исполнения.

Ubuntu economics: при отправке запуска единственный слот подготовки был занят. Сервер вернул HTTP 503 COORDINATOR_BUSY с retryable=true и retry_after_ms=100. Это произошло до создания задания. Полная локальная установочная проверка economics того же wheel завершилась успешно.
