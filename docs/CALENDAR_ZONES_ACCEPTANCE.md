Python 3.14.8, CI 57/57, один wheel.
Windows — 2133 успешных тестов. Linux — 2132 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены все 5147
прежних наблюдений.
Добавлены 17 исполняемых сценариев и
10 ожидаемых отказов.

На общем wheel CLI прочитал IR, сохранённый HTTP-компилятором.
Воркеры Windows и Linux восстановились между двумя барами с
локальным временем 01:30 в Нью-Йорке 3 ноября 2024 года.
Сохранённый IR и восстановленный запуск дали одинаковые ряды
и сигнал в 08:00 UTC. Нативные проверки подтвердили проверку
закреплённых настроек при восстановлении и отклонение изменённого
значения по умолчанию в IR.

В первом прогоне тест матрицы обнаружил, что объединённая строка
`timestamp` v4 потеряла ссылку на профиль константной даты.
Итоговая матрица связывает оба поддерживаемых профиля.
[Журнал первого прогона](https://github.com/s7cret/openpine/actions/runs/43977039157/job/133683564332).

Windows-набор observed исчерпал 1200 секунд ожидания корпуса на заключительном сценарии bands-rsi-v6. На момент остановки все завершённые проверки прошли, а replay последнего сценария продолжался. Повтор запущен с тем же исходником, wheel и лимитом.
