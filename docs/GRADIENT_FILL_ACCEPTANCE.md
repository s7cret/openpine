# Приёмка вертикальных градиентов R6

[Исходник c21027986c6c](https://github.com/s7cret/openpine/commit/c21027986c6c9f77de9a032fbaa709c34b462629) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42503472002) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42503472112)

CI 57/57, Python 3.14.8. В реестре каждой ОС 1 913 тестов. Conformance охватывает 4 328 сценариев, корпус — 180 программ.

- В Pine v5–v6 проверены градиенты между двумя `plot` и между двумя
  `hline`. Для v1–v4 добавлена диагностика версии. Маска из смешанной
  пары получает ошибку выбора перегрузки. В матрице допуск с `plot`
  отмечен `PARTIAL`, а `hline` указан с отдельным источником.
  [ADR 0032](adr/0032-gradient-fill.md)
- Прошли 15 браузерных сценариев. Проверены динамические
  уровни и цвета, прозрачный край, равные и обратные уровни, пересечение
  границ, пропуски, смещения и шкала панели.
- Установленный wheel на обеих ОС подтвердил обе маски, сохранение четырёх
  значений на бар, возобновление worker, выборку страницы и совпадение
  полного результата CLI с HTTP. Replay восстановил предпросмотр и
  заменил его значениями закрытого бара.
- На Windows успешно выполнено 1 913 тестов, на Linux — 1 912.
  На Linux ожидаемо пропущена проверка псевдонимов файлов Windows 8.3.
  Обе ОС использовали один wheel. Проверены четыре сценария восстановления.
- Совпали результаты всех 4 310 прежних сценариев.
  Добавлено 18 новых. Все отчёты совпали между Windows
  и Linux. Сверка с TradingView относится к отдельному этапу.

Первый прогон Windows остановился на сравнении HTTP и CLI. Smoke-тест отправлял в HTTP исходник с LF, а CLI получал файл с CRLF. После чтения одних и тех же байтов полные результаты совпали. [Журнал первого прогона](https://github.com/s7cret/openpine/actions/runs/42493624234/job/128776202676)
