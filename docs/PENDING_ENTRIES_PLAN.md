# Отложенные исторические входы v1–v6

- [x] 1. Отдельные версионные контракты и evidence по локальным каталогам.
- [x] 2. Limit-входы, улучшение на open, шаг цены и комиссии.
- [x] 3. Stop-входы, гэпы и закреплённое adverse slippage.
- [x] 4. Stop-limit: отдельная активация и детерминированная OHLC-граница.
- [x] 5. Изменение, отмена, разворот и точные targets частичной защиты.
- [x] 6. Checkpoint, workers, приложение, график и исследования.
- [x] 7. Независимый корпус, регрессия, wheel, браузер, нагрузка и CI обеих ОС.

Новый профиль включается именованным limit/stop у strategy.entry.
Позиция одна, pyramiding=0; entry исполняется целиком без моделирования объёма.
После внутрисвечной активации stop-limit его limit доступен со следующего
бара. Защита внутрисвечного входа также ждёт следующий бар. Вход на open
позволяет обработать защиту этой же свечи. Сначала известные исполнения на
open по sequence, затем защита существующей позиции, затем не более одного
фактического внутрисвечного входа. Прочие подходящие входы остаются pending.

Ранние пробелы v1/v2 восстановлены явно; when есть только в v1–v5.
Observed/live исполнение и точная сверка с TradingView — отдельные этапы.
