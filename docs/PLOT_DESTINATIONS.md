# Места вывода числового plot

В Pine v5 и v6 числовой `plot()` может выбирать четыре места вывода
независимо. Режимы складываются через `+` и исключаются через `-`.
`display.all` включает все четыре, а `display.none` задаёт пустой набор.
Подробности для двоичного `display` других слоёв и v4 описаны отдельно.
[Обзор TradingView](https://www.tradingview.com/pine-script-docs/visuals/overview/#display-in-other-locations)
· [Двоичный профиль](VISUAL_DISPLAY.md)

| Режим | Исторический график и replay |
| --- | --- |
| `display.pane` | Рисунок, легенда и участие в расчёте шкалы панели |
| `display.status_line` | Значение свечи в строке статуса |
| `display.price_scale` | Последнее значение на шкале назначенной панели |
| `display.data_window` | Название и значение свечи в окне данных |

```pine
//@version=6
indicator("Диапазон")
drawRange = input.bool(true, "Рисовать диапазон")
plot(high - low, "Размах", display=drawRange ? display.pane + display.data_window : display.data_window)
```

Режим фиксируется при запуске. Условие может быть булевым литералом,
прямым глобальным `input.bool` или их отрицанием. Вычисленные значения
доступны через API и полный экспорт при любом наборе. Видимая заливка
использует геометрию обеих опор, включая ряды без `display.pane`.

Строка статуса и окно данных показывают значение исходной свечи под
указателем или последней свечи текущего окна. `offset` сдвигает
геометрию, `show_last` ограничивает доступный интервал значений. Вне
него окно показывает `na`. Метка шкалы использует последнюю точку
подтверждённого результата независимо от страницы графика. При
следовании за открытой свечой она использует действующее превью.
`na` убирает метку. Значение за пределами шкалы отображается у края
без изменения её диапазона. Маршрут на панель наследуется от
декларации и `force_overlay`. [ADR 0034](adr/0034-plot-destinations.md)

Доступность и сохранение проверяются в
[корпусе visual-bands](../conformance/visual-bands/cases.json),
[тестах display](../tests/test_visual_display.py) и
[браузерном сценарии](../tests/ui/plot-destinations.html).
Сверка чисел и изображения с TradingView ведётся отдельным этапом.
