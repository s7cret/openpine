# Вычисления в запрошенном контексте

Ниже описан базовый выпуск .6. Его дополняют [параметры целей](PREPARED_REQUESTS.md)
и [младшие массивы](LOWER_TF.md) с [replay/live](LOWER_EVENTS.md). Ограничения
литерального базового профиля не отменяют эти отдельные реализованные расширения.

Выпуск `pine-requests-20261024.6` закрепляет `openpine.requests.vN.6`
для каждой версии v1–v6. Он расширяет выражение существующего запроса:

```pine
//@version=6
indicator("Requested calculations")
length=input.int(20)
src=(high+low+close)/3
average=ta.wma(src,length)
higher=request.security("TEST:SIGNAL","60",average[1])
plot(higher)
```

В запрошенном контексте заново вычисляются `src` и `average` на его свечах.
Имя API, именованные аргументы, gaps/lookahead и логика языка сохраняют правила
своей версии. Пробелы ранних артефактов — явно принятая реконструкция;
внешнее исполнение в TradingView не подтверждалось.

## Зависимости и исполнение

Компилятор и допуск IR используют общий сборщик графа уже связанных узлов.
Каждый необходимый глобальный initializer переносится в частную программу
один раз и выполняется в порядке исходных объявлений на каждом запрошенном
баре. Две ссылки читают одно значение, включая состояние TA. Два написанных
запроса имеют отдельные программы и состояния.

Допускаются глобальные безусловные обычные объявления чисел/bool и распаковки
плоских tuple. Транзитивные зависимости также должны быть допустимыми.
Переприсваивание в любой части программы, глобальный `var`, зависимость от
другого запроса или брокера дают `REQUEST_SCOPE`. Полный schema/settings inputs
сохраняется, включая неиспользованные параметры. `input.source` выбирает поле
запрошенных свечей; изменение закреплённого input исключает продолжение старого
checkpoint. Число с основного графика в запрошенное вычисление не подставляется.

Поддерживаются арифметика, сравнения, `and/or`, `?:`, возвращающий `if`,
зарегистрированные числовые/TA ядра и история числового/bool выражения с
литеральным смещением 0…100000. Прогрев и история относятся к requested bars.
Пропущенная ветка сохраняет общую семантику достигнутых вызовов runtime.

## Функции и типы

```pine
sample(x) =>
    [x[1],x>x[1]]
[previous,rising]=request.security("TEST:SIGNAL","60",sample(average))
plot(previous)
plot(rising ? 1 : 0)
```

UDF использует существующие параметры, локальные переменные, локальный `var`,
условия и состояние TA. Разрешены ациклические вложенные вызовы UDF.
Глобальные значения включаются в граф по реальным чтениям из тела.
Неиспользованные глобальные вычисления не переносятся. Частная таблица функций
сохраняет необходимые захваты; повторного разрешения исходных имён нет.

Результат — число, bool либо плоский tuple из 2…16 числовых/bool компонентов.
Числовой скаляр int, как в прежнем ABI, приводится к float; внутри tuple int
сохраняется. Перед первым видимым баром и при gaps_on без нового события
числовые компоненты получают na; bool в v1–v5 получает na, в v6 — false.
Настоящие false и 0 сохраняются; компоненты разделяют момент доступности.
Plot остаётся числовым; для bool используется условное 1/0.

## Состояние и ограничения

Частная программа использует существующие Typed IR и runtime. Версия схемы
выбирается по использованным возможностям; новых видов узлов нет.
Основной runtime не создаёт исторические буферы для выражения запроса.
Checkpoint включает курсоры, частные истории, параметры и состояния функций.
Непригодный checkpoint закрывает восстановление до выдачи результата.
Preview работает на отдельных изменениях и не записывает их в committed state.

Лимиты: 128 узлов выбранного графа, глубина 16, до 16 написанных запросов
и 8 рыночных контекстов. Общие ограничения истории, функций и памяти worker
также действуют. Общие зависимости не размножаются по числу чтений.

Запрос остаётся безусловным глобальным вызовом с литеральными symbol/timeframe.
Сам вызов запроса в теле/аргументах UDF и внутри условного выражения исключён;
внутри его собственного expression функции и условия разрешены.
Вложенные/динамические/локальные запросы, lower timeframe, строки, коллекции,
циклы внутри выражения, торговые и графические эффекты исключены. Barstate и
bar_index внутри выражения остаются за границей выпуска. Поддержанные поля
рынка и календаря читаются из собственного контекста.

## Примеры и проверка

Шесть [context-trend](../examples/context-graph/) стратегий объединяют
перенесённую WMA, историю её результата, UDF с tuple и локальным var,
старший контекст, параметры и защитные уровни. Данные синтетические.
Отдельные phase-примеры демонстрируют тот же граф при записанном replay.

Новый [корпус](../conformance/context-graph/cases.json) содержит 60 исполнений
и 30 ожидаемых отказов. Ожидания вычисляются независимо через Fraction/list
и ручное отображение доступности; результаты runtime не используются.
Все семь пунктов [плана этапа](CONTEXT_GRAPH_PLAN.md) приняты на Python 3.14.8:
639 тестов, 1105 conformance-сценариев, установленный wheel, браузер,
миллион свечей с восстановлением и CI 9/9 на Windows/Linux.
Исходники — `0e81685`; [свидетельство](evidence/context-graph-20261024.json)
содержит идентичности сборки, отчётов, wheel и логов.
