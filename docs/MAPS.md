# Типизированные словари maps

Профиль `openpine.maps.1` реализует ограниченные maps для Pine v5/v6.
В v1–v4 map API и аннотации отвергаются с `MAP_VERSION`; контрольные программы
показывают аналогичный расчёт скалярами. Основа — закреплённые записи Wiki
`reference/v5.json` и `reference/v6.json`, [руководство v5](https://www.tradingview.com/pine-script-docs/v5/language/maps/)
и [руководство v6](https://www.tradingview.com/pine-script-docs/language/maps/).
Внешнее исполнение TradingView не проверялось.

## Типы и операции

Ключи: `int/float/bool/string` и номинальные enum. Значения: эти же типы
и плоские UDT существующего профиля. В карте одна точная пара типов;
`int → float` допускается как прежнее явное преобразование IR. Разные
номинальные enum/UDT не взаимозаменяемы. Не поддержаны color/графические ID,
вложенные коллекции, reference-поля UDT, map-результаты tuple и request.

```pine
//@version=6
indicator("Map example")
var map<string, float> totals = map.new<string, float>()
totals.put("sum", nz(totals.get("sum"), 0) + close)
snapshot = totals.copy()
selected = 0.0
for [key, value] in snapshot
    if key == "sum"
        selected := value
plot(selected)
```

Namespace и instance-вызовы используют общий Binder:
`new`, `put`, `put_all`, `get`, `contains`, `remove`, `clear`,
`size`, `copy`, `keys`, `values`; `na(map)` проверяет missing reference.
Поддержаны UDF и пользовательские методы с map-параметром. Receiver вычисляется
до явных аргументов; named arguments исполняются один раз в исходном порядке.

`put` возвращает прежнее значение, `get/remove` — найденное значение.
При отсутствии ключа получается typed missing; для bool в v6 — false.
Ключ может быть typed `na`, кроме bool v6. Разные missing одного типа дают
один ключ. Финитные float используют числовое равенство, включая равенство
`-0.0` и `0.0`. Эти края sparse reference-описаний закреплены как явная
интерпретация OpenPine, а не наблюдение внешнего исполнения.

## Порядок, копии и ссылки

Сохраняется порядок первой вставки. Замена не переставляет ключ и сохраняет
первоначальное представление ключа; удаление и повторная вставка помещают
его в конец. `put_all` сохраняет позиции старых ключей и добавляет новые
в порядке источника. Self-merge читает исходное содержимое.

Присваивание сохраняет ID. `copy` создаёт независимый контейнер,
но UDT-значения сохраняют общие ObjectRef. `keys/values` создают новые
массивы: изменение их слотов не меняет карту, изменение полей UDT через
`values` видно через остальные алиасы.

Map-обход требует `for [key,value] in map`, включая discard-target `_`.
В первом профиле список ключей фиксируется на входе, значения читаются перед
очередной итерацией. Удалённый ключ даёт missing, новые ключи не посещаются.
Это явное ограниченное правило для мутаций во время обхода. Обычные
`break/continue`, счётчик работы и отмена остаются общими с циклами.

## Heap, бюджеты и восстановление

Карты используют общий heap с массивами, окнами и плоскими UDT:
единые IDs, GC, persistent/history roots, COW previews и field-level varip.
Граф ацикличен: карта ссылается только на плоские записи; ключи — значения.
Обычные поля UDT не становятся varip из-за помещения в varip-карту.

Каждая пара занимает две физические ячейки. Предел — 50 тысяч пар на карту;
прежние общие лимиты объектов, ячеек, UTF-8, работы и памяти не увеличены.
Ключи и enum-токены включены в UTF-8 счётчик. Служебный lookup index и
scratch включены в ledger. Канонические ключи хешируются SHA-256, чтобы
пользовательские int-коллизии Python hash не задавали стоимость поиска.

Мутации пока строят целую транзакционную копию карты. Их работа и временная
память растут с размером карты. Перед публикацией проверяются storage/work,
scratch и отмена; отказ сохраняет прежние слоты, счётчики и next ID.
Эффекты вычисления аргументов выполняются до этой транзакции.
`keys/values` также проверяют бюджеты перед материализацией.

Только программы с maps используют `openpine.typed-ir.17`,
`openpine.runtime-state.10` и `openpine.array-heap.3`. Новый heap codec
сохраняет key type, value type и упорядоченные пары; lookup index
восстанавливается из проверенных ключей. UDT-значения записываются компактными
ID, как в массиве объектов, без отдельного JSON-объекта на каждую ссылку.
Дубликаты, включая signed-zero
дубликаты, чужие ссылки, неверные типы и счётчики отвергаются. Восстановленные
буферы принадлежат runtime. Программы без maps сохраняют прежние форматы.

Правила воспроизводятся `tools.maps_spec --check`, исходники и ручные ожидания —
`tools.maps_fixtures --check`. Проверки находятся в `tests/test_maps.py`,
`conformance/maps/`; восемь программ `maps-*` включены в общий корпус.
Корпус расширен с 128 до 136 записей. Только предел размера каталога увеличен
до 256 записей; запуск одного батча по-прежнему ограничен 64 программами.
Рабочие бюджеты памяти, операций и процессов этим не меняются.

Архитектурное обоснование: [ADR-0002](adr/0002-maps-on-shared-reference-heap.md).
