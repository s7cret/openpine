# Копирование и перебор графических объектов

В индикаторах Pine v5–v6 доступны `line.copy(id)`, `label.copy(id)` и
`box.copy(id)`. Копия получает свой ID и сохраняет геометрию, координатный
режим и поддерживаемые свойства оформления. Копия линии не переносит заливку,
поскольку та ссылается на конкретную пару линий. Копирование расходует лимит
как обычное создание. OpenPine возвращает `na` для удалённого, вытесненного
или отсутствующего ID. [Журнал Pine](https://www.tradingview.com/pine-script-docs/release-notes/#january-2022) · [Лимиты](DRAWING_LIMITS.md)

Переменные `line.all`, `label.all`, `box.all`, `table.all`, `linefill.all`
и `polyline.all` доступны в Pine v5–v6. Каждое чтение возвращает снимок
живых ID данного вида в порядке создания. Объект с координатами `na`
входит в снимок, если он был создан и ещё существует.
[Справочник Pine v5](https://www.tradingview.com/pine-script-reference/v5/#var_line.all)

В профиле OpenPine снимок можно сохранить в обычной переменной текущего
расчёта, читать через `array.size()` и `array.get()` и перебирать через
`for…in`. Полученные ID подходят существующим операциям соответствующего вида.
Удаление объекта во время цикла сохраняет состав уже прочитанного снимка.
Новое чтение показывает актуальные ID. Изменяемые массивы ссылок, история
снимков, сохранение снимка в `var` или `varip` и перенос в пользовательскую
функцию или request-выражение вне этого профиля.

```pine
//@version=6
indicator("Drawing inventory", max_lines_count=2)
var line original = line.new(0, 20, 3, 20)
var line replica = line.copy(original)
if bar_index == 1
    line.set_xy2(replica, 3, 25)
    line.new(0, 30, 3, 30)
array<line> live = line.all
plot(array.size(live))
```

На втором баре остаются ID 2 и 3. В replay снимок отражает состояние
своего расчёта, включая изменения в preview. При возобновлении исполнения
снимок строится из восстановленного состояния рисунков.
[Сценарий с заливкой](../conformance/linefills/v6-drawing-inventory.pine) · [ADR 0040](adr/0040-drawing-inventory.md)

Поля найденного рисунка можно читать и менять по отдельности.
