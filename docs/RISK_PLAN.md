# Приёмка управления риском v1–v6

- [x] Отдельные версионные контракты и immutable companion с границами реконструкции.
- [x] Направление и размер входа, net-order scope, шаг и минимумы.
- [x] Постоянные остановки по drawdown и убыточным дням.
- [x] Дневные ограничения, UTC-календарь, D/W/M и счёт исполненных заявок.
- [x] Составной RiskController, порядок наблюдений, отмена и принудительное закрытие.
- [ ] Восстановление, worker, backup, CLI/HTTP, исследования и UI.
- [ ] Независимые оракулы, вся регрессия, масштабирование, установленный пакет и CI.

Исполнение и приёмка — на Python 3.14.8. Полная приёмка закрывается по
фактическим результатам. Границы OHLC-наблюдений и реконструкции приведены
в [описании риска](RISK.md); внешняя эквивалентность не заявляется.
