# Приёмка управления риском v1–v6

- [x] Отдельные версионные контракты и immutable companion с границами реконструкции.
- [x] Направление и размер входа, net-order scope, шаг и минимумы.
- [x] Постоянные остановки по drawdown и убыточным дням.
- [x] Дневные ограничения, UTC-календарь, D/W/M и счёт исполненных заявок.
- [x] Составной RiskController, порядок наблюдений, отмена и принудительное закрытие.
- [x] Восстановление, worker, backup, CLI/HTTP, исследования и UI.
- [x] Независимые оракулы, вся регрессия, масштабирование, установленный пакет и CI.

Исполнение и приёмка прошли на Python 3.14.8; результаты приведены ниже.
Границы OHLC-наблюдений и реконструкции приведены
в [описании риска](RISK.md); внешняя эквивалентность не заявляется.

## Результаты приёмки 2026-10-25

Все семь пунктов закрыты на Python 3.14.8 для исходников
`13221079374ef5a12e26348b23b43b6ef85b0caa`.

- Локально прошли 833 теста в 90 модулях. Те же 833 теста прошли отдельно
  на Windows и Linux; [CI — 27/27](https://github.com/s7cret/openpine/actions/runs/40220719808).
- В 24 корпусах проверены 2024 примера: 1345 исполнений и 679 ожидаемых
  отказов. Новая часть — 36 исполнений и 60 отказов. Все 1928 прежних
  наблюдений, включая 1309 успешных исполнений, и 75 файлов прежних
  immutable bundles совпадают с принятой экономической стадией.
- 18 примеров (три семейства × v1–v6) проходят по 160 свечам / 20 UTC-дням.
  Независимая арифметика сверяет капитал, комиссии, объём и состояние риска.
  Проверены 864 восстановления на точных границах, 18 реальных worker,
  backup и перезапуск координатора с постоянной остановкой.
- Один построенный wheel проверен вне checkout во всех десяти группах.
  CI отдельно проверяет те же десять групп на обеих ОС; RECORD и SHA всех
  членов локального wheel сверены с замороженной сборкой.
- Через браузер выполнены entry v1, дневная остановка v4 и постоянная
  остановка v6. Из SQLite / CAS / Parquet независимо сверены 1440 точек
  и комиссии 164 fill. Проверены выбранный бар, события, восстановление
  исходника и параметров; повторное правило отклоняется без нового задания.
- Эксперименты, поиск с holdout и два walk-forward окна сверены с
  независимым дневным расчётом. Победитель `Manual units=1`; каждый
  отложенный четырёхдневный участок даёт net profit `-72`.
- Масштабирование: 1 000 000 основных + 250 000 старших свечей,
  5 000 000 выходных точек. Максимум RSS worker — 153.25 MiB.
  Проверены принудительное падение с повторной попыткой, восстановление
  с checkpoint, backup и совпадение результатов. Итог стресс-сценария:
  equity `982`, комиссия `8`, позиция `0`; остановка по просадке на fill.
