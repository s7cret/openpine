# Приёмка размеров позиции и торговых издержек

- [x] Версионные артефакты, immutable companion и явные границы реконструкции.
- [x] Единый QuantityResolver и приоритет явного qty.
- [x] Закреплённый момент расчёта, pending-объём и поведение гэпа.
- [x] Версионные настройки, известные правила снимка и минимумы.
- [x] CommissionCalculator, частичные лоты, reversal и сохранение оплаты.
- [ ] Worker, backup/restore, установленный пакет, CLI/HTTP, исследования и UI.
- [ ] Независимые оракулы, полная регрессия, миллион свечей и CI.

Исполнение — на Python 3.14.8. Пункты полной приёмки закрываются по
фактическим результатам. Расчёт процента капитала здесь выполняется на
close создания, а не при открытии сделки; отличие документировано отдельно.
