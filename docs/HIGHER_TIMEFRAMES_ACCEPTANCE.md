Python 3.14.8, CI 57/57, один wheel.
Windows — 2122 успешных тестов. Linux — 2121 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены 5109
прежних наблюдений. Добавлены 18 исполняемых сценариев и
6 ожидаемых отказов. Они покрывают версии Pine,
границы дня, недели и месяца, високосный февраль и пропуски свечей.

Дневной пресет выставил заявки на барах 1 и 25, недельный — на баре 1.
Пауза пришлась на свечу перед началом понедельника. Восстановление
после изменения пресета дало первоначальный недельный журнал. CLI
и HTTP использовали один сохранённый IR. Эти проверки прошли на
общем wheel Windows и Linux.

Артефакт v6 с предыдущего wheel восстановился со значением D.
На новом wheel новая компиляция выдаёт 1D, а попытка загрузить артефакт
предыдущей сборки даёт ARTIFACT_IDENTITY.

В первом кандидате Windows `exits` превысил таймаут и прошёл повтор.
Windows `contexts` дважды исчерпал ожидание корпуса на последней программе.
Три более тяжёлых сценария обменены с группой `numeric`. Обе группы
по-прежнему проверяют по 20 сценариев с лимитом 1200 с. В принятом
прогоне Windows корпус `contexts` занял 1107.691 с,
`numeric` — 1000.497 с.
[Прогоны первого кандидата](https://github.com/s7cret/openpine/actions/runs/43887647504).

В статической матрице реализованные календарные перегрузки имеют статус PARTIAL.
Сравнение с исполнением TradingView ведётся отдельно.
