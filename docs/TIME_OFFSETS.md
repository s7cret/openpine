# Смещения открытия и закрытия бара

`time()` и `time_close()` принимают `bars_back` в Pine v5–v6.
Параметр `timeframe_bars_back` доступен в v6. Значение по умолчанию для
обоих параметров равно нулю. Результат имеет тип `series int` и выражен
в Unix-миллисекундах. [Pine v5, март 2024](https://www.tradingview.com/pine-script-docs/v5/release-notes/#march-2024) ·
[Pine v6, октябрь 2025](https://www.tradingview.com/pine-script-docs/release-notes/#october-2025).

1. `bars_back` выбирает свечу графика. Положительное число отсчитывает
   полученные свечи. Отрицательное число сдвигает время по календарю
   графика.
2. Выбранная свеча определяет текущую корзину целевого таймфрейма.
   Положительный `timeframe_bars_back` отступает по различным
   наблюдаемым корзинам. Пустые прошлые периоды пропускаются. При
   прогнозном якоре сначала отсчитываются календарные корзины до
   текущей, затем используются наблюдаемые корзины. Отрицательное
   значение сдвигает якорь по календарю целевого интервала.
3. `time()` возвращает начало выбранного периода, `time_close()` —
   его исключающую верхнюю границу. При нехватке истории результат
   равен `na`. [Порядок применения смещений](https://www.tradingview.com/pine-script-docs/concepts/time/#calculating-timestamps-at-bar-offsets).

Каждое смещение принимает `series int` в диапазоне от −500 до 5000.
Вызов с `na` в смещении возвращает `na`. Для смещения по целевому
таймфрейму, которое может обратиться к истории, цель задаётся
замороженным выражением, например строкой, `input.timeframe` или
`timeframe.period`. Прогнозы и ненулевые смещения по целевому
таймфрейму используют UTC 24×7. Положительное смещение только по графику
допускает существующие [минутные сессии](TRADING_SESSIONS.md). Допустимые
комбинации интервалов описаны в [календарном профиле](HIGHER_TIMEFRAMES.md).

[Пример индикатора](../examples/time-offsets/daily-boundaries.pine) рисует
две вертикальные линии на открытии и закрытии предыдущего наблюдаемого
дня и третью на прогнозном закрытии следующего дня. На наборе с пропусками
координаты равны 1, 2 и 6 марта 2024 года в полночь UTC. Восстановление
сохранённого IR и checkpoint даёт те же координаты.
[Корпус](../conformance/time-offsets/cases.json) · [Решение о хранении](adr/0071-time-offsets.md).

В [корпусе торговых сессий](../conformance/trading-sessions/cases.json)
сценарии `v5-bars-back` и `v6-timeframe-bars-back` переведены из
`LANGUAGE_INVALID / UNKNOWN_ARGUMENT` в выполнение. На часовом наборе
первая точка равна `na`, остальные возвращают время предыдущей свечи.
Матрица помечает функции как `PARTIAL`. Ожидания для пропусков,
восстановления и прогноза вычислены для модели OpenPine. Сравнение
исполнения с TradingView остаётся отдельным этапом.
