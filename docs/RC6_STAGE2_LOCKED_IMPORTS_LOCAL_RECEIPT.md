## Что сделано одним блоком

- Точный offline lock owner/Name/revision с отдельно закреплёнными SHA источников.
  Снимки неизменяемы и отделены от входных словарей/файлов; fallback на latest нет.
- Транзитивные и diamond-зависимости, несколько ревизий и aliases, экспортируемые
  скалярные функции, private helpers и константные глобальные зависимости.
  Имена связываются по AST/лексическим областям, не массовой заменой строк.
- Библиотечный демонстрационный код не запускается в потребителе. Каждый записанный
  вызов использует существующие UDF/state/history механизмы. Пример с двумя
  счётчиками получает 11, 22, 33; ордер на третьем баре использует qty=33.
- Inputs и builtin-defaults проходят нормальную типизацию. Проверены импортированная
  SMA, simple-параметры, default=high, private visibility, отрицательные формы.
- В generated_artifact.v3 активировано существующее поле dependency hashes,
  добавлена привязка @linkage. Изменение транзитивного источника меняет build/artifact
  identity; старый checkpoint не принимается для другого связанного артефакта.
- Исходные файлы/строки сохраняются в projection receipt. Его верификация заново
  строит проекцию из захваченных оригиналов, не доверяя одному внешнему checksum.
- До worker не передаются файлы библиотек или сетевой resolver. Safe POSIX reads
  отвергают traversal/symlinks/devices/FIFO; ограничены число, глубина и размер.

Обнаружен дефект исходного layout: DEDENT использовал весь диапазон следующего
токена, поэтому многострочная функция могла захватить чужой `export`. Исправление
сделано в Pine2AST, владельце диапазонов, а не удалением случайного текста в host.
Сохранены самостоятельные проверки границ и связанного исполнения.

production-installer и не разрешение запускать пользовательский код без sandbox.

## Негативные прогоны сохранены

Первичная обвязка не передавала broker state в session-only checkpoint-проверки;
эти проверки отделены от настоящих broker-тестов без удаления последних.
Ошибка диапазона многострочного AST воспроизведена тестом и исправлена у владельца.
Ранний общий прогон столкнулся с конфликтом test-package из PYTHONPATH и продуктами
локальной packaging-сборки в исходном checkout; повтор выполнен с установленными
зависимостями и чистыми источниками. Один общий командный запуск был прерван по
лимиту до XML компилятора; он не объявлен успешным, полный компилятор затем прошёл.
Все эти логи отделены от последних отчётов и не меняют счётчики уникальных тестов.

## Остаток и перенос

Это same-version scalar профиль, не полная поддержка Pine-imports: остаются
межверсионное связывание, exported UDT/reference/generic/method/enum/const,
одноимённые overloads, request capture и полный каталог. Поддержка этих конструкций
в TradingView не отрицается. Основной CLI/gateway/UI ещё не настраивает library store
автоматически; есть явный API и offline frontend-команда. Source-map у компилятора
ссылается на виртуальный Pine; полная перепроекция пользовательских сообщений
и торговых событий — отдельный остаток UX.

OP-31 переводится из «не проверялось» в **частично реализовано**, не accepted.
Весь этап 2 остаётся in_progress. Другие критерии языка/once/types/builtins не
закрываются фактом появления linker.

Архив содержит восемь исходных компонентов, incremental Git bundles с точными
базами, патчи и доказательства. Local pins нельзя скачивать из GitHub, пока сами
коммиты не опубликованы. При переносе нужны сохранение новых удалённых изменений,
обычный merge/fast-forward и полный защищённый CI, без force push. Самостоятельно
переключать production только на часть новых библиотек нельзя. Повторно проверять
актуальный remote head обязательно: исходная проверка не разрешает перезаписать
параллельные изменения.
