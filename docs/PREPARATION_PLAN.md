# Подготовка и приёмка: план этапа

- [x] 1. Профиль холодной/повторной Session и подготовки 1/32/256 вариантов.
- [x] 2. Ограниченный кеш проверенных шаблонов спецификации с изоляцией копий.
- [x] 3. Переиспользование IR и входов внутри конечной подготовки исследований.
- [x] 4. POST-чтения, ограниченные повторы, отмена и защита от устаревших ответов.
- [x] 5. Фактические веса CI, шесть частей на ОС, параллельные feedback/build.
- [x] 6. Независимый сквозной потребитель v1–v6 с worker и восстановлением.
- [x] 7. Полная приёмка Python 3.14.8, память/рост, wheel, Windows/Linux, публикация.

База: `f295726c2b0ede73a634a433f2629b38c571d060`, 1033 теста в 113 модулях,
2116 conformance-сценариев. Все прежние test ID и наблюдения должны сохраниться.
До изменений cProfile показал 14,5 с на три новых Session и 36,2 с на подготовку
256 вариантов; внутри Preparation — 512 декодирований IR. Приёмка сравнивает
эти данные с теми же фазами на закреплённом новом исходнике.


Принятый исходник: `2bded0311e97660f24c2cdf2411703e6c7cefdd4`. Python **3.14.8**.
**1046 тестов / 116 модулей** локально и на каждой ОС; все **1033** прежних test ID
сохранены. Все **2116** conformance-наблюдений (1410 исполнений / 706 ожидаемых
отказов) совпали с базой. Сохранены 79 файлов immutable bundle и прежние профили.

| Фаза cProfile | До, с | После, с |
| --- | ---: | ---: |
| Холодная Session | 4.41 | 4.56 |
| Три повторные Session | 14.52 | 1.24 |
| 1 вариант | 4.90 | 0.65 |
| 32 варианта | 4.64 | 1.74 |

Для 256 вариантов декодирования внутри Preparation сократились **512 → 1**,
чтения spec — **4096 → 16**. Логические настройки и выбранные снимки полностью
совпали с базой. Собственный импорт программы эксперимента считается отдельно.

Отдельный прогон без cProfile: три Session **6,31 → 0,53 с**; наблюдаемый пик
RSS этой фазы **74,2 → 93,7 МиБ**. Кеш требует дополнительной памяти; холодная
полная проверка сохраняется. Архив базы проверен по исходному commit и всем
хешам файлов. Это измерения данной машины, а не универсальная гарантия скорости.

[CI 47/47](https://github.com/s7cret/openpine/actions/runs/40503112348): полный корпус на Windows/Linux, шесть частей на
каждой ОС, один wheel и по 15 установочных наборов. В этом прогоне весь CI
занял **41.1 мин**; предыдущий принятый прогон — **60,8 мин**. Очереди
и машины CI могут различаться. Feedback/build стартовали параллельно, приёмка
потребовала успешного завершения обоих этапов.

Новый установленный потребитель research прошёл для v1–v6: файл, сохранённый IR,
UDF/SMA/накопление, выбранный контекст, worker с паузой/продолжением и восстановление
replay после перезапуска. v1/v6 проверены в новом офлайн-хранилище, v5/v6 — с lower-TF.
Локально research и contexts приняты вне исходного checkout.

Миллион событий, 800 000 независимо проверенных выходных значений, перезапуск
координатора с шестью ячейками незавершённого окна. Пик worker — **311.2 МиБ**
при пороге 400 МиБ. Проверены подмена файлов с сохранённым mtime, изоляция копий,
конкурентное первое чтение, вытеснение кеша, повреждение IR при повторном чтении,
изменение идентичности кода во время подготовки и освобождение при исключении.

HTTP проверен при реальном занятом бюджете; мутации без ключа не повторяются.
В браузере прошли восемь сценариев повторов/отмены/устаревших ответов. Настоящая
страница автоматически восстановила параметры TEST:B / 1 и результат 100…107
после перезагрузки; ошибок JavaScript и видимой диагностики busy нет.
