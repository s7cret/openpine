## Гонка завершения паузы

Второй кандидат f380961 / CI 41460428630 отменён после 49 успешных jobs:
Windows lots и oca достигли worker timeout 120s (325/360 и 388/400 баров),
а suite cycle обнаружил настоящий дефект публикации паузы в method-routing-v3.
Воркер мог записать checkpoint после первого чтения coordinator и выйти
до проверки completion. Coordinator сравнивал completion с устаревшим корнем
и ошибочно выдавал WORKER_CRASH. Это отдельный дефект управления заданиями.

Исправленный coordinator повторно принимает checkpoint после обнаружения
выхода процесса, сохраняя проверки attempt, cursor, run plan и самого manifest.
Детерминированный тест воспроизводит ошибку до исправления и проверяет четыре
сценария после: новый/заменяющий checkpoint принимается, чужая попытка и неверный
cursor отклоняются без замены прежнего корня. Лимиты и рабочие нагрузки сохранены.

Локальный полный lots-прогон второго кандидата не прошёл: после семи полных
случаев, включая FIFO v2, отдельный CLI any v3 превысил 90s. Отдельный source-прогон
reduce v2 с независимым oracle прошёл за 41s resume. Это диагностические результаты,
а не полная локальная приёмка; точные причины задержек не установлены.

Текущий CI заново квалифицировал исправленный исходник с собственным wheel и
полным набором native, installed и recovery receipts. Артефакты прежних кандидатов
не смешивались с текущей приёмкой. Старые 29 локальных graph-тестов и диагностический
профиль сохранены с исходными идентичностями при неизменном compiler/runtime.
Старые восемь локальных целых программ — историческое свидетельство: свежую цепочку
после исправления coordinator доказывает текущий корпус на обеих ОС.

## Граница

[Правила](OBJECT_GRAPHS.md) и [ADR 0004](adr/0004-reference-fields-and-cyclic-heap.md):
поля UDT/array/map/matrix, self/ранее объявленные типы, общий heap и GC циклов,
shallow copy, история ID, COW, constructor buffers и field-level varip.
Только graph-программы используют typed-ir.19/runtime-state.12/array-heap.5.

Сначала выбираются обычные/varip поля, затем обходится граф. Переносимый маршрут
сохраняет содержимое общей коллекции; собственные поля дочернего UDT требуют
своих пометок. Это явная ограниченная трактовка. Varip-коллекции допускают UDT
с полями-значениями и коллекциями значений; прямые UDT-поля в таких элементах отклоняются.

Forward type names, прямые коллекции коллекций, графика/color, object requests,
object tuple-results и рекурсивные функции не включены. Цена обхода и staging
растёт с графом. Внешняя эквивалентность TradingView остаётся отдельным этапом.
