# Приёмка фаз исполнения стратегии

- [x] Версионные контракты заголовка и явных реконструкций v1–v6.
- [x] Отдельные ценовые наблюдения, проходы, идентичности и фазы.
- [x] Пересчёт после атомарной пачки исполнений через общий evaluator.
- [x] Одна дополнительная обработка на известной цене закрытия.
- [x] Rollback, varip, один commit истории и атомарное восстановление.
- [x] Исторический driver, workers, CLI/HTTP, веб и переносимая запись.
- [ ] Независимые примеры, полная регрессия, нагрузка, браузер, wheel и CI.

База: `6c600cc`, 933 теста / 101 модуль, 2074 conformance-наблюдения.
Прежние test IDs и результаты conformance сохраняются; новые возможности
проверяются дополнительными тестами и собственными примерами.

Приёмка: все версии и оба clock-профиля, комбинации флагов, каждый разрез,
var/varip и массивы, запросы, TA-окна, несколько лотов, комиссия/slippage,
OCA, trailing, риск, сбой между фазами и после публикации, backup/restore,
активная запись и офлайн replay. Длинные ленты — 100 тысяч и миллион ценовых
событий с независимой арифметикой сделок и количеством проходов.
Поставка — Python 3.14.8, Windows/Linux, общий установленный wheel.
Точное сравнение с TradingView остаётся отдельным этапом.
