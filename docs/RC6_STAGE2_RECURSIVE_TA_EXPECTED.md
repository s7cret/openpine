# Independent recursive TA expectations

The corpus contains 40 ordinary Pine v5/v6 scripts from 20 independently authored formula rows: seven EMA, six RSI, and seven MACD rows. MACD comparisons include all three outputs. The immutable 33-row source table and its arithmetic review are retained verbatim. Its other 13 rows remain UNVERIFIED and are never assigned passing evidence by this corpus.

Expected values come from the primary formula derivations and Fraction/Decimal arithmetic frozen before runtime observations. They cover finite, leading-missing, and all-missing source trajectories within the documented authority boundary. This is an engineering corpus, not a TradingView execution receipt or whole-function parity claim. MACD length-qualifier residuals and TSI's separate range-only evidence remain outside this corpus.

The formal test uses NativeRC6CompilerAdapter, verifies the admitted call identity and target, and executes the actual generated module. Each source runs through ABI, historical, realtime, rollback/retry, and committed checkpoint continuation, with both full and compact transcripts. Realtime repeats use the same input and must produce the same independently expected bar value. Aborted trials use altered finite input, record their actual results without claiming independent numeric authority, and require the complete committed checkpoint to remain unchanged before same-sequence retry. Checkpoint continuation restores every committed bar into a fresh session and verifies the entire roundtrip.

There are 400 trajectory executions plus one authority-retention test. Normal-source Linux execution and package identity verification are required before these are accepted as native evidence. A separately labelled local direct compiler control can exercise real compiler/runtime behavior on Windows; it cannot satisfy the native adapter gate. No fcntl replacement, skipped mandatory test, or change to older test inventories is permitted.
