# Многоконтекстный запуск из приложения

- [ ] 1. Общая серверная подготовка из проверенного IR и закреплённых настроек.
- [ ] 2. Основной и дополнительные контексты: снимки, файлы, существующий провайдер.
- [ ] 3. Покрытие, явный прогрев и интервал оценки.
- [ ] 4. Веб: подготовка, запуск, пауза, продолжение, отмена и перезагрузка.
- [ ] 5. Общие закреплённые данные для experiment/search/walk-forward.
- [ ] 6. Просмотр и повтор сохранённой конфигурации.
- [ ] 7. v1–v6, настоящая браузерная приёмка, восстановление, полный worker на миллионе, wheel и CI.

Приёмка открыта. База: 484 теста / 57 модулей, 623 conformance-сценария.
Python 3.14.8; SQLite 3.54.1, закреплённый DuckDB 2.0 dev и Parquet.
Используется существующая модель Pine; сверка с TradingView остаётся отдельной задачей.
