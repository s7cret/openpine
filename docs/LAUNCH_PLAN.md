# Многоконтекстный запуск из приложения

- [x] 1. Общая серверная подготовка из проверенного IR и закреплённых настроек.
- [x] 2. Основной и дополнительные контексты: снимки, файлы, существующий провайдер.
- [x] 3. Покрытие, явный прогрев и интервал оценки.
- [x] 4. Веб: подготовка, запуск, пауза, продолжение, отмена и перезагрузка.
- [x] 5. Общие закреплённые данные для experiment/search/walk-forward.
- [x] 6. Просмотр и повтор сохранённой конфигурации.
- [x] 7. v1–v6, настоящая браузерная приёмка, восстановление, полный worker на миллионе, wheel и CI.

Реализация: `8ef1255`. Локально прошли 495 тестов / 59 модулей и 623
conformance-сценария; прежние 623 наблюдения и bundles сохранены.
Проверены установленный wheel, четыре браузерных запуска v1/v6, восстановление
страницы и управления, полный worker на 1 млн основных и 250 тыс. старших свечей,
реальное падение worker и backup/restore на 100 тыс. свечей. Независимо проверены
3 млн выходных точек, 1174 объекта и совместные checkpoints.
Приёмка закрыта 24 октября 2026 года: все девять
[CI jobs](https://github.com/s7cret/openpine/actions/runs/40026068868) прошли
на Windows/Linux для `8ef1255`. [Итоговые доказательства](evidence/launch-20261024.json)
содержат идентичности реализации и сборки, хеши журналов, состав проверок и ссылки
на четыре сохранённых браузерных задания. Пик RSS миллионного worker — 225 МиБ
при бюджете 512 МиБ.
Python 3.14.8; SQLite 3.54.1, закреплённый DuckDB 2.0 dev и Parquet.
Используется существующая модель Pine; сверка с TradingView остаётся отдельной задачей.
