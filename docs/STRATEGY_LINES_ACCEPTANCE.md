# Приёмка линий и заливок в стратегиях R6

[Исходник d6132d30a161](https://github.com/s7cret/openpine/commit/d6132d30a1611a7fc6618c309f3a5a556f554cfc) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42982862253) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42982862069)

SHA d6132d30a161. CI 57/57, Python 3.14.8. В реестре каждой ОС 1 979 тестов. Conformance охватывает 4 537 сценариев, корпус — 180 программ.

- Для v4–v6 проверен луч на уровне лимитной заявки. В v5–v6 проверены методы объекта и заливка канала вместе с меткой и таблицей капитала. Для ранних версий подтверждены `LINE_VERSION` и `LINEFILL_VERSION`.
- Сравнение со стратегией без рисунков подтвердило те же заявки, исполнения и капитал. Исторический worker восстановил торговый журнал и журналы меток и линий из префикса `.8`. Установленный wheel подтвердил совместное восстановление через HTTP на обеих ОС.
- В replay с `calc_on_every_tick` заливка исчезла в предпросмотре при вытеснении линии. Подтверждённое состояние сохранило её до закрытия бара. После возобновления итоговый график и все три журнала совпали с непрерывным прогоном. Браузерная проверка охватила линии, заливку и окно графика стратегии.
- На Windows прошло 1 979 тестов, на Linux — 1 978. На Linux пропущена проверка псевдонимов Windows 8.3. Аудит подтвердил общий wheel и четыре отчёта восстановления.
- Сохранены все 4 525 предыдущих наблюдений. Добавлено 12 сценариев. Отчёты conformance совпадают между Windows и Linux.

Сверка с исполнением TradingView проводится отдельно.
