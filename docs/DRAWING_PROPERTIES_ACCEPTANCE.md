# Приёмка доступа к свойствам графических объектов R6

[Исходник ac19dc09152a](https://github.com/s7cret/openpine/commit/ac19dc09152ae2a3311dce28fa9a4ccee5d5ab82) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42752945146) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42752945342)

CI 57/57, Python 3.14.8. В реестре каждой ОС 1 951 тест. Conformance охватывает 4 450 сценариев, корпус — 180 программ.

- Все 15 новых setters и getters проверены в Pine v4–v6. В v1–v3
  проверены отказы. При записи сохраняются режим координат, соседние
  поля, оформление и порядок создания.
- Проверены чтение и запись через прямой ID и через копию линии, найденной
  в `line.all`. Подтверждены каскадное удаление заливки, чтение без событий
  и атомарность записи при исчерпанном бюджете событий.
- Установленный wheel на обеих ОС подтвердил загрузку IR, возобновление
  исторического задания, совпадение журнала с replay и изоляцию preview.
  Прошли 19 браузерных регрессионных сценариев.
- На Windows прошёл 1 951 тест, на Linux — 1 950.
  Linux пропустил проверку псевдонимов файлов Windows 8.3.
  Прошли четыре сценария восстановления.
- Сохранены наблюдения всех 4 436
  прежних сценариев. Добавлено 14 сценариев.
  Отчёты conformance совпадают между Windows и Linux.

OpenPine возвращает `na` для getter по отсутствующему ID,
включая текст метки. Значение сохраняется в обычном и intrabar checkpoint.
Сверка пограничных случаев с TradingView проводится отдельно.
