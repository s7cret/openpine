# Вычисляемые цели: этап R6

- [x] 1. Версионная матрица, отдельный профиль и сохранение старых контрактов.
- [x] 2. Конечный граф const/input, условные строки, конкатенация и общие scalar rules.
- [x] 3. Подтверждённые специализированные inputs v5/v6 и проверка значений/options.
- [x] 4. Общий resolver до получения истории, settings и конкретные графы.
- [x] 5. Варианты исследований, replay/live, checkpoint и переносимые записи.
- [x] 6. Карточки вычисленных целей/зависимостей, ошибки, реальные проверки браузера.
- [x] 7. Полный gate Python 3.14.8, wheel, Windows/Linux, рост и публикация.

Принятая база: `951b0f5095d8cd1c2a7e4bffb846eb68af082a52`, 1046 тестов,
116 модулей и 2116 conformance-наблюдений. Прежние test ID и наблюдения сохраняются.
Новый корпус: 16 исполнений и 6 ожидаемых отказов; ранние формы берутся
из существующих версионных правил. Сравнение с TradingView отдельно.


Принятый исходник: `94dbf083f5ebc77d3a9d23d4df6a6217eadce64d`. Python **3.14.8**.
**1066 тестов / 118 модулей** локально и на каждой ОС. Все **1046** прежних
test ID сохранены; добавлено 20. **2138** conformance-наблюдений: 1426 исполнений
и 712 ожидаемых отказов. Все 2116 прежних наблюдений совпали с базой.
Сохранены все прежние файлы spec, включая 79 файлов immutable bundle, lock
и старые профили. Добавлен отдельный computed-targets профиль.

Отдельно проверена цепочка из 32 aliases: она сохраняет прежний `.prepared`
контракт и его бюджет, не подпадает под глубину 16 вычисляемого профиля.
Новые выражения и специализированные inputs используют `.computed.prepared`.
Есть проверки обеих веток, мутаций/UDF/series, глубины, числа узлов, переполнения
строк, деления и NA по версиям, подмены типов IR и выбранных недопустимых значений.

Worker/replay: сохранённый IR v1–v6, выбранный B1, UDF/SMA/накопление,
пауза/продолжение и новый координатор. Офлайн v1/v6, lower-TF v5/v6.
Исследования проверяют независимые графы experiment, selection/holdout и
walk-forward, отказ до создания заданий при нехватке данных. Live-проверка
сохраняет общую физическую подписку, backup/restore и перенос записи офлайн.

В настоящем браузере defaults A2 заменены условно выбранным B1. Получены
100…107 на восьми барах; перезагрузка автоматически восстановила источник,
inputs и результат. Карточка показывает choose/prefix/interval. Ошибочный
BADYB дал отказ requirements до запуска и удалил прежнюю карточку. Ошибок
JavaScript нет. Артефакт результата и конфигурация проверены по execution/build.

Миллион событий, 800 000 независимо проверенных значений, перезапуск после
100 000 основных баров с шестью ячейками незавершённого окна. Наблюдаемый пик
worker — **183.7 МиБ** при пороге 400 МиБ. Повторный cProfile подготовки
1/32/256 вариантов после локальных наборов: **0.84 /
1.95 / 15.03 с**;
для 256 вариантов сохраняется одно декодирование IR внутри Preparation.
Это измерения данной машины, не универсальная гарантия скорости.

офлайн v1/v6 и lower-TF v5/v6. Содержимое локального и CI wheel совпало побайтово.
