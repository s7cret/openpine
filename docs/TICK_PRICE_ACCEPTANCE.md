Python 3.14.8, CI 57/57, один wheel.
Windows — 2101 успешных тестов. Linux — 2100 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4961 прежних наблюдений conformance
сохранены. Добавлены 12 расчётных сценариев и 12 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. Одна и та же цена округлилась до 100.13 в основном
контексте и 100.25 в запрошенном. Подтверждённое пересечение дало одно
оповещение со строкой 101.00. CLI загрузил сохранённый IR стратегии,
а брокер принял и исполнил лимит 100.25 с шагом 0.25 из снимка.

В первой попытке установочная проверка Windows остановилась на разборе stdout сценария numeric_targets с ошибкой JSONDecodeError: Extra data. Содержимое stdout в журнале GitHub отсутствует. Локальный прогон того же wheel на Windows прошёл все шесть версий и выдал корректный JSON. Установочное задание повторили на том же исходнике и wheel.
[Первый журнал](https://github.com/s7cret/openpine/actions/runs/43757554451/job/132952363976) · [Успешный повтор](https://github.com/s7cret/openpine/actions/runs/43757554451/job/132982770181).

Округление и форматирование по шагу проверены в Pine v4–v6.
Проверены квалификаторы, оба знака половины шага, na, отсутствие
метаданных и завершающие нули. Для Pine v1–v3 подтверждены отказы.
Сравнение с исполнением TradingView остаётся отдельным этапом.
