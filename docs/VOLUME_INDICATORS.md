# Объёмные индикаторы и VWAP

| Форма | Pine |
| --- | --- |
| Переменные `accdist`, `vwap` | v1–v6 |
| Переменные `obv`, `pvt`, вызов `mfi(series, length)` | v4–v6 |
| Вызов `vwap(x)` / `ta.vwap(source)` | v1–v5 |
| Вызовы `ta.vwap(source, anchor)` и `ta.vwap(source, anchor, stdev_mult)` | v5–v6 |

Имена глобальные в v1–v4 и начинаются с `ta.` в v5–v6.
В v1–v2 аргументы позиционные. У записи `mfi` для v2 есть только имя,
поэтому вызов даёт `SPEC_UNRESOLVED`. Для `ta.vwap(source)` в v6
закреплённый bundle не содержит перегрузки. Одноаргументная форма v6
пока остаётся вне профиля OpenPine.

**Накопители.** `accdist` взвешивает объём по положению close внутри
диапазона свечи. Свеча с равными high и low вносит ноль.
`obv` прибавляет или вычитает объём по сравнению с предыдущим
закрытием. `pvt` взвешивает объём по относительному изменению close.
Оба сравнивают с предыдущей физической свечой. Если закрытия равны,
вклад равен нулю при ненулевой базе у `pvt`. Отсутствующий объём
или недопустимый знаменатель пропускает вклад. Результат равен `na`
до первого определённого вклада.

**MFI.** Поток `source * volume` попадает в сумму роста либо падения.
Равные значения вносят ноль в обе суммы. Длина `series int` может
меняться от 1 до 100 000. Окно содержит последние определённые потоки,
включая нулевые, а знак определяется по предыдущему определённому
источнику. Пропущенный объём не добавляет поток. При нулевой сумме
потоков результат равен `na`. [Формула MFI](https://www.tradingview.com/support/solutions/43000502348-money-flow-mfi/).

**VWAP.** Переменная использует `(high + low + close) / 3`. Она и вызов
без явного якоря сбрасываются на первом достигнутом баре каждого дня UTC
в календаре 24×7. Вызов с явным якорем возвращает `na` до первого
`true`. Каждый `true` начинает новый расчёт с текущей свечи.
Нулевой либо отсутствующий объём и отсутствующий источник не меняют
накопители. До первого положительного веса после сброса результат
равен `na`. Трёхпараметрическая форма возвращает
`[VWAP, VWAP + k*σ, VWAP − k*σ]`, где σ — взвешенное по объёму
популяционное отклонение источника после якоря.
[Якорь и полосы в Pine](https://www.tradingview.com/pine-script-docs/release-notes/).

В `request.security` вычисления используют OHLCV и время запрошенных
свечей. Состояние сохраняется в checkpoint. [Пример](../examples/volume-indicators/anchored-vwap.pine)
строит VWAP и полосы и подставляет MFI в оповещение о пересечении.
[Решения о версиях, якорях и прогреве](adr/0057-volume-indicators.md).
