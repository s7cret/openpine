# Среднее и экстремумы переданных аргументов

| Pine | Среднее | Минимум и максимум |
| --- | --- | --- |
| v1–v3 | `avg()`, 2–6 аргументов, `series float` | `min()`, `max()`, справочник описывает два аргумента |
| v4 | `avg()`, 2–32 аргумента, `series float` | `min()`, `max()`, 2–32 аргумента |
| v5–v6 | `math.avg()`, 2–32 аргумента, `simple float` или `series float` | `math.min()`, `math.max()`, 2–32 аргумента |

Поддерживаются позиционные вызовы. В v5–v6 результат `math.avg()` получает
квалификатор `series` при наличии аргумента `series` и `simple` при остальных
аргументах. Функция принимает смесь `int` и `float`, возвращает `float`
и распространяет `na`. Сумма для среднего вычисляется точно по двоичным
значениям входов и округляется до `float` после деления. Это позволяет
усреднять одинаковые значения у предела `float` и сохранять субнормальные значения.
[Закреплённый справочник](../spec/lock.json) · [Миграция Pine v4 → v5](https://www.tradingview.com/pine-script-docs/migration-guides/to-pine-version-5/#all-variable-function-and-parameter-name-changes).

`min/max` используют сильнейший квалификатор аргументов. Для целых
аргументов после связывания возвращают `int`, для смешанных чисел —
`float`. При пропуске возвращают `na`. В v1–v3 диапазон 3–32 аргумента
поддерживается для совместимости OpenPine. Идентификаторы и сигнатуры
числовых вызовов сохраняются. Артефакт предыдущей сборки привязан к её
вычислительной идентичности. Для запуска в новой сборке нужно заново
скомпилировать сохранённый Pine.
[Базовый числовой ABI](NUMERIC_TARGETS.md) · [Переход между сборками](UPGRADE_ACCEPTANCE.md).
