Python 3.14.8, CI 57/57, один wheel.
Windows — 2088 успешных тестов. Linux — 2087 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4871 прежних наблюдений conformance
сохранены. Добавлены 22 расчётных сценария и 6 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. Сохранились значения и RGBA графика, а переход
двухминутного изменения через ноль вызвал одно оповещение.

Формы `change` проверены в Pine v1–v6, цветовой `ta.valuewhen` в v5–v6.
Проверены значение длины по умолчанию, пропуски, разница bool между
версиями и файловое восстановление очереди из 100 000 событий.
Сравнение с исполнением TradingView остаётся отдельным этапом.
