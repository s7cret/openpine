сохранены. У прежнего корпуса **56 программ**, из них **50 исполняемых** и **6 ожидаемых
отказов**; все **356 применимых сравнений**, включая native state, побайтово совпадают
с предыдущей приёмкой. Новое сравнение прошло отдельно для history и replay всех
50 программ на обеих ОС; различие моделей корректно отклонялось. CLI v1–v6 и HTTP
возвращают один отчёт.

CFE `eb4243728a306ec127a339b6691a10275142be257fd8851887dba7ca7160cac9` и SQLite **16** не менялись. Проверка настоящего
предыдущего wheel подтвердила продолжение исторического checkpoint с бара 2, replay
до четырёх баров и двух вариантов исследования. Старый результат прошёл новое сравнение.
Отдельный настоящий результат ещё более раннего CFE читался и сравнивался, но его
диагностическое исполнение получило `COMPUTATION_INCOMPATIBLE`; исходный результат
сохранён и скрытых перекомпиляций не было.

обычные метрики. Зафиксированные пределы: 50 миллионов записей и 64 MiB scratch-индекса;
достижение предела не даёт положительного вывода о полном совпадении.

Проверен переход предыдущий wheel → новая сборка. Обратное открытие каталога с новыми
индексами диагностики прежней сборкой не входит в этот контракт; для отката используется
копия каталога, сделанная перед обновлением.

Срок хранения по умолчанию отключён и формирует кандидатов для явного удаления.
Физическое освобождение файлов выполняется штатным offline GC. Результаты без поддержанного
streamed ABI/закреплённого IR отклоняются явно. Совпадение данных конкретных запусков
не является доказательством эквивалентности всей программы или TradingView.
