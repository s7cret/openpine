Python 3.14.8, CI 57/57, один wheel.
Windows — 2191 успешных тестов. Linux — 2190 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены все 5430
прежних наблюдений.
Добавлены 4 исполняемых сценариев и
2 ожидаемых отказов.

Из общего wheel проверены исторические задания CLI и HTTP, сохранённый IR, повторная доставка событий и восстановление replay. Историческая стратегия подала заявку на баре 2 с исполнением по 103 на баре 3. В replay заявка появилась на баре 26 и исполнилась по 127 на баре 27. Журнал воспроизведён во всех 29 точках восстановления.

Первый локальный запуск получил HTTP 503 по резерву памяти. Повтор из того же wheel прошёл со штатными лимитами после освобождения памяти.

Пакетная проверка неизменённого коммита локально и в GitHub прошла.

Финансовый год завершился 30 сентября. Проверены USD/EUR, оба режима gaps, один и тот же сохранённый IR, старый и исправленный снимки и журнал сделок. В EUR исторический сигнал изменился после выбора исправленного снимка. В replay покупка исполнена 9 октября по 105. Все восемь нагрузочных комбинаций прочитали свечи один раз и загрузили снимок один раз с двумя чтениями файла для проверки SHA и декодирования. [Профиль](FINANCIAL.md).
Сравнение с исполнением TradingView ведётся отдельно.
