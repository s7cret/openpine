Python 3.14.8, CI 57/57, один wheel.
Windows — 2092 успешных тестов. Linux — 2091 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4899 прежних наблюдений conformance
сохранены. Добавлены 15 расчётных сценариев и 6 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. Двухминутное среднее OHLC с ограничением через min/max
дало одно оповещение после подтверждённого пересечения.

Формы avg, min и max проверены в Pine v1–v6. Покрыты версии арности,
квалификаторы, na и конечное среднее при больших входах.
Для запуска на новом wheel сохранённый Pine компилируется заново.
Во всех шести версиях проверены совпадение прежних связанных вызовов
и совпадение результатов после перекомпиляции.
Сравнение с исполнением TradingView остаётся отдельным этапом.
