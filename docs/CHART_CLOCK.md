# Границы графика и торговый день в OpenPine

| Переменная | Pine | Значение |
| --- | --- | --- |
| `last_bar_time` | v5–v6 | Время открытия последней доступной свечи |
| `last_bar_index` | v5–v6 | Индекс последней доступной свечи, начиная с нуля |
| `time_tradingday` | v4–v6 | UTC-полночь последнего торгового дня свечи |

Все три переменные имеют тип `series int`. Исторический запуск читает
время открытия последней свечи и число свечей из закреплённого снимка.
Оба значения доступны уже на первом баре. Пауза, пакетная выдача результата
и восстановление используют одну границу. В `request.security()`
переменные читают данные запрошенного контекста.
[Документация времени последнего бара](https://www.tradingview.com/pine-script-docs/concepts/time/#last_bar_time) ·
[Справочник индекса](https://www.tradingview.com/pine-script-reference/v5/#var_last_bar_index).

Для загруженного исторического префикса replay параметр окружения
`history_last_ms` задаёт время открытия последней исторической свечи.
`history_last_index` закрепляет её порядковый номер для
`last_bar_index`. Эти поля передаются для каждого контекста в
`environments` запроса создания replay. Например, в префиксе из
трёх свечей индекс равен 2 даже при пропусках минут. Пары времени и
индекса сверяются с подтверждёнными событиями. При чтении
`last_bar_index` в исторической фазе без закреплённого индекса
возвращается диагностика `LAST_BAR_HISTORY_INDEX`.

После исторического префикса граница обновляется с первым пришедшим
событием новой свечи. Если запись содержит только закрытия, граница
обновляется на первом полученном закрытии этой свечи. Все ревизии
одной свечи используют одну пару. Подтверждённые выводы сохраняют
границу, доступную в момент вычисления.

В профиле UTC 24×7 `time_tradingday` возвращает UTC-полночь даты
открытия минутной или дневной свечи. Для W/M это полночь последнего
календарного дня периода. Например, неделя, открытая 26 февраля 2024 года,
даёт 3 марта, а месячная свеча за февраль — 29 февраля.
[Торговый день в Pine](https://www.tradingview.com/pine-script-docs/concepts/time/#time_tradingday).

[Стратегия](../examples/chart-clock/recent-bars.pine) разрешает вход
в пределах последних двух свечей. На разреженном снимке из пяти
свечей исторический запуск создаёт заявку на индексе 3. В replay с
первоначальным префиксом из трёх свечей заявка появляется на индексе 1.
Сохранённый IR, очередная ревизия и восстановление используются
в проверках обеих цепочек. [Сценарии](../conformance/chart-clock/cases.json) ·
[ADR 0073](adr/0073-chart-clock.md).

Профиль имеет статус `PARTIAL`. Календарь торговых дней и наблюдаемые
границы проверены для принятой модели OpenPine. Сравнение с исполнением
TradingView ведётся отдельно.
