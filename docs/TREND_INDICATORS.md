# DMI, Supertrend и Parabolic SAR

| Pine | DMI и Supertrend | Parabolic SAR |
| --- | --- | --- |
| v1–v2 | — | `sar(x,y,z)`, позиционные аргументы |
| v3 | — | `sar(start,inc,max)` |
| v4 | `dmi(diLength,adxSmoothing)`, `supertrend(factor,atrPeriod)` | `sar(start,inc,max)` |
| v5–v6 | `ta.dmi(diLength,adxSmoothing)`, `ta.supertrend(factor,atrPeriod)` | `ta.sar(start,inc,max)` |

DMI возвращает `[+DI, −DI, ADX]`. Для направленного движения и True Range
нужна предыдущая физическая свеча. При равных встречных движениях оба
вклада равны нулю. DI рассчитывается после прогрева RMA, ADX после
прогрева второй RMA. При нулевом сглаженном True Range используется
последняя определённая пара DI, до её появления результат равен `na`.
При нулевой сумме определённых DI вклад в ADX равен нулю.

Supertrend возвращает `[линия, направление]`. Направление `-1`
соответствует росту, `+1` снижению. До прогрева ATR линия равна `na`,
а направление равно `+1`. Для смены направления цена закрытия должна
пересечь границу строго. `factor` может меняться по барам. Пропуск
в `factor` даёт `na` для линии и сбрасывает её границы, ATR продолжает
считать диапазон.

SAR инициализируется при первом вызове с двумя доступными закрытиями.
При непрерывном расчёте это вторая свеча. При равных закрытиях начальное
направление нисходящее. На каждом следующем расчёте учитываются разворот,
экстремум тренда, шаг ускорения и границы двух предыдущих свечей.
Параметры ускорения фиксированы для каждого вызова.
Параметры принимают конечные числа с `0 <= start <= max` и `inc >= 0`.

Длины DMI и ATR принимают `simple int` от 1 до 100 000. В
`request.security` рыночные входы и состояние принадлежат запрошенному
контексту. Если ветка с вызовом не выполнилась, состояние этого вызова
не обновляется. На следующем вызове индикатор использует физические
предыдущие свечи запрошенного контекста.

и SAR и подставляет ADX в оповещение о развороте. Для подстановки в replay
выберите [профиль шаблонов](ALERTS.md).
