# Чистые UDF в целях запросов

1. Закрепить v1–v6 правила, типы, qualifiers и историческую реконструкцию.
2. Проверять чистоту всего вызываемого графа, включая непрочитанные результаты.
3. Расширить общий evaluator существующими UserCallIR/BlockIR и lexical bindings.
4. Ограничить совокупные узлы, глубину и значения без обнуления в функциях.
5. Провести один граф через подготовку, worker, исследования, replay и live.
6. Добавить независимые all-version корпуса и проверки восстановления/offline.
7. Принять один исходник на Python 3.14.8, Windows/Linux и установленном wheel;
   сохранить 1084 прежних test ID, 2176 наблюдений и прежние файлы spec.

Границы и воспроизведение: [FUNCTION_TARGETS.md](FUNCTION_TARGETS.md).
Окончательные результаты добавляются после полной приёмки зафиксированного исходника.


Принятый исходник: `dd3bf59609b1d063da338d7e7bd0aadc96779d60`, Python **3.14.8**.
Все семь пунктов завершены. **1105 теста / 125 модуля** локально и на каждой ОС;
сохранены все 1084 прежних test ID, добавлено 21. Прежний тест отказывает
вызовам через computed/primary evaluator; исходник с чистым вызовом теперь
получает отдельный function-targets overload. История, series, мутации и
недопустимые ветки по-прежнему отклоняются. Старые helpers сохранены; общий
установочный helper переиспользован с прежними параметрами по умолчанию.

**2214 conformance observations**: 1490 исполнений и 724 ожидаемых отказа.
Все 2176 прежних наблюдений, прежние файлы spec, lock и 79 файлов immutable
bundle сохранены. Новый профиль содержит 38 независимых наблюдений и ссылается
на закреплённые правила scalar функций и историческую реконструкцию primary.

Проверены скрытые эффекты во всех инструкциях, аргументах и обеих ветках;
lexical captures, shadowing, forward calls, typed qualifiers, исходный порядок
и однократность вычисления аргументов, общий бюджет узлов/глубины/значений,
подмена IR и ограничения старых evaluator. Function bodies входят в program hash
нового графа; источники и сырые параметры не переписываются.

Один IR v1–v6 проверен на разных основных рынках через реальные worker с
pause/resume, experiment, selection/holdout, walk-forward, replay restart и
offline-повтор. Для v5/v6 проверены lower-TF; live сохраняет общую подписку
и перенос записи через backup. CLI разрешает requirements без свечей, HTTP
возвращает needs_primary до получения необходимых метаданных.

В настоящем браузере UDF-цели одного IR дали 107 на TEST:B/1 и 17 на TEST:A/1.
Пустые raw inputs и результат восстановились после reload. Старый снимок
сбрасывается при смене рынка; ошибок JavaScript нет. Graph program_sha256,
execution hash и artifact build обоих результатов сверены с исходником.
