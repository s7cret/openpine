# Чистые UDF в целях запросов

1. Закрепить v1–v6 правила, типы, qualifiers и историческую реконструкцию.
2. Проверять чистоту всего вызываемого графа, включая непрочитанные результаты.
3. Расширить общий evaluator существующими UserCallIR/BlockIR и lexical bindings.
4. Ограничить совокупные узлы, глубину и значения без обнуления в функциях.
5. Провести один граф через подготовку, worker, исследования, replay и live.
6. Добавить независимые all-version корпуса и проверки восстановления/offline.
7. Принять один исходник на Python 3.14.8, Windows/Linux и установленном wheel;
   сохранить 1084 прежних test ID, 2176 наблюдений и прежние файлы spec.

Границы и воспроизведение: [FUNCTION_TARGETS.md](FUNCTION_TARGETS.md).
Окончательные результаты добавляются после полной приёмки зафиксированного исходника.
