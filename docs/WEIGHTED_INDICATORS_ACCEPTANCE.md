Python 3.14.8, CI 57/57, один wheel.
Windows — 2077 успешных тестов. Linux — 2076 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4805 прежних наблюдений conformance
сохранены. Добавлены 19 расчётных сценариев и 17 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
закрытием свечи. COG в двухминутном контексте пересёк уровень −1,75,
и оповещение появилось один раз.

ALMA и COG проверены в Pine v1–v6, HMA в Pine v4–v6.
Проверены длины по версиям, обе формы ALMA с v4, пропуски и
файловое восстановление HMA на окне в 100 000 значений.
Сравнение с исполнением TradingView остаётся отдельным этапом.
