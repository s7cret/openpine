# Приёмка лучей и чтения цены линии

[Исходник 210605f0e505](https://github.com/s7cret/openpine/commit/210605f0e5057298e872dad324b996552944e7fd) · [CI 41735056105](https://github.com/s7cret/openpine/actions/runs/41735056105)

CI 57/57, Python 3.14.8, 1835 test ID на ОС, 3750 conformance-наблюдений, 180 программ. Проверены SHA-256 и происхождение всех 57 архивов.
Обе ОС и четыре сценария восстановления использовали wheel
1ef6b4fbfcfbeaa8c45d33430613cd04644db1bc12fd61e49b40d19a13197b64.

- На Windows прошли 1835 тестов. На Linux прошли 1834 теста
  с одним ожидаемым пропуском проверки Windows 8.3.
- Новый набор содержит 6 успешных исполнений и 9 ожидаемых отказов.
  Результаты 3735 прежних наблюдений сохранились с обновлённой
  идентичностью программы.
- Установочные проверки v4–v6 подтвердили один и тот же расчёт цены
  при смене режима, четыре события журнала и восстановление с бара 2.
  Replay v6 показал режим открытого бара отдельно от подтверждённого.
- График отображает луч при обеих исходных точках за окном.
  Chrome проверил продление в обе стороны, обрезку и live preview.
- Все 180 программ корпуса дали одинаковые переносимые
  свидетельства на обеих ОС.

Границы описаны в [профиле](LINE_EXTENSIONS.md). Сверка исполнения с
TradingView проводится отдельным этапом. Машиночитаемая запись доступна
в [JSON](evidence/line-extensions-20261104.json).
