# Защитные выходы стратегий R6

- [x] 1. Версионный контракт exit/cancel, доказательства и явная OHLC-модель.
- [x] 2. Компилятор → Typed IR → типизированные торговые intents.
- [x] 3. Исполнение stop/limit, гэпы, неоднозначность, комиссии и slippage.
- [x] 4. Создание, изменение, отмена, связь с конкретным входом и закрытием.
- [x] 5. Checkpoint, восстановление и совместимость политик.
- [x] 6. График, журнал и отчёт; experiments/search/walk-forward.
- [x] 7. Независимый корпус v1–v6, аварии, wheel и CI Windows/Linux.

Первый профиль: абсолютные stop/limit, полный выход, одна позиция и одна
защитная группа. from_entry задан явно. Для v1/v2 сигнатуры реконструированы;
для v3–v6 принят ограниченный срез локальных каталогов. При двух касаниях
без пересечения уровня на open выбирается stop и фиксируется неоднозначность.
Модель не восстанавливает действительный путь цены внутри свечи.
Точное сравнение с TradingView остаётся отдельным этапом.

Приёмка: Python 3.14.8; 424 теста / 50 модулей, 479 conformance-сценариев.
Все девять заданий CI Windows/Linux успешны на `af49817`.
