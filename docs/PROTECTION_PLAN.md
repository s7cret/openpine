# Защитные выходы стратегий R6

- [ ] 1. Версионный контракт exit/cancel, доказательства и явная OHLC-модель.
- [ ] 2. Компилятор → Typed IR → типизированные торговые intents.
- [ ] 3. Исполнение stop/limit, гэпы, неоднозначность, комиссии и slippage.
- [ ] 4. Создание, изменение, отмена, связь с конкретным входом и закрытием.
- [ ] 5. Checkpoint, восстановление и совместимость политик.
- [ ] 6. График, журнал и отчёт; experiments/search/walk-forward.
- [ ] 7. Независимый корпус v1–v6, аварии, wheel и CI Windows/Linux.

Первый профиль: абсолютные stop/limit, полный выход, одна позиция и одна
защитная группа. from_entry задан явно. Для v1/v2 сигнатуры реконструированы;
для v3–v6 принят ограниченный срез локальных каталогов. При двух касаниях
без пересечения уровня на open выбирается stop и фиксируется неоднозначность.
Модель не восстанавливает действительный путь цены внутри свечи.
Точное сравнение с TradingView остаётся отдельным этапом.
