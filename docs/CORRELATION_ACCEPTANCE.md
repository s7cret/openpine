Python 3.14.8, CI 57/57, один wheel.
На Windows прошли 2072 тестов. На Linux прошли 2071 тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Все 4780 прежних наблюдений conformance
сохранены. Добавлены 10 расчётных сценариев и 15 ожидаемых отказов.
Отчёты Windows и Linux совпадают. На установленном wheel обеих ОС
график и журнал оповещений совпали после восстановления перед
подтверждённым пересечением нуля. Оповещение было доставлено один раз.

В первой попытке набора Windows observed трассировка ранее существующего сценария завершилась с WORKER_HEARTBEAT после 16,58 с без heartbeat. Код, wheel и лимиты сохранены.
