# Изменяемые отрезки Pine v4–v6

Индикаторы поддерживают `line.new(x1, y1, x2, y2)`, `line.set_xy1(id, x, y)`,
`line.set_xy2(id, x, y)` и `line.delete(id)`. Для v1–v3 тип и эти вызовы
получают `LINE_VERSION`. Основание для версии и перегрузки закреплено в
[профиле линий](../spec/lines-profile.json).

```pine
//@version=6
indicator("Moving line and label", overlay=true)
var line track = na
var label tag = label.new(na, na, "moving")
if bar_index == 0
    track := line.new(0, close, 0, close)
alias = track
line.set_xy2(alias, bar_index, close)
label.set_xy(tag, bar_index, close)
```

Обе точки используют индексы баров и цены. Отсутствующая координата или
совпадающие точки скрывают отрезок до изменения координат. Вертикальный
отрезок с разными ценами виден. Обычные и `var`-переменные могут
ссылаться на один объект. Setter или повторное удаление отсутствующей,
удалённой или вытесненной ссылки ничего не меняют.

По умолчанию OpenPine удерживает до 50 линий на индикатор и вытесняет самую раннюю по
созданию. Лимит событий одного бара для линий равен 1024. Метки и линии
имеют отдельные счётчики и лимиты. После checkpoint новая линия получает
следующий ID, включая случай, когда прежняя линия уже удалена.
[Лимиты](DRAWING_LIMITS.md) · [Копирование и `line.all`](DRAWING_OBJECTS.md)

API возвращает живой отрезок, если его X-диапазон пересекает запрошенные
бары, даже когда обе точки лежат за окном. Canvas обрезает его по
границам окна и рассчитывает масштаб по видимой части. В v5–v6
`force_overlay=true` направляет конкретный отрезок на ценовую панель.
При `false` или пропущенном флаге отрезок наследует `overlay` индикатора.
[Размещение рисунков](DRAWING_OVERLAY.md)

Журнал доступен по `/api/jobs/{id}/line_events?start=0&limit=100` и
`/api/replays/{id}/line_events?start=0&limit=100`. Страницы журнала
содержат только подтверждённые создания, обновления и удаления.
Предпросмотр открытого бара использует отдельный снимок.

Четыре базовые операции образуют профиль конечных отрезков. Режимы
продления и `line.get_price` описаны в [профиле лучей](LINE_EXTENSIONS.md).
[Координаты времени](DRAWING_XLOC.md) поддерживаются в отдельном профиле.
Точечная перегрузка и сеттеры описаны в [профиле `chart.point`](CHART_POINTS.md).
[Цвет, стиль и ширина](LINE_STYLES.md) описаны в профиле оформления.
Коллекции и `varip line` входят в отдельные области покрытия. Проверки исполнения
на TradingView проводятся отдельно от
[внутреннего conformance](../conformance/lines/cases.json).
