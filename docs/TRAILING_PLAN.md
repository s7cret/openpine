# Приёмка относительных выходов и trailing

- [x] Версионные контракты и companion bundle, источники и границы реконструкции.
- [x] Расчёт тиков от фактических лотов и закреплённых метаданных.
- [x] Композиция trailing в существующем broker, проверяемый checkpoint.
- [x] Явный порядок open/OHLC, текущий и следующий стоп.
- [x] Частичные количества, OCA, отмена и повтор exit.
- [x] Установленный пакет, CLI/HTTP, исследования и браузер.
- [x] Полная регрессия, миллион свечей, восстановление, CI и публикация.

Пункты приёмки закрываются по фактическим результатам Python 3.14.8.
Сравнение результатов с внешним исполнением TradingView остаётся отдельным этапом.

Принято на Python 3.14.8: 776 тестов в 86 модулях; 1807 conformance-сценариев
(1231 исполнение, 576 ожидаемых отказов); 18 новых стратегий-примеров.
Все 1118 прежних успешных исполнений сохранили результаты, 71 прежний
файл bundle неизменен. Проверены восемь installed-групп, CLI/HTTP,
подбор и два walk-forward окна, браузер v1/v4/v6 и восстановление подготовки.

Миллион основных и 250 тысяч старших свечей: пять миллионов выходных
значений сверены независимым чтением Parquet. Принудительное падение
воркера, перезапуск координатора и восстановление backup дают одинаковый
результат. Память воркера не вышла за 512 MiB.

[CI 40199292978](https://github.com/s7cret/openpine/actions/runs/40199292978): 23/23 jobs, по 776 тестов
и восемь installed-групп на Linux и Windows. Шарды используют закреплённые
измерения длительностей без пропусков модулей.

При первом Windows installed-прогоне запись checkpoint на каждом баре
упёрлась в 120 секунд на 432/480 свечах. Installed-сценарий теперь пишет
периодический checkpoint раз в восьмибарный цикл и обязательно на критической
паузе. Проверка восстановления на каждой границе сохранена в native-тестах.
Изменён только helper приёмки; байты runtime и native-тестов совпадают.
Различия двух wheel проверены побайтно, изменённый helper повторно выполнен
из финального wheel; финальный CI проверил все группы на обеих ОС.
