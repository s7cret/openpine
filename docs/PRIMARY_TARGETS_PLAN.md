# Основной контекст в целях запроса

Этап: отдельный профиль primary-targets для Pine v1–v6.

1. Закрепить матрицу Wiki, явно обозначить реконструкцию ранних пустых значений.
2. Компилировать и читать символический IR без выбора основного рынка.
3. Разрешать две whitelisted simple ссылки общим bounded evaluator.
4. Хранить пустые raw inputs отдельно от эффективных целей.
5. Передавать один граф в worker, исследования, replay, live и записи.
6. Показывать needs_primary без истории, затем конкретные цели по метаданным.
7. Принять один исходник на Python 3.14.8, Windows/Linux и установленном wheel;
   сохранить прежние 1066 test IDs и 2138 conformance observations.

Проверки и границы профиля: [PRIMARY_TARGETS.md](PRIMARY_TARGETS.md).
Окончательные результаты публикуются после полной приёмки текущего исходника.
