# Приёмка визуальных панелей R6

[Исходник 42d40cb922e2](https://github.com/s7cret/openpine/commit/42d40cb922e206dc59f264b528f06b5ebf5f8a08) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42382219998) · [Проверка теста паспорта](https://github.com/s7cret/openpine/actions/runs/42385015633) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42385019243)

CI 57/57, Python 3.14.8, 1 893 теста в реестре каждой ОС, 4 188 наблюдений conformance, 180 программ корпуса.

- В v5–v6 проверены стили и ширина полилиний и принудительная панель
  для обычных рядов, рядов со ссылкой, фона и сигнальных меток.
  Предпросмотр и сохранённые результаты replay прошли проверку после
  перезапуска. Десять браузерных сценариев прошли в Chrome.
- На Windows прошли 1 893 теста, на Linux — 1 892.
  Проверка файловых псевдонимов Windows 8.3 на Linux ожидаемо пропущена.
  Обе ОС использовали один wheel. Проверены четыре сценария восстановления.
- Совпали 4 152 из 4 154 прежних наблюдений. В двух отрицательных
  сценариях полилиний прежний седьмой аргумент теперь разбирается как стиль и
  выдаёт ARGUMENT_TYPE. Добавлены 34 сценария
  в четырёх наборах, включая 12 из предыдущей пачки по таблицам.
  Сравнение отчётов учитывает хеш программы, привязанный к исходнику.
- Заливка между панелями сохраняет обе ссылки. График рисует её только
  в общей панели. Полилинии используют прямые сегменты, стрелки привязаны
  к концам открытого контура. Сверка с TradingView относится к отдельному этапу.

Первый кандидат остановился на тесте паспорта программы. Тест брал
отчёты предыдущей приёмки из checkout и отклонял их по хешу реализации.
Исправленный тест строит отчёт для временной копии сценариев.
