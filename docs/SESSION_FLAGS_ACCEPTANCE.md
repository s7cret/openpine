Python 3.14.8, CI 57/57, один wheel.
Windows — 2145 успешных тестов. Linux — 2144 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены все 5199
прежних наблюдений.
Добавлены 19 исполняемых сценариев и
31 ожидаемых отказов.

На общем wheel CLI прочитал IR, сохранённый HTTP-компилятором.
Исторический воркер восстановился после третьей свечи. Replay
возобновился из checkpoints после открытия, затем после обновления
свечи, закрывающей день. Значения до подтверждения отсутствовали.
Индикатор вернул суммы 5 и 30 за дни с полученным закрытием в полночь.
Проверены пропуск финальной свечи, версии Pine, ограничения периодов,
дневные флаги запрошенного контекста и история флага в стратегии.


В статической матрице переменные имеют статус PARTIAL.
Границы торговой сессии UTC 24×7 описаны в [профиле](SESSION_FLAGS.md).
Сравнение с исполнением TradingView ведётся отдельно.
