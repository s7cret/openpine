# Приёмка динамических и вложенных запросов

Исходник `232b0a8dd4bce4408cc67a7f7ad07ff233a7bc4b`, Python 3.14.8. Windows и Linux проверили один wheel с SHA-256 `b60f3cc57dfbcf4e9e306d40a6242ae3c50b92711899b6aa4b376ac769275dd8`. [Прогон GitHub Actions](https://github.com/s7cret/openpine/actions/runs/45070620301).

На Windows прошли 2265 тестов, на Linux — 2264. На Linux пропущена проверка коротких путей Windows. Сохранены все 2221 прежних идентификаторов тестов.

В предыдущем прогоне проверка паспортов ожидала 174 исполняемых программы. Теперь она сверяет каждый паспорт с манифестом корпуса, в котором 179 исполняемых программ и шесть ожидаемых отказов. Группа economics в Windows достигла предела ожидания на последнем из 20 сценариев. На данном wheel локальный повтор всей группы завершил корпус за 661.325 с при лимите 1500 с. [Предыдущий прогон](https://github.com/s7cret/openpine/actions/runs/44940652025).

Первый локальный запуск группы OCA остановился при чтении статуса поиска через localhost с ошибкой Windows 10048. При повторе на том же wheel прошли обе части группы. Корпус из пяти программ занял 152.651 с. Для каждой программы хеш результата совпал на локальной Windows и на обеих платформах CI.

Проверены 5543 сценариев спецификации. У 5536 результаты совпали с базовой версией. Семь изменений диагностики приведены ниже.

При включённых динамических запросах конечный выбор рынка допускается до привязки данных. Отсутствующее покрытие для выбранного контекста даёт `DYNAMIC_COVERAGE_MISSING`. Для выражения вне поддержанного профиля сохраняется отказ с кодом `REQUEST_SCOPE`.

Проверка восстановления завершила процесс воркера после фиксации checkpoint и повторно отправила часть событий. График и журнал сделок после перезапуска совпали с непрерывным запуском. Исполнение произошло по цене 13 на основном инструменте. После поправки FX последнее значение старого задания осталось 128, новое задание получило 120.

После исправления свечи B приостановленное задание и полный повтор по прежнему снимку дали ряд 10, 32, 14, 36. Запуск по обновлённому снимку дал 10, 32, 14, 96.

После остановки координатора и воркера задание продолжило расчёт с бара 10000. Проверены 3000000 значений в Parquet. При имитации заполненного диска сохранились ранее записанные данные, после восстановления из копии продолжилась сборка мусора.

Внутри открытого бара восстановление прошло для Pine v1–v6. В сумме обработано 304128 событий. В отдельном прогоне с перезапуском процесса сверены все 10000020 точек выходных рядов.
