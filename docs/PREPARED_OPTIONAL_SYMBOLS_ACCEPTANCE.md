# Приёмка выбора рынка из настроек с ignore_invalid_symbol

Python 3.14.8. На Windows прошли 2212 тестов, на Linux 2211. Проверка коротких путей Windows пропущена на Linux. CI завершил 57 заданий. Установка использовала один wheel на обеих платформах.

Отчёты обеих ОС совпали по всем 104 файлам. Сохранены 5491 прежних наблюдений без изменений. В новой выборке 10 исполнений и 8 ожидаемых отказов.

Через CLI и HTTP один сохранённый IR индикатора и один IR стратегии проверены с тремя рынками. Выбор известного рынка даёт значения, подтверждённое отсутствие даёт пропуски, отсутствие сведений вызывает ошибку входа. У стратегии при подтверждённом отсутствии была одна заявка и одно исполнение по цене 3 на третьем баре. Восстановление и повторная доставка десяти событий дали тот же график и журнал.

Для security и security_lower_tf на 100 тысячах и миллионе основных баров сравнены все выходные значения литеральных и подготовленных запросов. Совпали хеши рядов, два открытия снимков, одно разрешение каталога и одна группа чтения. Внешняя сверка с TradingView остаётся отдельным этапом.

Сохранённые IR без флага предыдущей сборки для v1–v6 декодированы. После перекомпиляции совпали узлы запросов и результаты.

При первом запуске установочной проверки contexts на Ubuntu HTTP /start вернул 503 COORDINATOR_BUSY. Слот prepare был занят, ответ указал slot_limit и retryable=true. Повтор выполнен на том же исходнике и wheel с прежними лимитами.
