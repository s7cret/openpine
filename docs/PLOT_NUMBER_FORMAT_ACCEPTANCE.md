# Приёмка формата чисел на графике R6

[Исходник b42a9bc69e63](https://github.com/s7cret/openpine/commit/b42a9bc69e63857992560b54dadbee3a0ab2e931) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42602857456) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42602857740)

CI 57/57, Python 3.14.8. В реестре каждой ОС 1 924 теста. Conformance охватывает 4 396 сценариев, корпус — 180 программ.

- Поддержка деклараций подтверждена по закреплённым версиям v1–v6.
  Для всех шести функций `plot*` в v5–v6 проверены `format` и `precision`.
  Проверки включают значения точности 0 и 16 и явные отказы за пределами
  профиля. Политика исполнения стратегии сохранена.
- Прошли 17 браузерных сценариев. Проверены наследование,
  переопределение, цена, проценты, суффиксы K/M/B/T, пропуски и OHLC.
  Формат шкалы ряда, статуса и окна данных совпадает в истории и replay.
- Установленный wheel на обеих ОС подтвердил сохранение метаданных
  после смены пресета и возобновления worker. Числа в Parquet и экспорте
  сохранились, полные результаты CLI и HTTP совпали.
- На Windows прошло 1 924 теста, на Linux — 1 923.
  На Linux ожидаемо пропущена проверка псевдонимов файлов Windows 8.3.
  Обе ОС использовали один wheel. Прошли четыре сценария восстановления.
- Сохранены наблюдения всех 4 382
  прежних сценариев и байты закреплённой спецификации. Добавлено
  14 сценариев. Отчёты совпали между Windows и Linux.
  Внешняя сверка строк отображения с TradingView проводится отдельно.
