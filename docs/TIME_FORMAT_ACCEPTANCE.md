Python 3.14.8, CI 57/57, один wheel.
Windows — 2109 успешных тестов. Linux — 2108 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены 5012
прежних наблюдений. Добавлены 10 исполняемых сценариев и
18 ожидаемых отказов. Они покрывают часовые пояса,
границы DST, миллисекунды, календарные маски и поведение пропусков.

На осеннем переводе часов в Нью-Йорке одна свеча открылась в 01:59
со смещением -0400 и закрылась в 01:00 со смещением -0500. После
восстановления перед закрытием сохранилась одна метка и появилось
одно оповещение с обоими временами. Журналы и график совпали с
непрерывным прогоном. CLI прочитал сохранённый IR и вывел ту же метку.
Эти проверки прошли на общем wheel Windows и Linux с tzdata 2026.6
и базой IANA 2026f.

В статической матрице две строки str.format_time имеют статус PARTIAL.
Сравнение с исполнением TradingView ведётся отдельно.
