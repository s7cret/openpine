# Приёмка временных координат рисунков Pine v4–v6

[Исходник 08e65032beca](https://github.com/s7cret/openpine/commit/08e65032becab1eb7d3e60537df79d95f3d73f2a) · [CI 41907313030](https://github.com/s7cret/openpine/actions/runs/41907313030)

CI 57/57, Python 3.14.8, 1847 зарегистрированных тестов на каждой ОС, 3836 наблюдений conformance, 180 программ.
Проверены происхождение и SHA-256 всех 57 архивов CI.
Обе ОС и четыре сценария восстановления использовали wheel
`6a5cf2f7ea44f6a454e716bc8318d9199ad5d306a118ce08681d21c0509278fd`.

- Windows — 1847 тестов. Linux — 1846 тестов
  и 1 ожидаемый пропуск проверки Windows 8.3.
- Новый набор содержит 8 исполнений и 15
  ожидаемых отказов. У 3804
  прежних наблюдений сохранено поведение. Девять сценариев со
  строковым `xloc` в конструкторах теперь выдают `DRAWING_XLOC`.
- На обеих ОС воркеры v4–v6 продолжили с бара 2. Результаты и
  журналы сохранили исходные координаты, а соседние окна графика
  дали одинаковую проекцию.
- Replay подтвердил смешанный `linefill` и отдельную временную ось
  предпросмотра. Chrome проверил позиции меток, линий и зон
  и построение заливки между границами с разными режимами X.
- Все 180 программ корпуса дали одинаковые переносимые
  свидетельства на обеих ОС. Сохранены
  62 явно отмеченных различия моделей.
