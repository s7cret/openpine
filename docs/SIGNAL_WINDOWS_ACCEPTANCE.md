# Приёмка стрелок и окна сигнальных меток R6

[Исходник adef53660a21](https://github.com/s7cret/openpine/commit/adef53660a212fe757e9367debaa5735b1430720) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42413350541) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42413353956)

CI 57/57, Python 3.14.8, 1 901 тест в реестре каждой ОС, 4 253 сценария conformance, 180 программ корпуса.

- `plotarrow` работает для Pine v1–v6. Параметр `show_last` доступен для стрелок,
  фигур и символов с v3. Двенадцать браузерных сценариев прошли в Chrome.
  Проверены направление, высота, обе панели и смещение в обе стороны.
- Parquet и checkpoint сохраняют максимум модуля подтверждённого
  ряда. Открытый бар меняет высоту только в предпросмотре.
  Тест с перезапуском replay подтвердил границы окна и смещения.
- На Windows прошёл 1 901 тест, на Linux — 1 900.
  Проверка файловых псевдонимов Windows 8.3 на Linux ожидаемо пропущена.
  Обе ОС использовали один wheel. Проверены четыре сценария восстановления.
- Совпали результаты всех 4 222 прежних сценариев. Добавлен 31 сценарий
  сигналов. Все отчёты совпали между Windows и Linux. Сверка с TradingView относится к отдельному этапу.
