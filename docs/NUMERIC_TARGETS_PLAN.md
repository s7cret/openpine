# Этап: базовая математика и общий scalar-реестр

1. Закрепить Wiki v1–v6: типы, сигнатуры, qualifiers и источники различий.
2. Перенести прежние числовые ядра в общую инфраструктуру без изменения ABI; сохранить отдельные правила round/formatter.
3. Добавить floor, ceil, sign, sqrt, pow, log, log10 и exp с domain/NA/overflow ограничениями.
4. Допустить выбранную математику в новом профиле чистых целей и UDF; прежние профили оставить закрытыми.
5. Подключить те же ядра внутри security и lower-TF с частным запрошенным контекстом.
6. Проверить независимые оракулы, границы и общий бюджет, worker/research/replay/live/checkpoints.
7. Полная приёмка Python 3.14.8, Windows/Linux, installed wheel и миллион событий; сохранить 1128 прежних test ID и 2251 наблюдение; разделить установочные research/targets, обновить Git и локальную Wiki.

math.sin. Изменение сценариев описано в evidence, test ID не удалялись.

**2309 conformance observations**: 1551 исполнение и 758 ожидаемых отказов.

все прежние spec-файлы, source lock и 79 файлов immutable bundles.

Прежние числовые ABI сверены полностью: 69 контрактов для каждой v1–v5 и 73
для v6. Один реестр обслуживает runtime и frozen targets; новые ядра исполняются
в запрошенном контексте security/lower-TF. Проверены версии floor/ceil,
раздельные правила round/formatter, domain NA, underflow/overflow, int64,
точная чётность целой степени, порядок и однократность именованных аргументов,

значений применены независимые Decimal oracles и явный допуск 1e-12.

walk-forward, replay restart, offline и lower-TF v5/v6 проверены. Live сохраняет
общую подписку и запись через backup. Один IR в браузере дал 107 на TEST:B/1
