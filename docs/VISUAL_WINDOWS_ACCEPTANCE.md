# Приёмка окон визуальных рядов R6

[Исходник dd7895cb38ff](https://github.com/s7cret/openpine/commit/dd7895cb38ffe9d9baa438df191d84f22c54a0e0) · [Веточная проверка](https://github.com/s7cret/openpine/actions/runs/42426522484) · [Приёмка по тегу](https://github.com/s7cret/openpine/actions/runs/42426525493)

CI 57/57, Python 3.14.8. В реестре каждой ОС 1 905 тестов. Conformance охватывает 4 288 сценариев, корпус — 180 программ.

- С Pine v3 параметр `show_last` доступен для `plot`, `barcolor`, `bgcolor`,
  `plotbar`, `plotcandle` и заливки между двумя `plot`. Закреплённый
  справочник v3–v4 содержит обе сигнатуры `fill` в одной записи.
  [ADR 0030](adr/0030-visual-output-windows.md)
- Именованный статический `offset` для `plot` проверен в обе стороны.
  Полный экспорт совпал с исходным результатом. Сохранённый IR и
  восстановленный checkpoint сохраняют параметры окна. При закрытии
  бара replay использует окончательное значение.
  Прошли 13 браузерных сценариев, включая границы заливки,
  базовые цвета свечей и исключение скрытых OHLC из шкалы.
- Установленный wheel на обеих ОС прошёл сценарий с вводом размера окна,
  паузой и возобновлением worker. CLI с сохранённым IR совпал с HTTP.
  Проверены смещённые значения из двух соседних диапазонов.
- На Windows успешно выполнено 1 905 тестов, на Linux — 1 904.
  На Linux ожидаемо пропущена проверка псевдонимов файлов Windows 8.3.
  Обе ОС использовали один wheel. Проверены четыре сценария восстановления.
- Совпали результаты всех 4 253 прежних сценариев. Добавлено 35 новых.
  Все отчёты совпали между Windows и Linux. Сверка с TradingView
  относится к отдельному этапу.
