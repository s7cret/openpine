# Приёмка валютных запросов security

Python 3.14.8. На Windows прошли 2221 тестов, на Linux — 2220. Обе системы выполнили один набор из 5543 сценариев. Сверены идентификаторы и содержимое 106 отчётов. Пять прежних случаев получили диагностику версии или отсутствующих метаданных валюты. Четырнадцать новых сценариев охватывают Pine v1–v6.


Повторная проверка `installation (windows-latest, numeric)` прошла на том же коммите. Причина первого сбоя и SHA-256 журнала сохранены в данных приёмки. [Первая попытка](https://github.com/s7cret/openpine/actions/runs/44802207038/job/136534372377).

Для каждой версии Pine v1–v6 проверено чтение IR предыдущей сборки. Узлы запросов совпали, а повторная компиляция примеров дала прежние результаты. Запуск IR другой сборки требует перекомпиляции и возвращает диагностику `ARTIFACT_IDENTITY`.

Сохранённый IR индикатора и стратегии дал одинаковые ряды через CLI и HTTP на общем wheel. Исправленный FX-снимок изменил последнюю цену со 128 до 120 EUR. После остановки процесса воркера и повторной доставки событий восстановленный запуск воспроизвёл график и журнал сделок непрерывного запуска. Первичный инструмент исполнил заявку по цене 13 EUR. [Проверка восстановления](../tests/test_security_currency_replay.py).

Доступность аргументов основана на версионных сигнатурах wiki. Порядок пересчёта EMA и смешанных кортежей зафиксирован как семантика OpenPine. Сверка с TradingView запланирована отдельно. [ADR-0084](adr/0084-security-currency.md).

Нагрузочный прогон на миллионе минутных баров прочитал 16 667 часовых свечей. При одном и трёх запросах каждый источник был открыт один раз. Зафиксированы обращения к датам и значениям FX, время и выборочный максимум RSS.
