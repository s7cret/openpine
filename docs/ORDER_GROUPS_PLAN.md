Объём этапа: подтверждённые исторические бары, фиксированное количество,
существующие лоты и ограниченная OHLC-модель. Пробелы локальных источников
отмечаются как реконструкция для каждой версии. Внешняя сверка с TradingView,
trailing-stop, sizing/margin и исполнение защиты на незакрытой свече — отдельные этапы.
