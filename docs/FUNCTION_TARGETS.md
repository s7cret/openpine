# Чистые функции в целях запросов

`openpine.function-targets.1` дополняет [основной контекст](PRIMARY_TARGETS.md)
отдельными overload IDs `.function.primary.prepared` для Pine v1–v6.
Функции используют существующие UserCallIR, binding IDs, типизацию и qualifiers.
Парсер и неизменяемые выпуски Wiki не изменены.

```pine
//@version=6
indicator("Context helper")
pick(useChart, fallback) =>
    useChart ? syminfo.tickerid : fallback
useChart=input.bool(true)
sym=pick(useChart, "TEST:A")
plot(request.security(sym, "60", close))
```

## Допуск

Разрешены ациклические вызовы чистых scalar функций, обязательные позиционные
и именованные параметры, неизменяемые локальные объявления и возвращающий if.
Параметры принимают прежние const/input/simple типы. Результат цели — string.
Арифметика, сравнения, условные выражения, NA и логика следуют существующей
политике каждой версии. Аргументы вычисляются один раз в исходном порядке,
включая аргументы, не прочитанные телом. Каждая специализация имеет свои locals.

Проверяются все аргументы, инструкции тела и обе ветки. Запрещены var/varip,
переприсваивания, история, встроенные kernels/TA, коллекции, циклы, торговые
эффекты и любые запросы внутри helper. Внешняя цель также не может читать series.
Неиспользуемая отдельная функция не входит в граф цели; внутри вызываемого тела
неиспользуемый недопустимый результат всё равно отклоняется.

Глобальные захваты определяются по реальным LoadIR и окружению определения.
Локальные переменные вызывающей функции не становятся захватами. Видимый,
но непрочитанный глобальный var не мешает чистой функции. Прочитанный глобальный
источник обязан быть неизменяемым безусловным объявлением. Из simple ссылок
допускаются только прежние tickerid/period соответствующей версии.

Один общий бюджет включает раскрытые вызовы, аргументы, локальные инструкции,
ветки и транзитивные глобальные зависимости: 128 узлов, глубина 16, прежняя
глубина вызовов 12. У вложенной функции нет нового бюджета. Сохраняются пределы
строк 4096, int64/конечного float, восьми контекстов и шестнадцати запросов.

## Подготовка и перенос

Общий evaluator дополняется закрытым режимом чистых UDF. Прежние literal,
alias-only, computed и primary профили по-прежнему не допускают вызовы функций.
Изменение их правил задним числом исключено. Новый overload выбирается по всем
целям до выбора более узкого профиля; функция во второй цели или невыбранной
ветке не теряется из-за primary ссылки в первой.

Сначала допускается весь граф, затем вычисляется выбранная ветка. Значения
параметров и основные метаданные разрешают граф до чтения свечей. Пустой результат
наследует основной symbol/timeframe; raw inputs сохраняются. До получения
необходимых метаданных HTTP/CLI/UI показывают needs_primary. Ошибки известных
значений отклоняются до получения данных и создания worker.

Граф содержит raw targets, inputs/primary dependencies, отдельные сведения о
вызываемых функциях и program_sha256. Тела функций поэтому участвуют в его
идентичности. Существующие RunPlan/checkpoint bindings закрепляют полные источники
и ревизии данных. Worker, исследования, replay и live используют этот общий
resolver; отдельного способа исполнения целей в приложении нет.

Матрица `spec/function-targets-profile.json` ссылается на прежний выпуск функций
и primary profile. Исторические реконструкции v1–v6 и ранних пустых значений
сохранены явно. Точная эквивалентность TradingView остаётся отдельным этапом.

## Проверка

```sh
python -m tools.function_targets_spec --check
python -m tools.function_targets_flow --directory NEW_DIRECTORY
python -m tools.function_targets_soak --directory ANOTHER_DIRECTORY
```

Корпус содержит 38 независимых наблюдений: 32 исполнения и 6 ожидаемых отказов.
Оракулы — ручное отображение закрытий и суммы, без runtime в ожидаемых значениях.
Flow объединяет сохранённый IR v1–v6, UDF/SMA/state запрошенного выражения,
pause/resume worker, restart replay и свежий offline-повтор. Установленный suite
research проверяет CLI на двух рынках v1–v6, HTTP v1/v6 и lower-TF v5/v6.

Тесты дополнительно проверяют lexical captures, shadowing, аргументы, обе ветки,
совокупные бюджеты, подмену IR и старые ограничения. Миллион событий проверяется
независимой формулой для каждого выходного значения с восстановлением в середине
младшего бара. [План и окончательная приёмка](FUNCTION_TARGETS_PLAN.md).
