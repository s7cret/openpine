# Вертикальные градиенты fill

В Pine v5–v6 `fill` принимает две ранее объявленные ссылки одного
вида, два уровня и два цвета. Уровни и цвета могут меняться на каждом
баре. Первые шесть аргументов можно передать позиционно. Именованные
`title` и `fillgaps` принимают константы. Значение `fillgaps`
по умолчанию равно `false`. Для v1–v4 доступность проверяется
отдельной диагностикой.
[ADR 0032](adr/0032-gradient-fill.md) · [Анонс TradingView](https://www.tradingview.com/blog/en/pine-script-vertical-gradients-33586/)

```pine
//@version=6
indicator("Градиентный канал", overlay=true)
hi = plot(high, show_last=60)
lo = plot(low, show_last=60)
fill(hi, lo, high, low, color.new(color.teal, 25), na, fillgaps=false)
```

Два `plot` или два `hline` ограничивают область рисования. Границы
`plot` берутся после применения `show_last` и `offset`, включая
точки из соседних страниц. Градиент окрашивает сегмент по значениям
его правого бара. Он лежит под линиями и виден в их общей панели.
Цвет линий может быть прозрачным. Уровни градиента влияют на цвет
внутри маски, а пределы шкалы определяются отображаемыми рядами.

Уровни могут идти в любом порядке. Цвет остаётся связан со своим
уровнем. При совпадении уровней на этой высоте получается резкая
граница. Один `na`-цвет заменяется прозрачной версией другого цвета.
Если оба цвета или любой уровень равны `na`, соответствующий
сегмент пропускается. При `fillgaps=true` маска может соединить
допущенные пары границ по сторонам пропуска в текущем окне.
Пересечение двух границ делит сегмент в точке пересечения.

Слой `openpine.gradient-fill.1` хранит ссылки, тип маски и параметры
сегментов. Строка Parquet содержит четыре исходных значения в объекте
`gradient` и пустой скалярный слот. Полный экспорт и API графика
возвращают `gradients`, а replay передаёт подтверждённые строки
и отдельный образец открытого бара. Геометрия использует одну
реализацию для истории и replay.
