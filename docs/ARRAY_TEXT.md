# Разделение строки и объединение массива

В Pine v4–v6 `str.split(string, separator)` создаёт новый массив строк при каждом определённом вызове. Ссылки на один результат видят мутации. Массив, полученный повторным вызовом, независим. В v4 тип результата записан как `string[]`, в v5/v6 — `array<string>`.

`array.join(id, separator)` возвращает series string и читает текущие элементы по порядку. В v5/v6 справочник перечисляет массивы string, int и float. В записи v4 тип массива не уточнён, поэтому профиль v4 принимает те же три типа. Для чисел используется существующее десятичное представление OpenPine по умолчанию, включая округление до десяти дробных знаков.

| Вход | Результат профиля |
| --- | --- |
| split строки `::A::::B::` по `::` | Пять элементов, включая пустые на краях и между соседними разделителями |
| Разделитель отсутствует в строке | Один элемент с исходной строкой |
| Разделитель пуст | По элементу на кодовую точку Unicode. Для пустого исходника получается пустой массив |
| Пустой исходник и непустой разделитель | Один пустой элемент |
| na в аргументе split | Отсутствующая ссылка |
| Пустой массив для join | Пустая строка |
| Один элемент | Текст элемента без разделителя |
| na среди элементов или вместо разделителя join | Отсутствующая строка в пределах бюджета вычисления |
| na вместо ссылки join | Диагностика ARRAY_NA |

Граничные случаи отражают решения исторического профиля. Исходные строки, разделитель и результат join ограничены 4096 кодовыми точками. Учитываются общий бюджет скалярных операций, работа над элементами и лимиты хранилища массивов. Обе функции имеют статус PARTIAL во всех трёх версиях. Сохранение и восстановление используют существующий формат массива.
