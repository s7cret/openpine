# Массивы ссылок на table и linefill

В Pine v4–v6 `array.new_table(size, initial_value)` создаёт изменяемый массив ссылок на таблицы. Оба аргумента необязательны, size по умолчанию равен 0, initial_value равен na. Эти значения указаны в закреплённых записях справочника, включая v4.

В Pine v5/v6 поддерживаются `array.new_linefill(size, initial_value)`, `array.new<table>()` и `array.new<linefill>()`. Для именованного конструктора linefill закреплённый справочник перечисляет размер и начальную ссылку, но оставляет обязательность неизвестной. OpenPine использует общие значения по умолчанию типизированного конструктора массива: нулевую длину и пустую ссылку. Явно переданная ссылка имеет тип элемента и повторяется в каждой ячейке.

Копирование массива создаёт независимые ячейки и сохраняет идентичность объектов. Через get или pop можно получить исходный объект. Изменение таблицы или цвета заливки по полученной ссылке видно через другие ссылки. Операции set, push и clear меняют только содержимое массива. Удаление граничной линии удаляет заливку по правилам существующего хранилища. Сохранённый идентификатор удалённого объекта допустим. Списки table.all и linefill.all доступны для чтения в v5/v6 и сохраняют ограничения своего профиля.

При восстановлении checkpoint идентификаторы таблиц проверяются по счётчику таблиц, заливок — по отдельному счётчику заливок в хранилище линий. При realtime-пересчёте изменение таблицы и удаление границы заливки во временном обновлении откатываются вместе с состоянием скрипта. Внешняя сверка исполнения с TradingView остаётся открытой.
