# Приёмка наблюдаемого брокера

- [x] Отдельный закреплённый профиль v1–v6, прежние модели сохранены.
- [x] Известные цены и разделение Pine rollback/сохранённых исполнений.
- [x] Pending-входы, stop-limit, изменение/отмена и OCA на общем брокере.
- [x] Защита, partial, trailing, fees, лоты и risk.
- [x] Checkpoint внутри свечи, атомарная публикация, backup и журнал.
- [x] CLI/HTTP, отображение в вебе и переносимая офлайн-запись.
- [x] Независимые ожидания, полная регрессия, нагрузка, браузер и CI.

База: `218f086`, 889 тестов/95 модулей, 2074 conformance-наблюдения.
Прежние test IDs и семантические наблюдения сохраняются. Новые проверки
должны охватить шесть языковых версий, logical/received clocks, восстановление
после каждого события, плотную незакрытую свечу, падение до/после публикации,
новый worker, backup, перенос записи и одинаковый журнал CLI/HTTP.
Приёмка выполняется на Python 3.14.8 в Windows/Linux, из checkout и общего
установленного wheel. Сравнение с TradingView в этот этап не входит.

Скрипт рассчитывается на подтверждённом закрытии; модель исполняет существующие
заявки по известным ценовым кадрам. Пропущенные тики не реконструируются,
биржевые заявки не отправляются. Эквивалентность TradingView остаётся отдельным
этапом. Прежние сессии с несовместимой implementation identity требуют новой
компиляции и новой сессии.

После квалифицированного коммита публикуются только документация, доказательства
и сгенерированные отчёты conformance; исполняемый исходник остаётся тем же.
