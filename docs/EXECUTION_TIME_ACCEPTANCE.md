Python 3.14.8, CI 57/57, один wheel.
Windows — 2150 успешных тестов. Linux — 2149 успешных тестов.
На Linux пропущена проверка коротких путей Windows 8.3.

Отчёты Windows и Linux совпадают. Сохранены все 5249
прежних наблюдений.
Добавлены 4 исполняемых сценариев и
6 ожидаемых отказов.

На общем wheel CLI прочитал IR, сохранённый HTTP-компилятором.
Исторический воркер сохранил закреплённое время после возобновления.
Replay восстановился после открытия и после обновления свечи. Итоговые
интервалы между обновлениями и время запоздавших закрытий совпали,
а журнал оповещений сохранил время того же события без дублей.
Нативные проверки сверили часы запрошенного контекста, исторический
префикс replay, повторную доставку и несовместимость смены метки.

Первый прогон Windows lots остановился на any v2 после 302 из 360 свечей с JOB_TIMEOUT. Heartbeat обновлялся до остановки; расхождение результатов не зафиксировано. Из того же wheel локальная Windows-проверка прошла с исходным лимитом 120 с, возобновление any v2 заняло 28.9 с. Повтор назначен для того же источника и wheel.
