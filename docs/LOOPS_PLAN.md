# Циклы и управление исполнением

- [x] 1. Версионные правила v1–v6, источники и явные реконструкции.
- [x] 2. `for`: границы, шаг, вложенность, динамический history offset.
- [x] 3. `while`, ближайшие `break` и `continue`.
- [x] 4. Значения циклов, нулевые итерации, типы и возврат из UDF.
- [x] 5. Локальные переменные, `var`, история и состояние TA.
- [x] 6. Общий бюджет работы на бар, отмена и диагностики с позицией.
- [x] 7. CLI/web/research, checkpoint/rollback/recovery, нагрузка, wheel и CI.

`for` отсутствует в v1; `while` отсутствует до v5. Для v6 конечная
граница `for` динамическая. Проверка эквивалентности TradingView остаётся
отдельным этапом. Предыдущие неизменяемые bundles сохраняются.

Приёмка закрыта 24 октября 2026 года для `7146b5a`:
527 тестов в 62 модулях, 715 conformance-сценариев (92 новых).
Наблюдения прежних 623 сценариев и 51 файл старых bundles сохранены.

Проверены установленный wheel, сохранённый IR `.8`, CLI/HTTP, experiment,
search и walk-forward. В настоящем браузере выполнены `for` v2/v6 и
`while` v5/v6, восстановлены исходник/параметры/контексты/результат после
перезагрузки. Для v1 проверен явный отказ с переходом к строке исходника.

Полный worker прошёл 1 млн основных и 250 тыс. старших свечей:
5 млн итераций и 3 млн обновлений SMA внутри цикла. Независимо прочитаны 3 млн выходных
точек и проверены 1174 объекта, SQLite, Parquet и совместные checkpoints.
Пик RSS — 150,4 МиБ при бюджете 512 МиБ. На 100 тыс. свечей проверены
настоящее падение worker, повторная попытка и backup/restore без расхождения.

Все девять [CI jobs](https://github.com/s7cret/openpine/actions/runs/40038391702) прошли на Windows/Linux
с Python 3.14.8. [Итоговые доказательства](evidence/loops-20261024.json)
связывают исходный коммит, идентичности исполнения/сборки, контрольные суммы
журналов, браузерные задания и результаты независимого чтения хранилища.
Предварительные неуспешные проверки прежних тестовых ожиданий сохранены;
исправленные проверки и оставшийся локальный хвост выполнены повторно,
а финальная матрица CI прошла с чистых checkout.
