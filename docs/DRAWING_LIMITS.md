# Лимиты графических объектов

| Параметр | Версии Pine | Допустимое значение | По умолчанию |
| --- | --- | --- | --- |
| `max_lines_count` | v4–v6 | 1–500 | 50 |
| `max_labels_count` | v4–v6 | 1–500 | 50 |
| `max_boxes_count` | v4–v6 | 1–500 | 50 |
| `max_polylines_count` | v5–v6 | 1–100 | 50 |

Передавайте параметры по имени и используйте константные целые значения.
В v4 декларация индикатора называется `study`, в v5–v6 `indicator`.
Декларация `strategy` принимает эти параметры в тех же версиях. Исполнение
рисуемых объектов в текущем профиле ограничено индикаторами.
Константные выражения в параметрах вычисляются при подготовке программы,
до обработки первого бара.
[Справка Pine](https://www.tradingview.com/pine-script-docs/language/declaration-statements/#max_lines_count-max_labels_count-max_boxes_count-and-max_polylines_count)

При создании объекта сверх лимита OpenPine удаляет самый старый живой объект
того же вида. Обновление координат сохраняет его возраст. Объект с координатами
`na` занимает место, если вызов создал запись. При удалении линии исчезает
заливка, которая на неё ссылается. Лимит linefill и правила для таблиц
задаются отдельно. У полилиний действуют и предел по числу объектов, и бюджет
вершин. Бюджет событий применяется к каждому бару.

На открытом баре вытеснение видно в preview. Только подтверждённый бар
попадает в журнал и меняет набор сохранённых объектов. При возобновлении
выполнения лимит снова вычисляется из той же допущенной программы.
Справка TradingView описывает приблизительное число показываемых объектов.
OpenPine соблюдает точный предел. Сверка с TradingView входит в отдельный этап.
