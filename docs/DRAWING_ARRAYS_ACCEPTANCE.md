- Линии, метки и зоны поддерживаются в массивах v4–v6, полилинии — в v5–v6. Проверены очереди индикатора, методы массива и перебор, несовместимые типы ID, ранние версии и ограничение `varip`.
- В checkpoint сохраняются алиасы и история массива, включая ID вытесненной линии. Восстановление отклоняет ID за границей выделения и сохраняет подтверждённое состояние при ошибке.
- Зоны, полилинии, график и журналы стратегии после перезапуска совпали с непрерывным прогоном. Replay подтвердил откат открытого бара. Заявки, исполнения и капитал совпали с контрольной стратегией. Проверка через HTTP прошла на общем wheel в Windows и Linux.

- Сохранены 4 549 прежних наблюдений, добавлено 12 сценариев. Отчёты conformance совпадают между Windows и Linux.
