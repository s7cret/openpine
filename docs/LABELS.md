# Метки Pine v4–v6

Исторический и наблюдаемый индикаторы поддерживают `label.new(x, y, text)`,
`label.set_xy(id, x, y)`, `label.set_text(id, text)` и `label.delete(id)`.
В Pine v4 используется `study()`, в v5–v6 — `indicator()`. Для v1–v3
тип и операции отклоняются с `LABEL_VERSION`. Профиль привязан к выпускам
спецификации в [labels-profile.json](../spec/labels-profile.json).

```pine
//@version=6
indicator("Moving label", overlay=true)
var label moving = na
if bar_index == 0
    moving := label.new(na, na)
alias = moving
label.set_xy(alias, bar_index, close)
label.set_text(alias, close > open ? "Up" : "Down")
```

Исходный режим использует индекс бара и числовую цену. В режиме `yloc.price`
координата `na` скрывает объект до установки обеих координат.
Текст по умолчанию пустой. Псевдонимы ссылаются на один объект. Повторное
удаление, setters на `na`, удалённой или вытесненной ссылке ничего не меняют.
Один индикатор удерживает до 50 живых меток и вытесняет самую раннюю по
созданию. Текст ограничен 4096 символами, один бар — 1024 операциями журнала.

В первом профиле доступны обычные и `var`-переменные, операторы `if` и
присваивание. За его пределами остаются стратегии, `varip label`,
передача ссылок в функции, коллекции и request-выражения, история ссылок,
`label.all` и методы.
Координаты времени доступны через именованный аргумент [`xloc`](DRAWING_XLOC.md).
Точечная перегрузка и сеттер описаны в [профиле `chart.point`](CHART_POINTS.md).
Цвет, форма, цвет текста и размер описаны в [профиле оформления](LABEL_STYLES.md).
Режим Y и привязка к свече описаны в [профиле `yloc`](LABEL_YLOC.md).
Выравнивание, шрифт и подсказки описаны в [профиле текста](LABEL_TEXT.md).

При повторном расчёте открытого бара обычные ссылки и метки берутся из
подтверждённого состояния. Preview возвращает свой набор живых объектов.
После закрытия воркер сохраняет упорядоченные `create`, `update` и `delete`
в отдельный журнал. Страница `/api/jobs/{id}/label_events?start=0&limit=100`
возвращает события в порядке записи. Аналогичный маршрут есть у replay.

Окно графика выбирает метки из последнего опубликованного снимка по их
текущей координате X. Поэтому метка, созданная до начала окна, видна
после перемещения в это окно. ID и причины удаления доступны в журнале.
Решения о восстановлении записаны в [ADR 0009](adr/0009-durable-labels.md).
Локальные ожидания в [conformance/labels](../conformance/labels/cases.json)
проверяют границы этого профиля. Сравнение исполнения с TradingView
проводится отдельным этапом.
