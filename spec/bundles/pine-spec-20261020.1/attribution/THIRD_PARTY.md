# Источники и права

Pine Wiki — неофициальный справочник, не связанный с TradingView. Имена Pine Script и TradingView используются для указания предмета справочника; права на обозначения принадлежат их правообладателям.

По решению владельца собственный код интерфейса и инструментов распространяется по [MIT](LICENSE). Собственные строки интерфейса в `wiki-i18n.js` также относятся к коду интерфейса. Это решение не распространяется автоматически на редакторские тексты каталогов, переводы, документацию, примеры кода и снимки источников.

| Материал | Источник / правообладатель | Условия в этой поставке |
|---|---|---|
| Справочник и руководство Pine Script | TradingView и указанные авторами правообладатели | Сохранены исходные ссылки и данные происхождения. MIT проекта к этим материалам не применяется. |
| Исторические снимки страниц | Исходные авторы; Internet Archive хранит снимки | Архивная ссылка не является отдельной лицензией на исходный текст. |
| Ссылки и материалы GitHub / gists | Авторы соответствующих репозиториев и публикаций | Проверять лицензию конкретного источника; принадлежность домену GitHub не определяет лицензию. |
| Переводы и редакторские пояснения в каталогах | Проект и авторы использованных материалов | Отделены от MIT-кода; выбор лицензии на собственный код не означает разрешение на распространение производных текстов. |

Полный список сохранённых URL и числа ссылок генерируется в [docs/source-inventory.csv](docs/source-inventory.csv). На уровне карточек сохранены `sources`, `source` и SHA-256 снимков. SHA-256 подтверждает идентичность сохранённого источника, а не права на его использование.

Актуальные условия правообладателя доступны на странице [TradingView Terms of Service](https://www.tradingview.com/policies/). Текст лицензии MIT опубликован [Open Source Initiative](https://opensource.org/license/mit). Этот файл описывает границы лицензии данной поставки и не заявляет о полученном разрешении TradingView на публичную раздачу каталогов.

Экспорт JSON содержит те же сторонние материалы и не меняет их правовой статус. Права на их публичное распространение в рамках этой задачи не установлены. Ни репозиторий, ни сайт в ходе исправлений не публиковались.
