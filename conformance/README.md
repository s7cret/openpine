# Исполняемый conformance R6

Ожидания задаются отдельно от реализации: ручная арифметика, типы и правила binding закреплённых профилей. Они не вычисляются OpenPine и не переписываются по результатам запуска. Внешнее исполнение Pine Editor не заявляется.

| Корпус | Успешных | Ожидаемых отказов | Объём |
|---|---:|---:|---|
| `literal-harness/cases.json` | 5 | 3 | Один synthetic observation, absolute value, v1/v5/v6 |
| `historical-bars/cases.json` | 6 | 5 | Close, EMA, NA, вложенные вызовы, v5/v6 |
| `versions/cases.json` | 36 | 26 | Отдельные случаи для каждой версии v1–v6 |

Версионный корпус содержит по шесть успешных программ на версию: close, абсолютная величина, EMA, независимые/вложенные вызовы, пропуски и integer promotion. Отказы проверяют длину, тип, имя из другой эпохи и отсутствие данных. Для v1/v2 отдельно проверяется отказ непроверенных именованных вызовов EMA. Gate сравнивает покрытые семейства операций между всеми шестью версиями; выпадение версии обнаруживается.

Собственные синтетические close-only fixtures находятся рядом с программами. Для длины 3 коэффициент EMA равен 1/2. При первом-source seed значения 10,20,30,40 дают 10,15,22.5,31.25; при SMA seed — null,null,20,30. Вложенный SMA-seeded EMA на 10..60 даёт null,null,null,null,30,40. Эти ожидания проверяют **явно объявленные профили**, а не доказывают поведение старого TradingView. v1/v2 частично реконструированы; противоречия старой документации описаны в [VERSIONS.md](../docs/VERSIONS.md).

Запуск: `python -m tools.conformance`. Команда компилирует и исполняет все корпуса, сравнивает точные типы/результаты и диагностические категории/коды с ожиданиями, затем сверяет отчёты в `results/`. Отчёты содержат source/expected/IR/data/spec-lock/implementation hashes, semantic profile/version и Python 3.14.8. После намеренного изменения реализации: рассмотреть diff, выполнить `python -m tools.conformance --write-report`, проверить новые отчёты. Эталонные ожидания команда не изменяет.

Unittest дополнительно проверяют EMA через независимую формулу взвешенной суммы на точных дробях, изоляцию состояний, отсутствие будущих данных, несовместимый IR, целостность нового version-review и сохранение неопределённых defaults v5. Полная совместимость Pine, realtime, requests и стратегии этими корпусами не заявляются.
